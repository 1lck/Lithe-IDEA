# Editor Shortcut Import

The provider uses the official Lithe Rust plugin SDK (Apache-2.0),
`jsonc-parser` 0.34.0 by David Sherret (MIT), and `quick-xml` 0.37.5
(MIT). Their license texts are included in `licenses/`. Other Rust runtime
dependencies are available under Apache-2.0 or MIT; their exact versions and
sources are pinned in `Cargo.lock`.

The IDEA default mappings are based on JetBrains IntelliJ Community's
Apache-2.0 keymaps at revision `e12d185a335d02f3831c12f2af64130b3ace46db`
and [JetBrains' macOS reference](https://www.jetbrains.com/help/idea/reference-keymap-mac-default.html).
VS Code defaults follow [Microsoft's macOS reference](https://code.visualstudio.com/shortcuts/keyboard-shortcuts-macos.pdf).
