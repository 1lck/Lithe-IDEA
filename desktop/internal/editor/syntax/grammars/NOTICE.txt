Bundled TextMate grammars

The files below are third-party grammars, copied without changes. The client embeds them and
reads them only from memory: there is no download, extraction, token cache or write to the
installation directory. Other languages get their grammars from plugins.

Unless noted, a file comes from microsoft/vscode at commit
e646868227c3e3a9e3f24277c8c7220be42c0be7, extensions/<extension>/syntaxes/<file>, which VS Code
distributes under its MIT license, LICENSE.vscode.txt. The grammar each file was converted from,
and that grammar's license, follow.

- java.tmLanguage.json (extension java): redhat-developer/vscode-java
  f09b712f5d6d6339e765f58c8dfab3f78a378183, language-support/java/java.tmLanguage.json, itself
  derived from atom/language-java (MIT). VS Code records the file as MIT; the vscode-java
  repository is licensed under the Eclipse Public License 2.0, LICENSE.vscode-java.txt, so the
  file is treated as available under that license as well.
- make.tmLanguage.json (extension make): fadeevab/make.tmbundle
  1d4c0b541959995db098df751ffc129da39a294b. LICENSE.make.txt (MIT and the Original TextMate
  License).
- rust.tmLanguage.json (extension rust): dustypomerleau/rust-syntax
  ca34cf382a7b250144f2ccb99ff9af96912c79f2. MIT, LICENSE.rust-syntax.txt.
- go.tmLanguage.json (extension go): worlpaker/go-syntax
  c74e22eb9ef32958e3edd130ea750ce78d8b8241. MIT, LICENSE.go-syntax.txt.
- c.tmLanguage.json (extension cpp): jeff-hykin/better-c-syntax
  34712a6106a4ffb0a04d2fa836fd28ff6c5849a4. MIT, LICENSE.better-c-syntax.txt. Derived from
  atom/language-c and textmate/c.tmbundle, LICENSE.textmate-bundles.txt.
- cpp.tmLanguage.json, cpp.embedded.macro.tmLanguage.json: not from VS Code, but from
  jeff-hykin/better-cpp-syntax at commit 06f4011c0b5ccb85fcbcbaebbb73d2fda93365bf,
  autogenerated/<file>, where the author returned the repository to the MIT license:
  LICENSE.better-cpp-syntax.txt. The files are byte for byte those of the commit VS Code
  updates its C++ grammar from (071dd6ecc9eda347bd84c8aa0e0b557396cb6a40), whose rules VS Code
  ships unchanged.
- TypeScript.tmLanguage.json, TypeScriptReact.tmLanguage.json (extension typescript-basics):
  microsoft/TypeScript-TmLanguage 48f608692aa6d6ad7bd65b478187906c798234a8. MIT,
  LICENSE.typescript-tmlanguage.txt.
- JavaScript.tmLanguage.json, JavaScriptReact.tmLanguage.json (extension javascript): derived
  from microsoft/TypeScript-TmLanguage 3133e3d914db9a2bb8812119f9273727a305f16b, MIT,
  LICENSE.typescript-tmlanguage.txt, and textmate/javascript.tmbundle,
  LICENSE.textmate-bundles.txt.
- html.tmLanguage.json (extension html): textmate/html.tmbundle
  0c3d5ee54de3a993f747f54186b73a4d2d3c44a2, LICENSE.textmate-bundles.txt.
- css.tmLanguage.json (extension css): microsoft/vscode-css
  de9e6beee756760f31b15efbd782735fc25de3db. MIT, LICENSE.vscode-css.txt.
- markdown.tmLanguage.json (extension markdown-basics): microsoft/vscode-markdown-tm-grammar
  0812fc4b190efc17bfed0d5b4ff918eff8e4e377, MIT, LICENSE.vscode-markdown-tm-grammar.txt, derived
  from textmate/markdown.tmbundle, LICENSE.textmate-bundles.txt.
- dotenv.tmLanguage.json (extension dotenv): dotenv-org/dotenv-vscode

- yaml.tmLanguage.json, yaml-1.0.tmLanguage.json, yaml-1.1.tmLanguage.json,
  yaml-1.2.tmLanguage.json, yaml-1.3.tmLanguage.json, yaml-embedded.tmLanguage.json (extension

- JSON.tmLanguage.json, JSONC.tmLanguage.json (extension json): microsoft/vscode-JSON.tmLanguage

- toml.tmLanguage.json: not from VS Code, but from tamasfe/taplo at commit
  08f343be02ce1b20296470396a42f0fa47820449, editors/vscode/toml.tmLanguage.json. MIT,
  LICENSE.taplo.txt.

The tokenizer that runs them (internal/editor/textmate) is a Go port of vscode-textmate's
algorithm, MIT: internal/editor/textmate/LICENSE.vscode-textmate.md.
Its Oniguruma-compatible regular expressions come from a modified copy of
github.com/dlclark/regexp2 v1.12.0, MIT: internal/editor/textmate/internal/regexp2/LICENSE;
the changes are listed in internal/editor/textmate/internal/regexp2/NOTICE.md.
