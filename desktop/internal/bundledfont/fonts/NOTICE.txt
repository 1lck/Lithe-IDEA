JetBrains Mono Nerd Font Mono — Nerd Fonts v3.5.1 (JetBrains Mono 2.304).
https://github.com/ryanoasis/nerd-fonts/tree/v3.5.1/patched-fonts/JetBrainsMono/Ligatures
Four unmodified upstream TTF faces; redistribution: JetBrainsMonoNerdFont-OFL.txt.
These complete patched terminal faces include cell-aligned prompt symbols.

The packaged macOS build compiles this folder, licenses included, into the executable under the
lithe_bundled_fonts build tag (scripts/desktop/package-desktop.sh). The client registers each face
with CoreText at process scope; nothing is installed in the user's font library, and nothing is
read from or written to the app bundle for them, so the signed bundle and the baseline Sparkle
differential updates are built against stay unchanged.
