## 中文

Lithe 0.3.2 将最新的 0.3.0 预发布开发成果完整合入稳定分支，集中改进 macOS 与 Windows 的编辑器、Java 工具链、运行配置和工作台体验。

### 下载

- **项目主页：** [Lithe IDEA](https://github.com/1lck/Lithe-IDEA)
- **macOS Apple Silicon：** [下载 DMG](https://github.com/1lck/Lithe-IDEA/releases/download/v0.3.2/Lithe-0.3.2-arm64.dmg)

> Windows 版本目前仍处于预览阶段。安装程序在未配置 Authenticode 证书时可能没有数字签名，Windows 可能会显示安全提示。

### 重点更新

- 为 macOS 增加可配置的工作台背景，并完善透明工作台表面、设置持久化与背景图片校验。
- 扩展项目运行配置，支持项目级工具链覆盖、保存前同步，以及 macOS 与 Windows 一致的运行配置行为。
- 改进 Windows IDEA 风格工作台布局、工具窗口、通知入口、搜索交互和编辑器输入路由。
- 增强 Java 语义高亮、JDTLS 文档同步、定义悬停与依赖导航，并在正式安装包中继续内置 JDK/JDTLS 运行资源。

### 改进与修复

- 支持文件与终端标签横向吸附、统一排序和终端停靠/拖回，同时保留原生终端视图状态。
- 修复编辑器折叠、装饰层和 gutter 布局更新问题，并改进多种配置文件的语法高亮。
- 降低 Windows 编辑器输入热路径开销，修复滚动、弹出菜单、设置页和项目菜单交互问题。
- 修复工作区级编辑器保存、Java 文档生命周期、LSP 会话路由及 Git 换行差异显示问题。
- 加固 macOS 与 Windows 构建缓存、依赖下载校验和平台更新清单生成流程。

### 升级说明

- **macOS DMG：** 退出正在运行的 Lithe，打开对应架构的 DMG，然后将 Lithe 拖入“应用程序”并替换旧版本。
- **Homebrew：** 运行 `brew update && brew upgrade --cask lithe`。
- **Windows：** 退出正在运行的 Lithe，然后运行 Windows x64 安装程序并按提示完成安装。

### 兼容性与已知问题

- macOS 需要 macOS 13 或更高版本。
- Java 项目功能需要 JDK 17 或更高版本，推荐使用 JDK 17 或 JDK 21。
- macOS 和 Windows 正式安装包均包含 JDTLS，无需单独安装。
- Windows 版本仍处于预览阶段，部分平台能力和界面细节可能与 macOS 不完全一致。

## English

Lithe 0.3.2 brings the latest 0.3.0 preview work into the stable branch, with a broad set of editor, Java tooling, run configuration, and workbench improvements for macOS and Windows.

### Downloads

- **Project homepage:** [Lithe IDEA](https://github.com/1lck/Lithe-IDEA)
- **macOS Apple Silicon:** [Download DMG](https://github.com/1lck/Lithe-IDEA/releases/download/v0.3.2/Lithe-0.3.2-arm64.dmg)
- **macOS Intel:** [Download DMG](https://github.com/1lck/Lithe-IDEA/releases/download/v0.3.2/Lithe-0.3.2-x86_64.dmg)
- **Windows x64 preview:** [Download installer](https://github.com/1lck/Lithe-IDEA/releases/download/v0.3.2/Lithe-0.3.2-windows-x64.exe)
- **All downloads:** [View Release Assets](https://github.com/1lck/Lithe-IDEA/releases/tag/v0.3.2)

> The Windows build remains a preview. If an Authenticode certificate is not configured, the installer may be unsigned and Windows may show a security warning.

### Highlights

- Added configurable macOS workbench backgrounds with transparent workbench surfaces, persisted settings, and replacement image validation.
- Expanded project run configurations with project-scoped toolchain overrides, save-before-run synchronization, and aligned behavior across macOS and Windows.
- Refined the Windows IDEA-inspired workbench layout, tool windows, notifications, search interactions, and editor input routing.
- Improved Java semantic highlighting, JDTLS document synchronization, definition hover, and dependency navigation while continuing to bundle the required JDK and JDTLS runtime assets.

### Improvements and fixes

- Added horizontal docking and shared ordering for file and terminal tabs, including reliable terminal undocking and native view preservation.
- Fixed editor folding, overlay, and gutter relayout behavior, and improved syntax highlighting for common configuration formats.
- Reduced work on the Windows editor input hot path and fixed scrolling, popup, settings, and project menu interactions.
- Fixed workspace-scoped editor saves, Java document lifecycle handling, LSP session routing, and line-ending-only Git diffs.
- Hardened macOS and Windows build caches, dependency verification, and platform-specific update manifest generation.

### Upgrade instructions

- **macOS DMG:** Quit Lithe, open the DMG for your Mac architecture, and replace the existing application in the Applications folder.
- **Homebrew:** Run `brew update && brew upgrade --cask lithe`.
- **Windows:** Quit Lithe, run the Windows x64 installer, and follow the installation prompts.

### Compatibility and known issues

- macOS requires macOS 13 or later.
- Java project features require JDK 17 or newer. JDK 17 or JDK 21 is recommended.
- Release packages for macOS and Windows include JDTLS, so it does not need to be installed separately.
- The Windows build remains a preview, and some platform capabilities and interface details may differ from macOS.
