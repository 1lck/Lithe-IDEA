## 中文

本版本改进了 Git 多仓库、Windows 终端和 macOS 编辑体验，让项目切换、克隆和提交文件查看更加稳定。

### 下载

- [项目主页](https://github.com/1lck/Lithe-IDEA)
- [macOS 与 Windows 安装包（完整 Release Assets）](https://github.com/1lck/Lithe-IDEA/releases/tag/v0.4.4)

### 重点更新

- 多仓库工作区现在能正确汇总各仓库的变更。
- Windows 支持更可靠地识别 Git Bash，并可快捷创建终端。
- Windows 欢迎页可以正常进入仓库克隆流程。
- macOS 提交文件树修复文字重叠，并支持悬停展开。
- macOS 右键菜单和工作区分割条交互更加统一。
- macOS 与 Windows 均支持导出脱敏诊断包，便于提交问题。
- Java Mapper 可以跳转到对应的 MyBatis XML 文件。

### 升级说明

macOS：下载对应架构的 DMG，打开后将 Lithe.app 拖入“应用程序”；也可使用 Homebrew 安装。Windows：下载 Windows x64 安装包并运行安装程序。

### 兼容性与已知问题

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

[查看 v0.4.3 到 v0.4.4 的完整变更](https://github.com/1lck/Lithe-IDEA/compare/v0.4.3...v0.4.4)

## English

This release improves multi-repository Git workspaces, Windows terminals, and the macOS editing experience, making project switching, cloning, and commit review more reliable.

### Downloads

- [Project homepage](https://github.com/1lck/Lithe-IDEA)
- [macOS and Windows installers (complete Release Assets)](https://github.com/1lck/Lithe-IDEA/releases/tag/v0.4.4)

### Highlights

- Multi-repository workspaces now aggregate changes from all repositories correctly.
- Windows detects Git Bash more reliably and supports quick terminal creation.
- The Windows welcome page can proceed to repository cloning.
- The macOS commit file tree no longer overlaps text and expands on hover.
- macOS context menus and workspace split-bar interactions are more consistent.
- Both macOS and Windows can export a redacted diagnostics package for issue reports.
- Java Mapper navigation can open the corresponding MyBatis XML file.

### Upgrade instructions

macOS: download the DMG for your architecture and drag Lithe.app to Applications; Homebrew installation is also supported. Windows: download the Windows x64 installer and run it.

### Compatibility and known issues

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
