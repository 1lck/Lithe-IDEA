## 中文

Lithe 0.5.8 改善两端设置与标题栏体验，修复 Maven 配置、中文文本编辑和浏览器打开问题。

### 重点更新

本次更新内容如下。

#### ⚡ 改进

- macOS 插件管理移入独立设置窗口，不再占用编辑区，并支持调整和记住侧栏宽度。
- macOS 优化设置布局、输入控件和按钮样式，快捷键设置按操作树组织。
- Windows 标题栏菜单原位展开，点击外部或按 Escape 即可收起，窄窗口也可滚动浏览。
- Windows 项目菜单显示自定义图标，窗口控制、加载和刷新图标更加一致。

#### 🛠 修复

- Maven 设置变更可正确应用到 Java 项目，重新加载时刷新依赖，并显示可定位的 pom.xml 错误。
- Windows 修复 Maven 依赖面板无法加载的问题。
- Windows 含中文的 properties 和未知扩展名文本可正常编辑，并为 properties 启用配置文件高亮。
- 两端 HTML“在浏览器中打开”使用默认浏览器，正确处理中文、空格和特殊字符路径。
- Windows 更新页面正确区分未检查、检查中和失败状态，不再误报“已是最新版”。
- Windows 扩展更新缺少必要依赖时保留旧扩展，并提供手动安装语言工具的提示。
- Windows 运行日志逐字显示符号，避免连字改变等号和箭头的外观。
- macOS 修复壁纸模式下编辑器右侧黑边。
- macOS 插件设置正确处理确认、取消与项目窗口切换，避免修改应用到错误项目。

### 升级说明

- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。

### 兼容性与已知问题

- macOS 需要 13 或更高版本；提供 Apple Silicon、Intel 和 Windows x64 安装包。
- macOS 安装包尚未使用 Developer ID 签名或公证，Windows 安装包尚无 Authenticode 发布者签名；应用更新使用独立签名校验。
- 浏览器打开磁盘上已保存的 HTML；预览前请先保存编辑内容。
- macOS 插件设置目前仅提供 PHP Support 本地安装与启用管理，尚无联网插件市场。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

## English

Lithe 0.5.8 improves settings and title bars, and fixes Maven configuration, Chinese text editing, and opening HTML in browsers.

### Downloads

- [Project homepage](https://github.com/1lck/Lithe-IDEA)
- [macOS Apple Silicon](https://github.com/1lck/Lithe-IDEA/releases/download/v0.5.8/Lithe-0.5.8-arm64.dmg)
- [macOS Intel](https://github.com/1lck/Lithe-IDEA/releases/download/v0.5.8/Lithe-0.5.8-x86_64.dmg)
- [Windows x64](https://github.com/1lck/Lithe-IDEA/releases/download/v0.5.8/Lithe-0.5.8-windows-x64.exe)
- [All downloads](https://github.com/1lck/Lithe-IDEA/releases/tag/v0.5.8)

### Highlights

Changes are grouped below.

#### ⚡ Improvements

- macOS plugin management moves into a separate settings window, with resizable sidebars that remember their widths.
- macOS refines settings layouts, inputs, and buttons, and organizes keyboard shortcuts into an action tree.
- Windows menus expand inside the title bar, dismiss on outside click or Escape, and scroll in narrow windows.
- Windows project menus show custom icons, with more consistent window controls, loading indicators, and refresh icons.

#### 🛠 Fixes

- Maven setting changes now reach Java projects; reloading refreshes dependencies and surfaces navigable pom.xml errors.
- Windows fixes Maven dependency panels that failed to load.
- Windows opens Chinese properties files and unknown-extension text for editing, with configuration highlighting for properties files.
- Both platforms open HTML in the default browser and handle paths containing Chinese characters, spaces, and special characters.
- Windows update settings distinguish unchecked, checking, and failed states instead of incorrectly reporting the latest version.
- Windows preserves existing extensions when update prerequisites are missing and explains how to install language tools manually.
- Windows run logs render symbols individually, preventing ligatures from changing the appearance of equals signs and arrows.
- macOS fixes the black strip beside the editor in wallpaper mode.
- macOS plugin settings handle confirmation, cancellation, and workspace switching without applying changes to the wrong project.

### Upgrade instructions

- macOS: open the DMG for your architecture and drag Lithe.app to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.

### Compatibility and known issues

- macOS requires version 13 or later; installers are available for Apple Silicon, Intel, and Windows x64.
- macOS packages are not Developer ID signed or notarized, and Windows installers lack an Authenticode publisher signature; app updates use separate signature verification.
- Browsers open saved HTML files from disk; save your edits before previewing.
- macOS plugin settings currently support local PHP Support installation and enablement; an online plugin marketplace is not available.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
