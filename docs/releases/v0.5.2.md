Lithe 0.5.2 让运行和测试 Java 代码更直接，集中管理 JDK、Maven 与运行配置，并为 Windows 带来 AI 提交信息生成。

### 重点更新

本次更新重点改善 Java 运行、测试和项目环境配置体验。

#### ✨ 新功能

- Java 文件行号旁显示运行图标，可直接运行 main 方法、整个测试类或单个测试方法。
- 测试跑完后，行号旁的图标会标出每个测试方法和测试类是通过还是失败。
- 设置中新增「项目 · JDK & Maven」和「运行配置」页面，集中管理项目环境和各服务的启动参数。
- Windows 可用 AI 按勾选的文件生成提交信息，支持多个服务商、提交格式设置和导入本机 Codex/Claude 配置。
- Windows 运行面板新增「输出始终滚动到最后一行」开关。

#### ⚡ 改进

- JDK 和 Maven 设为「自动识别」时，设置页会显示实际使用的版本、路径和来源。
- macOS JDK 下拉列表按内容自动变宽，完整显示较长的名称和安装路径。
- macOS 检测完 JDK 后不再重复检测，减少界面卡顿。
- Windows Maven 工具窗口使用与 macOS 一致的 Maven 图标。

#### 🛠 修复

- macOS 选择自定义 Maven 主目录后，依赖解析不再报“权限被拒绝”。
- Windows 大型项目打开运行面板时先显示已有配置，校验超时也不会清空列表。
- Windows 终端中按 `Ctrl+V` 可正常粘贴，不再输入 `^V`。
- Windows 设置中恢复「缓冲区轮播」开关，可以关闭标签横向平铺。
- 导入 Windows 换行格式的 diff/patch 文件时，差异内容和文件路径不再带多余字符。
- 个别代码行着色耗时过长时，不再导致其他 Java 文件都失去语法高亮。
- macOS 去掉 Maven 面板分隔区域的色差和编辑器右侧多余的短线。

### 升级说明

- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。
- 运行面板不再提供逐个服务的编辑按钮，请在「设置 → 运行配置」中修改启动参数、环境变量和 JDK/Maven。

### 兼容性与已知问题

- macOS 需要 13 或更高版本；Windows 仍处于预览阶段，部分功能与 macOS 存在差异。
- Windows 的行号运行图标暂不提供“调试”，macOS 可从同一菜单调试。
- macOS 安装包尚未使用 Developer ID 签名和公证；Windows 安装包尚未使用 Authenticode 发布者签名，系统可能提示安全警告。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

### Highlights

This release focuses on running and testing Java code and configuring project environments.

#### ✨ New features

- Run icons beside Java line numbers start a main method, a whole test class, or a single test method.
- After tests finish, the line-number icons show whether each test method and test class passed or failed.
- New Project · JDK & Maven and Run Configurations settings pages manage project environments and service launch options in one place.
- Windows generates commit messages with AI from the checked files, supporting multiple providers, commit formats, and importing local Codex/Claude settings.
- The Windows run panel adds an "Always scroll output to the end" toggle.

#### ⚡ Improvements

- When JDK or Maven is set to Auto-detect, settings show the actual version, path, and source in use.
- The macOS JDK drop-down widens to fit its options, showing long names and install paths in full.
- macOS no longer repeats JDK detection after it finishes, reducing UI stalls.
- The Windows Maven tool window uses the same Maven icon as macOS.

#### 🛠 Fixes

- On macOS, choosing a custom Maven home no longer causes a "permission denied" dependency resolution error.
- On large Windows projects, the run panel shows existing configurations first and no longer empties the list after a validation timeout.
- `Ctrl+V` pastes in the Windows terminal instead of typing `^V`.
- Windows settings restore the Buffer Carousel toggle, so horizontally tiled tabs can be turned off.
- Importing diff/patch files with Windows line endings no longer adds stray characters to changes and file paths.
- A single slow-to-color line no longer makes every other Java file lose syntax highlighting.
- macOS removes the Maven panel divider color mismatch and stray short lines on the editor's right edge.

### Upgrade instructions

- macOS: open the DMG for your architecture and drag Lithe.app to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.
- The run panel no longer has per-service edit buttons; change launch options, environment variables, and JDK/Maven under Settings → Run Configurations.

### Compatibility and known issues

- Requires macOS 13 or later; Windows remains a preview, with some features differing from macOS.
- Line-number run icons on Windows do not offer Debug yet; on macOS, the same menu can debug.
- macOS packages lack Developer ID signing and notarization; Windows installers lack Authenticode publisher signing, so system security warnings may appear.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
