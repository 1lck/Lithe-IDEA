Lithe 0.5.5 支持按编码重新打开和保存文件，完善多仓库 Git 与终端操作，并改善插件安装、软件更新和工作台体验。

### 重点更新

本次更新涵盖文件编辑、按需插件、多仓库操作与日常使用修复。

#### ✨ 新功能

- 可按指定编码重新打开或保存文件，支持 GBK、GB18030 等编码。
- PHP 支持改为独立安装的官方插件，按需启用语言服务与运行、测试入口。
- Windows 终端支持最小化，并可在设置中选择 Git Bash 等已检测到的 Shell。
- Git 引用菜单补充复制分支名；macOS 增加上游分支设置和重置，Windows 增加撤销提交和复制短哈希。
- Windows 项目树的仓库菜单提供常用 Git 操作，拉取时可选择远程分支和策略。

#### ⚡ 改进

- 多仓库 Git 引用按仓库着色，Windows 分支图颜色保持稳定，切换引用减少重复加载。
- 手动检查到更新后可直接查看详情并安装，设置页也提供安装按钮。
- 可选插件只在安装并启用后工作，禁用后不会因更新重新激活。
- Windows 终端的新建与配置按钮紧邻页签，关闭按钮始终可见。
- Windows 关闭终端诊断后停止额外采样，减少不必要的后台工作。
- macOS 工作台统一主题色与活动栏图标，侧栏可收窄并记住宽度。

#### 🛠 修复

- 大型 Maven 项目的依赖树不再因构建日志过多而加载失败，并显示更多依赖管理信息。
- 修改 Maven 模块服务的工作目录后，运行配置不再错误地从列表消失。
- Java 启动参数和 Windows 终端超长命令得到处理，避免命令长度限制导致失败。
- Java 运行时不再写入安装目录，减少 macOS 增量更新退回完整下载的情况。
- Windows 工作区差异页不再意外关闭，刷新保持滚动位置，长内容可以滚动到底。
- Windows 修复 Git 仓库发现争用、逐行作者信息请求和分支顶端的多余连线。
- Windows 修复部分状态更新异常、编辑器小地图边缘露底和诊断日志导出弹窗溢出。
- macOS 修复背景图片下分隔线不清晰、窄侧栏遮挡、悬停提示和设置标题栏背景问题。
- macOS 修复 Maven 设置按钮被截断和浅色模式下未读通知图标不清晰的问题。

### 升级说明

- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。
- PHP 用户需另行安装并启用官方插件，应用安装包不包含 PHP 工具；Windows 安装步骤见 [插件说明](https://github.com/1lck/Lithe-IDEA/blob/v0.5.5/Plugins/win/README.md)。

### 兼容性与已知问题

- macOS 需要 13 或更高版本；Windows 部分功能仍与 macOS 存在差异，参见[功能矩阵](https://github.com/1lck/Lithe-IDEA/blob/v0.5.5/docs/development/platform-parity-matrix.md)。
- macOS 安装包尚未使用 Developer ID 签名和公证；Windows 安装包尚未使用 Authenticode 发布者签名，系统可能提示安全警告。
- PHP 插件需要另备运行工具；Windows 需要已有的 Bun、Node.js，插件包仅应从可信来源导入，暂不支持自动更新。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

### Highlights

This release improves file editing, optional plugins, repository workflows, and everyday reliability.

#### ✨ New features

- Reopen or save files with a chosen encoding, including GBK and GB18030.
- PHP support is now a separately installed official plugin with optional language services and run and test actions.
- Windows terminals can be minimized, and settings can select Git Bash or another detected shell as the default.
- Git menus add branch-name copying; macOS adds upstream settings and reset options, while Windows adds revert and short-hash copying.
- Windows repository folders offer Git actions, and Pull lets you choose a remote branch and strategy.

#### ⚡ Improvements

- Git references use repository colors; Windows graph colors stay stable, and switching references avoids redundant loading.
- Manual update checks offer release details and installation immediately; settings also provide an install button.
- Optional plugins run only after installation and activation, and updates keep disabled plugins inactive.
- Windows terminal creation and profile buttons sit beside tabs, with close buttons always visible.
- Windows stops extra terminal sampling when diagnostics are disabled, reducing unnecessary background work.
- The macOS workbench refreshes theme colors and activity icons, and remembers narrower sidebar widths.

#### 🛠 Fixes

- Large Maven dependency trees no longer fail because of lengthy build logs, and show more dependency management details.
- Changing a Maven service working directory no longer incorrectly removes its run configuration.
- Large Java launch arguments and long Windows terminal commands are handled to avoid command-length failures.
- Java runtime state no longer writes into installation folders, reducing macOS incremental updates falling back to full downloads.
- Windows working-tree diffs stay open, retain scroll position during refresh, and allow scrolling to the bottom.
- Windows fixes competing Git discovery requests, line-author lookups, and stray lines above branch tips.
- Windows fixes some state-update errors, exposed minimap gutters, and overflowing diagnostic export dialogs.
- macOS fixes unclear dividers over background images, narrow sidebar overlap, hover hints, and settings titlebar backgrounds.
- macOS fixes clipped Maven settings buttons and low-contrast unread notification icons in light mode.

### Upgrade instructions

- macOS: open the DMG for your architecture and drag Lithe.app to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.
- PHP users must separately install and enable the official plugin; PHP tools are not bundled with the app. See [Windows plugin instructions](https://github.com/1lck/Lithe-IDEA/blob/v0.5.5/Plugins/win/README.md).

### Compatibility and known issues

- Requires macOS 13 or later; some Windows capabilities differ from macOS. See the [feature matrix](https://github.com/1lck/Lithe-IDEA/blob/v0.5.5/docs/development/platform-parity-matrix.md).
- macOS packages lack Developer ID signing and notarization; Windows installers lack Authenticode publisher signing, so system security warnings may appear.
- PHP plugins require separate runtime tools; Windows requires existing Bun and Node.js installations. Import only trusted plugin packages; automatic plugin updates are not supported yet.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
