### 重点更新

本次更新让项目准备、代码审阅和 Agent 操作更清楚，也改善日常编辑交互。

#### ✨ 新功能

- macOS Agent 活动栏可展开任务与工具详情，查看文件差异，并保留或回撤修改。
- macOS Git 历史差异以独立标签打开，可与普通文件一起切换、关闭和拖动排序。

#### ⚡ 改进

- macOS 统一菜单、输入框、树列表、工具栏与滚动条样式，更新界面和代码字体。
- macOS Git Log 改善面板拖动与分支引用显示，分支菜单支持分组折叠和直接输入搜索。
- macOS 差异视图改善单栏与双栏切换、文本选择、差异导航、滚动同步及面板收起。
- macOS 底部工具窗口横跨工作区，收起侧栏后可从活动栏恢复原宽度。
- macOS 通知支持长文展开和历史查看，悬停或切到后台时暂停自动关闭计时。
- macOS 终端沿用系统 Terminal 默认配色，关闭最后一个底部终端时自动收起面板。
- macOS Agent 回复期间可预选下一轮的模型、审批模式和思考强度。
- macOS 检查更新和背景选择入口移至右侧活动栏底部。

#### 🛠 修复

- Java 导入不会再因 45 秒没有进度更新就被中止，仍保留 10 分钟总等待上限。
- Windows Ctrl+点击在临时失败或服务重连后重新查询，避免一直无法跳转或使用旧位置。
- Maven 子模块可识别从项目内父模块继承的构建插件，改善 Spring Boot 服务识别。
- macOS 关闭文档后的迟到请求不再误报同步失败、锁住其他打开文件。
- macOS Agent 区分等待响应、重试和工具执行，避免持续误显示“思考中”。
- macOS 修复中文组词时占位文字重叠、编辑器右键剪贴板操作及标签拖放边界问题。
- macOS 修复差异块颜色、连接线错位，以及横纵滚动条拖动失效的问题。

### 升级说明

- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。

### 兼容性与已知问题

- macOS 需要 13 或更高版本，提供 Apple Silicon 和 Intel 安装包；Windows 提供 x64 安装包。
- macOS 安装包尚无 Developer ID 签名和公证，Windows 安装包尚无 Authenticode 签名；自动更新使用独立的更新签名。
- Agent 对话与本次审阅、预选配置交互目前仅在 macOS 提供；原始内容不完整或文件已被另行修改时，自动回撤可能被拒绝。
- Java 修复针对已确认的等待和缓存缺陷；#1051、#1052 原项目的 Windows 实机效果仍待确认，不代表所有 Maven 导入问题均已解决。
- 部分 macOS 界面和更新安装流程仍待完整实机验收；差异视图的词内高亮尚不能细分所有离散修改片段。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

### Highlights

This release clarifies project preparation, code review, and Agent activity while improving everyday editing interactions.

#### ✨ New features

- macOS Agent activity expands into task and tool details, file diffs, and actions to keep or revert edits.
- macOS Git history diffs open in editor tabs that can be switched, closed, and reordered alongside ordinary files.

#### ⚡ Improvements

- macOS unifies menus, inputs, trees, toolbars, and scrollbars, with updated interface and code fonts.
- macOS Git Log improves panel resizing and branch references; branch menus support collapsible groups and type-to-search.
- macOS diffs improve unified and split views, text selection, change navigation, synchronized scrolling, and pane collapsing.
- macOS bottom tool windows span the workbench; collapsed sidebars restore their width from the activity bar.
- macOS notifications support expanded text and history, pausing dismissal timers on hover or while the app is in the background.
- macOS terminals use the system Terminal default colors and collapse the bottom panel when its last terminal closes.
- macOS Agent lets you preselect the next turn's model, approval mode, and reasoning effort during a response.
- macOS update checks and background selection move to the bottom of the right activity bar.

#### 🛠 Fixes

- Java imports no longer stop after 45 seconds without progress updates; the 10-minute overall limit remains.
- Windows Ctrl-click queries again after temporary failures or reconnection, avoiding persistent misses and stale navigation targets.
- Maven submodules recognize build plugins inherited from parent modules within the project, improving Spring Boot service detection.
- macOS ignores stale requests after document closure instead of reporting synchronization failure and locking other open files.
- macOS Agent distinguishes waiting, retries, and tool execution instead of continuously showing “Thinking.”
- macOS fixes overlapping placeholders during Chinese composition, editor context-menu clipboard actions, and tab drag boundaries.
- macOS fixes diff block colors, misaligned connectors, and unresponsive horizontal and vertical scrollbar dragging.

### Upgrade instructions

- macOS: open the DMG for your architecture and drag Lithe.app to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.

### Compatibility and known issues

- macOS requires version 13 or later, with Apple Silicon and Intel installers; Windows installers target x64.
- macOS installers lack Developer ID signing and notarization, and Windows installers lack Authenticode signing; automatic updates use separate update signatures.
- Agent conversations, edit review, and next-turn configuration are currently macOS-only; rollback may be refused when original content is incomplete or files changed independently.
- Java changes address confirmed waiting and caching defects. Windows verification on the original projects from #1051 and #1052 remains pending; not every Maven import problem is resolved.
- Some macOS appearance and update-installation workflows still await full runtime verification; word-level diffs do not separate every disjoint edit.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
