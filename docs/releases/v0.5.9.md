Lithe 0.5.9 新增 Agent 项目操作与 Java 服务代码更新，并改善 macOS Agent 对话和 PHP 插件管理。

### 重点更新

本次更新内容如下。

#### ✨ 新功能

- 两端新增 MCP 配置，授权外部 Agent 查询或配置项目环境、操作 Maven、运行项目并读取输出。
- 两端 Java 调试支持应用代码更改，使用 Spring Boot DevTools 的运行服务可手动编译更新。

#### ⚡ 改进

- macOS Agent 相邻工具调用合并为可展开的时间线，支持搜索调用内容和文件路径。
- macOS Agent 显示每轮耗时，以及 Agent 实际上报的输入、输出 token 用量。
- macOS PHP 支持改为可选插件，插件管理负责安装、重装和卸载，LSP 控制中心管理项目开关。

### 升级说明

- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。

### 兼容性与已知问题

- macOS 需要 13 或更高版本；提供 Apple Silicon、Intel 和 Windows x64 安装包。
- macOS 安装包未使用 Developer ID 签名或公证，Windows 安装包无 Authenticode 发布者签名；应用更新使用独立签名校验。
- 本版不预装 PHP 插件，且因未配置 Developer ID，不提供在线安装所需的插件下载包；PHP 语言功能需另行安装兼容插件及 Node.js。
- MCP 按项目授权，配置与执行权限默认关闭，关闭项目后需重新启用。
- Java 更新仅覆盖受支持的本地服务；JVM 不支持的结构修改需重启，DevTools 项目配置触发文件时仍需更新该文件。
- MCP 与 Java 服务更新的双端原生端到端验收仍待完成；Agent 时间线与统计界面目前仅在 macOS 提供，用量取决于 Agent 上报。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

Lithe 0.5.9 adds Agent-driven project operations and Java service updates, and improves macOS Agent conversations and PHP plugin management.

### Highlights

Changes are grouped below.

#### ✨ New features

- Both platforms add MCP settings to authorize external Agents to inspect or configure environments, operate Maven, run projects, and read output.
- Both platforms can apply Java code changes during debugging and manually build running services that use Spring Boot DevTools.

#### ⚡ Improvements

- macOS groups adjacent Agent tool calls into expandable timelines, with searchable call content and file paths.
- macOS shows elapsed time per Agent turn and input/output token counts when reported by the Agent.
- macOS PHP support becomes optional, with installation, reinstallation, and removal in Plugin Management and project switches in LSP Control Center.

### Upgrade instructions

- macOS: open the DMG for your architecture and drag Lithe.app to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.

### Compatibility and known issues

- macOS requires version 13 or later; installers are available for Apple Silicon, Intel, and Windows x64.
- macOS packages are not Developer ID signed or notarized, and Windows installers lack an Authenticode publisher signature; app updates use separate signature verification.
- PHP is no longer bundled, and this release provides no plugin download for online installation because Developer ID is not configured; PHP language features require a separately installed compatible plugin and Node.js.
- MCP authorization is per project, configuration and execution permissions default to off, and closing a project requires enabling access again.
- Java updates cover supported local services only; unsupported structural changes require a restart, and DevTools projects using a trigger file still need that file updated.
- Native end-to-end acceptance for MCP and Java service updates remains pending on both platforms; Agent timelines and statistics are macOS-only, and usage depends on Agent reporting.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
