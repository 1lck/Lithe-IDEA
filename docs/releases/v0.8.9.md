### 重点更新

本次更新让搜索更完整、结果更清楚，并让构建和编辑操作更方便。

#### ✨ 新功能

- 项目搜索支持分页、按文件分组折叠、完整匹配计数和未保存内容。
- 搜索支持项目、模块、目录和自定义范围，可临时包含忽略文件、生成目录及项目内符号链接。
- 随处搜索支持空格分词、路径缩写、通配符和文件名后接行号，“全部”同时显示文本结果。
- “类型”和“符号”按需启动语言服务，无需先打开文件；搜索与替换文件大小可在设置中调整。
- 编辑器显示代码操作、参数信息和内联提示，补全候选完整展示名称与签名。
- 构建窗口显示插件声明的快捷开关、运行环境和翻译后的选项，并可浏览路径及覆盖工具实际值。
- 插件工具链提供方可参与版本和安装解析，受管运行环境按需准备，测试发现可使用声明的命令。
- 打开项目时先确认工作区信任，并识别可运行的启动类。

#### ⚡ 改进

- 项目搜索首屏不再等待完整内容索引，完整计数在后台完成。
- 搜索统一字体、压缩结果行距、对齐行列号，并在文件名旁显示匹配数。
- 搜索与编辑器统一处理非 UTF-8 文本；替换保留原编码、BOM 和换行符。
- 构建选项提供说明与路径覆盖提示，插件不再提供的旧选项会明确提醒。

#### 🛠 修复

- 修复紧凑搜索列表大幅滚动到底部时出现空白的问题。
- 修复插件画布宽度不准确，以及窗口调整大小后未通知插件的问题。
- 修复在非仓库目录中查询根 Git 引用引起的错误。

### 升级说明

- 已安装版本可从标题栏更新入口或“设置 → 关于”检查更新；也可下载完整安装包。
- macOS：打开对应芯片的 DMG，将 `Lithe Desktop.app` 拖入“应用程序”。
- Homebrew：配方更新后运行 `brew update && brew upgrade --cask lithe`。
- Windows：运行 x64 安装程序；Windows 0.8.0 用户需要手动下载安装。
- Linux：全部下载文件中提供 x64、ARM64 的 DEB、RPM 和 tar.gz。

### 兼容性与已知问题

- macOS 最低 13.0；Windows 提供 x64 包；Linux 需要兼容的运行库和图形环境。
- 类型与符号结果依赖已安装、已启用且支持工作区符号查询的语言服务。
- 符号链接只跟随当前项目内部目标，跳过循环和外部目标；手动排除目录仍生效。
- Windows 搜索原生窗口未在本机验收；功能矩阵保留待验证状态。
- 本次按发布安排保留现有 Viva 基线，只加入列表滚动修复，未纳入待同步的 65 个上游提交。
- macOS 使用临时签名且未公证，Windows 安装包没有发行者签名，系统可能显示安全提示。

如果 macOS 提示无法打开 `Lithe Desktop.app`，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可执行 `xattr -dr com.apple.quarantine "/Applications/Lithe Desktop.app"`。旧版 `Lithe.app` 使用 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

### Highlights

This release makes search more complete and readable, and simplifies build and editing workflows.

#### ✨ New features

- Project search supports pagination, collapsible file groups, complete match counts and unsaved content.
- Search project, module, directory or custom scopes, optionally including ignored files, generated directories and internal symbolic links.
- Search Everywhere supports space-separated words, abbreviated paths, wildcards and filename line suffixes; All also includes text results.
- Types and Symbols start language services on demand, without opening files first; search and replacement file limits are configurable.
- The editor shows code actions, parameter information and inline hints, plus full completion names and signatures.
- Build windows show plugin switches, execution environments and translated options, with path browsing and explicit overrides of actual tool values.
- Plugin toolchain providers participate in version and installation resolution; managed runtimes prepare on demand and declared commands can discover tests.
- Opening a project confirms workspace trust and discovers runnable entry classes.

#### ⚡ Improvements

- Project search shows its first page without waiting for a full content index; complete counts finish in the background.
- Search uses consistent fonts, compact rows, aligned line positions and match counts beside filenames.
- Search and the editor handle non-UTF-8 text consistently; replacement preserves encoding, BOM and line endings.
- Build options include explanations and path override guidance, and warn when plugins no longer provide saved options.

#### 🛠 Fixes

- Fixed blank results after scrolling compact search lists to the end in a large wheel movement.
- Fixed inaccurate plugin canvas widths and missing resize notifications after window size changes.
- Fixed root Git reference queries in folders outside a repository.

### Upgrade instructions

- Check for updates from the title bar or Settings → About, or download a full package.
- macOS: open the DMG for your processor and drag `Lithe Desktop.app` to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` once the cask update is available.
- Windows: run the x64 installer; Windows 0.8.0 users must download and install manually.
- Linux: All downloads includes DEB, RPM and tar.gz packages for x64 and ARM64.

### Compatibility and known issues

- macOS requires 13.0 or newer; Windows packages target x64; Linux requires compatible libraries and a graphical environment.
- Type and symbol results require an installed, enabled language service that supports workspace symbol queries.
- Symbolic links follow targets inside the current project only, skipping cycles and external targets; manual exclusions still apply.
- Native Windows search windows were not verified locally; the feature matrix retains pending verification.
- This release retains the existing Viva baseline with the list scrolling fix; 65 upstream commits awaiting synchronization are excluded.
- macOS packages use ad hoc signing without notarization; Windows installers have no publisher signature and may trigger system prompts.

If macOS cannot open `Lithe Desktop.app`, Control-click it in Applications and choose Open. If it remains blocked, run `xattr -dr com.apple.quarantine "/Applications/Lithe Desktop.app"`. For the older `Lithe.app`, use `xattr -dr com.apple.quarantine /Applications/Lithe.app`. Use these commands only for an app from a source you trust.
