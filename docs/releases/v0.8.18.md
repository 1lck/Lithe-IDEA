## 中文

Lithe Desktop 0.8.18 让被省略的文字悬停即可看到全文，单文件模式支持预览 HTML 和 SVG，新增 Git 推送、拉取等快捷键，并修复 Windows 构建闪窗、SSH 远程连接失败等问题。

- [macOS Apple Silicon DMG](https://github.com/1lck/Lithe-IDEA/releases/download/desktop-v0.8.18/lithe-0.8.18-darwin-arm64.dmg)
- [macOS Intel DMG](https://github.com/1lck/Lithe-IDEA/releases/download/desktop-v0.8.18/lithe-0.8.18-darwin-amd64.dmg)
- [Windows x64 安装程序](https://github.com/1lck/Lithe-IDEA/releases/download/desktop-v0.8.18/lithe-0.8.18-windows-amd64-setup.exe)

### 重点更新

本次更新改进长文字和预览的显示，补齐 Git 快捷键和构建工具设置入口，并集中修复项目树移动文件、Diff 自动保存和 Windows 上的多个问题。

#### ✨ 新功能

- 日志、输入框、工具链路径、Git 提交信息、状态栏文件名和信任对话框路径等处被「…」省略的文字，悬停即可看到全文；下拉选择框过长时也改为显示「…」，不再直接截断。
- 单文件模式下可以预览 HTML 和 SVG 文件。SVG 预览新增「交互模式」开关，开启后支持悬停、点击、链接和脚本交互，并随源码修改实时刷新。
- 「设置」的构建工具页列出项目中识别到的构建实例，嵌套的实例显示相对目录，点击即可打开对应工作区的选项。
- 快捷键设置新增 Git 推送、拉取、获取和更新项目。推送默认 `⌘⇧K`（Windows/Linux 为 `Ctrl+Shift+K`），更新项目默认 `⌘T`（Windows/Linux 为 `Ctrl+T`），四项都可以自定义。
- 插件可以为编辑器中的一段文字指定前景色，与主题、语法和语义高亮一起显示。

#### ⚡ 改进

- 同时弹出的多条通知折叠成一叠，鼠标悬停时展开。
- 设置中只读的输入框可以获得焦点，能选中并复制其中的内容。
- 构建窗口顶部的齿轮按钮改名为「忽略路径」；构建系统的齿轮按钮、右键菜单、对话框标题和设置链接统一称为「{名称} 工作区选项」。
- 中文界面把 Git 的 Stash 从「暂存」改称「贮藏」，避免与暂存区混淆；贮藏列表为空时显示「暂无贮藏」。
- 文件关联批量应用时，单项失败不再中断其余项目；新增「Lithe 状态」列，显示未注册、已注册候选或已是默认，设置窗口重新激活时会重新读取状态。Windows 上只打开一次「默认应用」设置页。
- 工具链探测失败会写入日志，便于排查，不再静默忽略。

#### 🛠 修复

- 在项目树中剪切或移动目录后，已打开的标签页会跟随到新路径；重新创建文件时会补建缺失的上级目录；文件被删除的提示条新增「丢弃并关闭」。[#2405](https://github.com/1lck/Lithe-IDEA/issues/2405)
- 打开未跟踪文件的 Diff 后，自动保存不再每次在末尾追加空行。[#2377](https://github.com/1lck/Lithe-IDEA/issues/2377)
- Windows 上构建、运行、测试和调试时不再闪出控制台窗口。[#2402](https://github.com/1lck/Lithe-IDEA/issues/2402)
- Windows 上通过 SSH 连接远程主机时，不再因日志文件出现「Broken pipe」而失败。
- Windows 设置中的「选择…」按钮（SSH 程序、可信位置、工具链目录）不再报错。
- 在同一窗口打开的第二个项目可以正常加载插件网页以及 Markdown 和网页预览。[#2394](https://github.com/1lck/Lithe-IDEA/issues/2394)
- 只声明任务、没有提供项目模型的构建插件，其任务会列在构建窗口中，不再显示模型加载错误。
- 在 Git 控制台中搜索跳转时，目标行在第一帧就会绘制出来。

### 升级说明

- 可从标题栏的更新入口或「设置 → 关于」检查更新，也可以下载完整安装包。
- macOS 用户打开对应架构的 DMG，将 `Lithe Desktop.app` 拖入「应用程序」。
- Homebrew 配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows 用户运行 x64 安装程序，从 Windows 0.8.0 升级时请手动下载安装。
- Linux 用户可以用一行命令安装，也可以在全部下载文件中选 x64、ARM64 的 DEB、RPM 和 tar.gz。

### 兼容性与已知问题

- macOS 最低要求 13.0。Windows 提供 x64 安装包，Linux 需要兼容的运行库和图形环境。
- macOS 安装包使用临时签名，Windows 安装包无发行者签名。系统可能显示安全提示。
- Windows 上勾选文件关联后，需要在系统打开的「默认应用」设置中确认；Windows 11 的右键菜单项可能在「显示更多选项」里。
- 远程开发只支持 x86_64 和 arm64 的 Linux 主机。SSH 连接使用本机的 OpenSSH，WSL 只能在 Windows 上使用，Dev Container 需要本机安装 Dev Container CLI，且只能在本机构建。[#2231](https://github.com/1lck/Lithe-IDEA/issues/2231)
- 远程工作区暂不启动语言服务器，调试、测试、构建工具以及插件提供的运行配置和执行前任务暂不可用，「在新窗口打开」和「在文件浏览器中显示」也暂不可用。[#2231](https://github.com/1lck/Lithe-IDEA/issues/2231)
- 远程 Git 推送和拉取时的凭据询问暂不显示在窗口中，仓库根目录位于所打开文件夹上级时暂不支持。
- Windows 首次导入 Gradle 项目时，如果 Wrapper 尚未下载且探测超时，可在项目目录运行 `gradlew.bat --version` 等待下载完成，再回到 Lithe 重试。
- 以 `build.xml` 为根的 Apache Ant 工程仍有项目导入、调试和源码跳转缺口。[#1761](https://github.com/1lck/Lithe-IDEA/issues/1761)

如果 macOS 提示无法打开 `Lithe Desktop.app`，请在「应用程序」中按住 Control 点按应用并选择「打开」。如果仍被阻止，可执行 `xattr -dr com.apple.quarantine "/Applications/Lithe Desktop.app"`。旧版 `Lithe.app` 使用 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

## English

Lithe Desktop 0.8.18 shows the full text of truncated labels on hover, previews HTML and SVG files in single-file mode, adds shortcuts for Git push, pull, and more, and fixes console flashes during Windows builds and failing SSH remote connections on Windows.

### Highlights

This release improves how long text and previews are shown, adds Git shortcuts and build tool settings entries, and fixes moving files in the project tree, Diff autosave, and several Windows issues.

#### ✨ New features

- Text truncated with "…" in logs, fields, toolchain paths, Git commit messages, status bar file names, and trust dialog paths shows in full when you hover over it. Long values in dropdowns now end with "…" instead of being cut off.
- Single-file mode previews HTML and SVG files. The SVG preview adds an Interactive mode switch that enables hover, clicks, links, and scripts and refreshes as you edit the source.
- The build tool pages in Settings list the build instances found in the project, show nested ones with their relative directory, and open that workspace's options when you click one.
- The keymap adds Git Push, Pull, Fetch, and Update Project. Push defaults to `⌘⇧K` (`Ctrl+Shift+K` on Windows and Linux) and Update Project to `⌘T` (`Ctrl+T` on Windows and Linux). You can change all four.
- Plugins can set a foreground color for a range of editor text, shown together with theme, syntax, and semantic highlighting.

#### ⚡ Improvements

- Notifications that appear at the same time fold into a stack that expands when you hover over it.
- Read-only fields in Settings can take focus, so you can select and copy their contents.
- The gear at the top of the Build window is now named Ignored Paths. The build system gear, context menu, dialog title, and settings link all use "{name} workspace options".
- The Chinese interface now calls Git Stash 「贮藏」 instead of 「暂存」 so it no longer clashes with staging, and an empty stash list shows 「暂无贮藏」.
- Applying file associations in bulk continues past a single failure. A new Lithe status column shows Not registered, Candidate registered, or Default confirmed for each type, and the status is read again when the Settings window becomes active. On Windows the Default apps page opens only once.
- Toolchain discovery failures are written to the log for troubleshooting instead of being ignored.

#### 🛠 Fixes

- After you cut or move a directory in the project tree, open tabs follow the new path. Recreating a file creates any missing parent folders, and the deleted-file banner adds Discard and Close. [#2405](https://github.com/1lck/Lithe-IDEA/issues/2405)
- After you open a Diff of an untracked file, autosave no longer appends a blank line each time. [#2377](https://github.com/1lck/Lithe-IDEA/issues/2377)
- On Windows, building, running, testing, and debugging no longer flash a console window. [#2402](https://github.com/1lck/Lithe-IDEA/issues/2402)
- On Windows, SSH connections to remote hosts no longer fail with "Broken pipe" on the log file.
- On Windows, the Choose… buttons in Settings (SSH program, trusted locations, toolchain directory) no longer show an error.
- A second project opened in the same window loads plugin web pages and Markdown and web previews. [#2394](https://github.com/1lck/Lithe-IDEA/issues/2394)
- Build plugins that declare tasks without a project model list those tasks in the Build window instead of showing a model loading error.
- Jumping to a search result in the Git console draws the target line in the first frame.

### Upgrade instructions

- Check for updates from the title bar or Settings → About, or download a full installer.
- On macOS, open the DMG for your architecture and drag `Lithe Desktop.app` to Applications.
- With Homebrew, run `brew update && brew upgrade --cask lithe` after the cask update is available.
- On Windows, run the x64 installer. Upgrading from Windows 0.8.0 needs a manual download.
- On Linux, use the one-line install, or pick a DEB, RPM, or tar.gz for x64 or ARM64 from the downloads.

### Compatibility and known issues

- macOS requires 13.0 or newer. Windows packages target x64. Linux requires compatible libraries and a graphical environment.
- macOS packages use ad hoc signing. Windows installers have no publisher signature. Your system may show security prompts.
- On Windows, after you tick file associations, confirm them in the Default apps settings that Windows opens. On Windows 11 the context menu entry may be under Show more options.
- Remote development supports x86_64 and arm64 Linux hosts only. SSH connections use the OpenSSH on your computer, WSL is available only on Windows, and Dev Containers need the Dev Container CLI installed on your computer and build only there. [#2231](https://github.com/1lck/Lithe-IDEA/issues/2231)
- Remote workspaces do not start language servers yet. Debugging, tests, build tools, and plugin-provided run configurations and before-launch tasks are not available yet, and neither are Open in New Window and Reveal in File Manager. [#2231](https://github.com/1lck/Lithe-IDEA/issues/2231)
- Credential prompts from remote Git push and pull are not shown in the window yet, and repositories whose root is above the opened folder are not supported yet.
- On Windows, a Gradle project can time out during its first import if its Wrapper distribution still needs to download. Run `gradlew.bat --version` in the project directory, wait for it to finish, and retry in Lithe.
- Apache Ant projects rooted at `build.xml` still have gaps in project import, debugging, and source navigation. [#1761](https://github.com/1lck/Lithe-IDEA/issues/1761)

If macOS cannot open `Lithe Desktop.app`, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine "/Applications/Lithe Desktop.app"` in Terminal. For the older `Lithe.app`, use `xattr -dr com.apple.quarantine /Applications/Lithe.app`. Use these commands only for an app from a source you trust.
