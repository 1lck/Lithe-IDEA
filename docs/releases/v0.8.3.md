### 重点更新

本次重点是语言服务故障提示，以及插件市场与 Git Log 的日常使用修复。

#### ✨ 新功能

- 语言服务器启动失败或意外退出时弹出错误通知，并在状态栏显示“LSP 出错”。
- 通过“LSP 出错”菜单可查看原因和日志并重启，保存工具链设置后会自动重试。

#### 🛠 修复

- 设置中的插件市场加载失败或部分源不可用时，直接显示具体错误原因。
- 删除或重命名分支、删除标签后，Git Log 会自动清除或同步更新对应的筛选和对比目标。

### 升级说明

- 已安装 0.8.2：在标题栏的更新入口或“设置 → 更新”中检查更新，即可在应用内更新到本版；0.8.1 在 Windows 上会下载完整安装包。
- Windows 0.8.0 无法在应用内完成更新，请下载本版安装程序手动安装。
- macOS：也可选择对应芯片的 DMG，将 `Lithe Desktop.app` 拖入“应用程序”。
- Homebrew：配方更新到本版后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：运行 x64 安装程序，或将 ZIP 解压到独立目录后运行 `lithe.exe`。
- Linux：使用对应架构的 DEB/RPM；tar.gz 用户需要自行满足运行库要求。

### 兼容性与已知问题

- macOS 最低为 13.0，分别提供 Apple Silicon 和 Intel 包；Windows 桌面端提供 x64 包。
- Linux 提供 x64 和 ARM64 包，需要兼容的运行库和图形环境，未验证所有发行版。
- 自动生成运行配置、隐藏 `target`、`node_modules` 等目录需要启用对应的语言或构建插件。
- 新客户端的功能迁移仍在进行，部分旧版功能尚未完全对齐。
- macOS 使用临时签名且未公证，Windows 安装包没有发行者签名，系统可能显示安全提示。

如果 macOS 提示无法打开 `Lithe Desktop.app`，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可执行 `xattr -dr com.apple.quarantine "/Applications/Lithe Desktop.app"`。旧版 `Lithe.app` 对应命令是 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

### Highlights

This release focuses on language server failure feedback and fixes for the plugin marketplace and Git Log.

#### ✨ New features

- Language servers that fail to start or exit early now show an error notification and "LSP failed" in the status bar.
- From the "LSP failed" menu, view the reason and logs or restart the server; saving toolchain settings retries automatically.

#### 🛠 Fixes

- Settings now show the underlying error when loading the plugin marketplace or one of its sources fails.
- Deleting or renaming a branch or deleting a tag now clears or updates the matching Git Log filter and compare target.

### Upgrade instructions

- From 0.8.2: check for updates from the title-bar update entry or Settings → Updates to update in-app; Windows 0.8.1 downloads the full installer.
- Windows 0.8.0 cannot finish an in-app update; download and run this release's installer instead.
- macOS: or open the DMG for your processor and drag `Lithe Desktop.app` to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask is updated to this release.
- Windows: run the x64 installer, or extract the ZIP into its own directory and run `lithe.exe`.
- Linux: use the DEB/RPM for your architecture; tar.gz users must provide the required runtime libraries.

### Compatibility and known issues

- macOS requires 13.0 or newer, with separate Apple Silicon and Intel packages; the Windows desktop package targets x64.
- Linux packages target x64 and ARM64, requiring compatible libraries and a graphical environment; not every distribution is verified.
- Generated run configurations and hiding folders such as `target` and `node_modules` need the matching language or build plugin enabled.
- Feature migration continues; some features of the older client are not yet at full parity.
- macOS packages use ad hoc signing without notarization; Windows installers have no publisher signature and may trigger system prompts.

If macOS cannot open `Lithe Desktop.app`, Control-click it in Applications and choose Open. If it remains blocked, run `xattr -dr com.apple.quarantine "/Applications/Lithe Desktop.app"`. For the older `Lithe.app`, use `xattr -dr com.apple.quarantine /Applications/Lithe.app`. Use these commands only for an app from a source you trust.
