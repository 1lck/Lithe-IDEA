## 中文

Lithe 0.3.1 汇集了近期的稳定性、性能和工作区体验改进，并首次在正式 Release 中提供 Windows x64 预览版安装程序。

### 下载

- **项目主页：** [Lithe IDEA](https://github.com/1lck/Lithe-IDEA)
- **macOS Apple Silicon：** [下载 DMG](https://github.com/1lck/Lithe-IDEA/releases/download/v0.3.1/Lithe-0.3.1-arm64.dmg)
- **macOS Intel：** [下载 DMG](https://github.com/1lck/Lithe-IDEA/releases/download/v0.3.1/Lithe-0.3.1-x86_64.dmg)
- **Windows x64（预览版）：** [下载安装程序](https://github.com/1lck/Lithe-IDEA/releases/download/v0.3.1/Lithe-0.3.1-windows-x64.exe)
- **全部下载：** [查看 Release Assets](https://github.com/1lck/Lithe-IDEA/releases/tag/v0.3.1)

> Windows 版本目前处于预览阶段。安装程序在未配置 Authenticode 证书时可能没有数字签名，Windows 可能会显示安全提示。

### 重点更新

- 提供 Windows x64 预览版，包含 React/Tauri 工作台、Java 运行与语言服务、Git 日志与差异查看，以及更完整的简体中文界面。
- 改进 macOS 文件打开、编辑器渲染和侧边栏刷新性能，减少大型项目中的重复工作与界面卡顿。
- 正式安装包内置 Eclipse JDT Language Server，并支持为 JDTLS 单独选择 JDK。

### 改进

- 增加项目标签页、项目切换和单文件编辑体验，并默认启用自动保存。
- 改进运行配置、项目级运行路径以及 Java、Maven 和 Spring Boot 工作流。
- 增加可配置的应用日志目录、进程内存状态和帧率监控。
- 改进 Windows Git Log、分栏差异、分支操作、合并与变基，以及拉取前检查。
- 优化 Windows 项目打开、紧凑目录、编辑器标签和工作台交互。

### 问题修复

- 修复 macOS 快速切换 Git、Changes 和 Pull Requests 视图时的刷新竞态。
- 修复 macOS 打开文件时可能出现的渲染延迟。
- 修复 Windows 深色模式下部分文字不可读的问题。
- 修复 Windows Git 视图滚动、分支菜单、标签检出和运行配置更新问题。
- 修复 Windows 后台控制台闪现、项目切换和新窗口恢复问题。

### 升级说明

- **macOS DMG：** 退出正在运行的 Lithe，打开对应架构的 DMG，然后将 Lithe 拖入“应用程序”并替换旧版本。
- **Homebrew：** 运行 `brew update && brew upgrade --cask lithe`。
- **Windows：** 退出正在运行的 Lithe，然后运行 Windows x64 安装程序并按提示完成安装。

### 兼容性与已知问题

- macOS 需要 macOS 13 或更高版本。
- Java 项目功能需要 JDK 17 或更高版本，推荐使用 JDK 17 或 JDK 21。
- macOS 和 Windows 正式安装包均包含 JDTLS，无需单独安装。
- Windows 版本仍处于预览阶段，部分平台能力和界面细节可能与 macOS 不完全一致。

查看 [v0.3.0 到 v0.3.1 的完整变更](https://github.com/1lck/Lithe-IDEA/compare/v0.3.0...v0.3.1)。

## English

Lithe 0.3.1 brings together recent stability, performance, and workspace improvements. It is also the first stable-channel Release to include a Windows x64 preview installer.

### Downloads

- **Project homepage:** [Lithe IDEA](https://github.com/1lck/Lithe-IDEA)
- **macOS Apple Silicon:** [Download DMG](https://github.com/1lck/Lithe-IDEA/releases/download/v0.3.1/Lithe-0.3.1-arm64.dmg)
- **macOS Intel:** [Download DMG](https://github.com/1lck/Lithe-IDEA/releases/download/v0.3.1/Lithe-0.3.1-x86_64.dmg)
- **Windows x64 preview:** [Download installer](https://github.com/1lck/Lithe-IDEA/releases/download/v0.3.1/Lithe-0.3.1-windows-x64.exe)
- **All downloads:** [View Release Assets](https://github.com/1lck/Lithe-IDEA/releases/tag/v0.3.1)

> The Windows build is currently a preview. If an Authenticode certificate is not configured, the installer may be unsigned and Windows may show a security warning.

### Highlights

- Added a Windows x64 preview with the React and Tauri workbench, Java run and language tooling, Git log and diff views, and broader Simplified Chinese coverage.
- Improved file opening, editor rendering, and sidebar refresh performance on macOS to reduce redundant work and interface stalls in larger projects.
- Bundled Eclipse JDT Language Server in release packages and added an independent JDK selection for JDTLS.

### Improvements

- Added project tabs, project switching, and standalone file editing, and enabled auto-save by default.
- Improved run configurations, project-scoped run paths, and Java, Maven, and Spring Boot workflows.
- Added configurable application log directories, process memory status, and frame-rate monitoring.
- Improved Git Log, split diffs, branch actions, merge and rebase flows, and pull preflight checks on Windows.
- Refined project opening, compact folders, editor tabs, and workbench interactions on Windows.

### Bug fixes

- Fixed refresh races when rapidly switching between Git, Changes, and Pull Requests views on macOS.
- Fixed rendering delays that could occur while opening files on macOS.
- Fixed unreadable text in parts of the Windows dark theme.
- Fixed Windows Git scrolling, branch menus, tag checkout, and run configuration updates.
- Fixed background console flashes, project switching, and new-window recovery on Windows.

### Upgrade instructions

- **macOS DMG:** Quit Lithe, open the DMG for your Mac architecture, and replace the existing application in the Applications folder.
- **Homebrew:** Run `brew update && brew upgrade --cask lithe`.
- **Windows:** Quit Lithe, run the Windows x64 installer, and follow the installation prompts.

### Compatibility and known issues

- macOS requires macOS 13 or later.
- Java project features require JDK 17 or newer. JDK 17 or JDK 21 is recommended.
- Release packages for macOS and Windows include JDTLS, so it does not need to be installed separately.
- The Windows build remains a preview, and some platform capabilities and interface details may differ from macOS.
