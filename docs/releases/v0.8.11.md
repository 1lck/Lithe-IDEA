### 重点更新

本次更新重点提升运行可观测性、项目初始化引导、命令行工作流与分支管理安全性。

#### ✨ 新功能

- 支持在设置中手动注册 `lithe` 命令行，打开文件时启动带终端且不激活工作区插件的独立编辑窗口。
- 打开工作区时按项目特征自动检测并通过通知推荐尚未安装的相关插件。
- 运行窗口工具栏实时显示当前服务进程树监听的 TCP 端口（如 Spring Boot 应用端口）。

#### ⚡ 改进

- 编辑器动作与测试启动补充即时状态和失败提示，避免点击触发无响应时缺少反馈。
- Git 分支删除遇到未完全合并的本地分支时提供独立二次确认强制删除，批量删除逐项保留混合结果并标红展示失败分支原因。
- 同步 Viva 图形框架到最新上游基线（`39376802`），涵盖焦点陷阱滚轮屏蔽、macOS 文档 URL 处理、Windows 唤醒调度、文件拖出及控件测量修复。

#### 🛠 修复

- 修复文件树首次追加多选时丢失原行以及多选底色仅高亮单行的问题。

### 升级说明

- 已安装版本可从标题栏更新入口或“设置 → 关于”检查更新；也可下载完整安装包。
- macOS：打开对应芯片的 DMG，将 `Lithe Desktop.app` 拖入“应用程序”。
- Homebrew：配方更新后运行 `brew update && brew upgrade --cask lithe`。
- Windows：运行 x64 安装程序；Windows 0.8.0 用户需要手动下载安装。
- Linux：全部下载文件中提供 x64、ARM64 的 DEB、RPM 和 tar.gz。

### 兼容性与已知问题

- macOS 最低 13.0；Windows 提供 x64 包；Linux 需要兼容的运行库和图形环境。
- 部分依赖本机特定交互的 Windows 能力仍待在本机 Windows 环境进一步验收，功能矩阵按实保留待验证状态。
- macOS 使用临时签名且未公证，Windows 安装包没有发行者签名，系统可能显示安全提示。

如果 macOS 提示无法打开 `Lithe Desktop.app`，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可执行 `xattr -dr com.apple.quarantine "/Applications/Lithe Desktop.app"`。旧版 `Lithe.app` 使用 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

## English

Lithe Desktop 0.8.11 adds live listening TCP port display in the Run window, workspace plugin recommendation notifications, and opt-in CLI standalone file editing with terminal support, while improving Git branch deletion safety, fixing file-tree multi-selection, and syncing upstream Viva improvements.

### Highlights

This release improves runtime visibility, workspace plugin onboarding, CLI workflows, and Git branch safety.

#### ✨ New features

- Adds opt-in CLI registration in Settings and a standalone file-editing window with an integrated terminal when launched with a file path.
- Recommends installable workspace plugins through notifications based on detected project files and build configuration.
- Displays live listening TCP ports from the running process tree directly in the Run window.

#### ⚡ Improvements

- Improves editor action and test-launch status feedback when triggering actions fails or returns no runnable targets.
- Adds explicit secondary confirmation for force-deleting unmerged local branches and preserves per-branch mixed results with error highlighting in batch deletion.
- Synchronizes Viva with upstream commits (`39376802`), bringing focus-trap wheel blocking, macOS document URL and UTF-8 label fixes, Windows wake scheduling, file drag-out, and control measurement fixes.

#### 🛠 Fixes

- Fixes file-tree multi-selection dropping the initial row on range/additive selection and highlighting only a single selected row.

### Upgrade instructions

- Check for updates from the title bar or Settings → About, or download a full package.
- macOS: open the DMG for your processor and drag `Lithe Desktop.app` to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` once the cask update is available.
- Windows: run the x64 installer; Windows 0.8.0 users must download and install manually.
- Linux: All downloads includes DEB, RPM and tar.gz packages for x64 and ARM64.

### Compatibility and known issues

- macOS requires 13.0 or newer; Windows packages target x64; Linux requires compatible libraries and a graphical environment.
- Native Windows acceptance for recently shared workbench workflows remains pending in the feature matrix.
- macOS packages use ad hoc signing without notarization; Windows installers have no publisher signature and may trigger system prompts.

If macOS cannot open `Lithe Desktop.app`, Control-click it in Applications and choose Open. If it remains blocked, run `xattr -dr com.apple.quarantine "/Applications/Lithe Desktop.app"`. For the older `Lithe.app`, use `xattr -dr com.apple.quarantine /Applications/Lithe.app`. Use these commands only for an app from a source you trust.
