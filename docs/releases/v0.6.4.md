### 重点更新

本次更新内容如下。

#### ✨ 新功能

- macOS 重新设计设置界面，插件可注册语言和构建工具设置页。
- macOS 插件设置支持项目级覆盖，并提示各项设置的生效方式。
- macOS 可从编辑器行号右键菜单开启或隐藏 Git Blame。
- Windows 终端支持扩展按键，兼容的终端程序可用 Shift+Enter 换行。
- 插件开发者可使用官方 Java 后端 SDK。

#### ⚡ 改进

- macOS 优化项目树展开速度、图标与交互，改进全局搜索的名称匹配和只读预览。
- macOS 设置提供工作台背景预览，Git 设置集中到同一页面。
- Windows Git Log 改进分支创建、文本与分支筛选、删除后的恢复操作。
- Windows 改进最近项目管理、项目菜单和右键菜单定位。
- Windows 提交文件树采用自然排序，编辑器和 Notebook 使用更细的圆角滚动条。
- Windows 从文件夹打开终端时统一使用底部面板，隐藏全屏终端后会话继续保持。
- 工具链设置更明确地区分当前项目与全局作用范围。
- 构建插件可获得刷新请求和当前宿主解析出的构建工具。

#### 🛠 修复

- 修复 Agent 多项目入口指向错误项目、历史活动时间不准和历史加载延迟。
- macOS 修复设置窗口 OK/Cancel 偶发失效及设置页导致的发布构建失败。
- macOS 修复浅色终端文字白边，改进退出时后台服务的选择与停止处理。
- macOS 启动时模块激活被打断后不再弹出取消通知。
- 修复插件市场无法显示部分远程图标的问题。
- Windows 差异块回退遵循“放弃前确认”，避免确认期间目标变化后误改文件。
- Windows 修复 MCP 打开窗口时的归属字段，并改进 WSL 自定义挂载根下的路径转换。
- 编辑器、Notebook 和差异预览不再把中文全角标点标记为易混淆字符。

### 升级说明

- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。

### 兼容性与已知问题

- macOS 需要 13.0 或更高版本，提供 Apple Silicon 和 Intel 安装包；Windows 安装包面向 x64。
- macOS 使用临时签名，未提供 Developer ID 签名或公证；Windows 安装包未提供 Authenticode 签名。
- 两个平台的自动更新均使用独立签名验证。
- 插件注册设置页目前仅支持 macOS；Windows 尚未支持 settings 2 插件。
- 部分插件设置生效流程和 Windows 终端完整交互回归仍待实机验证。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

### Highlights

Changes are grouped below.

#### ✨ New features

- macOS redesigns settings and lets plugins register language and build-tool settings pages.
- macOS plugin settings support project overrides and explain when changes take effect.
- macOS adds Show/Hide Git Blame actions to the editor line-number context menu.
- Windows terminals support extended keys, allowing Shift+Enter newlines in compatible terminal applications.
- Plugin developers can use the official Java backend SDK.

#### ⚡ Improvements

- macOS improves project-tree expansion, icons, and interactions, plus global-search name matching and read-only previews.
- macOS settings add a workbench background preview and consolidate Git options into one page.
- Windows Git Log improves branch creation, text and branch filters, and recovery after branch deletion.
- Windows improves recent-project management, project menus, and context-menu positioning.
- Windows commit file trees use natural sorting; editors and Notebooks use slimmer rounded scrollbars.
- Windows folder terminals open in the shared bottom panel; hidden fullscreen terminals retain their sessions.
- Toolchain settings clarify project-local and global scope.
- Build plugins receive refresh requests and build tools resolved by the host.

#### 🛠 Fixes

- Fixes Agent entry points targeting the wrong project, inaccurate history activity times, and slow history loading.
- macOS fixes intermittent OK/Cancel failures and a settings-page compiler crash during release builds.
- macOS fixes bright terminal text fringes and improves background-service selection and shutdown when quitting.
- macOS no longer shows cancellation notifications for module activation interrupted during startup.
- Fixes missing remote icons in the plugin marketplace.
- Windows hunk rollback honors discard confirmation and avoids writes when the target changes while confirming.
- Windows fixes MCP window ownership and improves path conversion for custom WSL mount roots.
- Editors, Notebooks, and diff previews no longer flag Chinese full-width punctuation as ambiguous characters.

### Upgrade instructions

- macOS: open the DMG for your architecture and drag Lithe.app to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.

### Compatibility and known issues

- macOS requires 13.0 or later, with Apple Silicon and Intel installers; Windows installers target x64.
- macOS uses ad-hoc signing without Developer ID signing or notarization; Windows installers lack Authenticode signing.
- Both platforms use separate signatures for automatic updates.
- Plugin-registered settings pages are currently macOS-only; Windows does not yet support settings 2 plugins.
- Some plugin-settings activation workflows and full Windows terminal interaction regressions still await runtime verification.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
