## 中文

Lithe 0.5.6 为 macOS 带来 Agent 对话，完善双端多仓库提交，并补齐 Windows 开发设置与编辑体验。

### 下载

- [项目主页](https://github.com/1lck/Lithe-IDEA)
- [macOS Apple Silicon](https://github.com/1lck/Lithe-IDEA/releases/download/v0.5.6/Lithe-0.5.6-arm64.dmg)
- [macOS Intel](https://github.com/1lck/Lithe-IDEA/releases/download/v0.5.6/Lithe-0.5.6-x86_64.dmg)
- [Windows x64](https://github.com/1lck/Lithe-IDEA/releases/download/v0.5.6/Lithe-0.5.6-windows-x64.exe)
- [全部下载文件](https://github.com/1lck/Lithe-IDEA/releases/tag/v0.5.6)

### 重点更新

本次更新内容如下。

#### ✨ 新功能

- macOS 新增 Agent 侧栏，可使用 Codex、Claude 对话并引用项目文件。
- macOS 支持本机和自定义 Agent 供应商，以及 Codex 订阅登录与额度显示。
- macOS 可管理对话历史、查看上下文用量，并选择模型与权限。
- 双端支持一次提交多个仓库，按子模块依赖执行，并重试失败步骤。
- Windows 新增项目级 Maven 设置，可查看实际生效的配置路径。
- Windows 新增 Spring 接口搜索，可从接口列表跳转到源码。

#### ⚡ 改进

- 双端统一 Git 提交图布局与分支颜色，便于辨认分支关系。
- macOS 编辑器标签图标与项目树保持一致，并随文件变化刷新。

#### 🛠 修复

- macOS 修正部分输入法下触控板轻点后移动指针导致的意外选区。
- macOS 设置窗口不再始终覆盖其他窗口。
- macOS 修复 Agent 空会话重连，并保留禁用状态下的设置入口。
- Windows 修复重复打开项目时产生多余窗口的问题。
- Windows 恢复编辑器语义高亮与快捷键设置编辑。
- Windows 修复网络共享、扩展及特殊路径下的 Git 仓库识别。
- 双端修复首次提交前无法取消暂存及部分暂存文件预览不准确的问题。

### 升级说明

- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。

### 兼容性与已知问题

- macOS 需要 13 或更高版本；双端功能差异参见[功能矩阵](https://github.com/1lck/Lithe-IDEA/blob/v0.5.6/docs/development/platform-parity-matrix.md)。
- macOS 尚无 Developer ID 签名和公证，Windows 安装包尚无 Authenticode 发布者签名，系统可能提示安全警告。
- Agent 对话界面本版仅支持 macOS，需配置本机 CLI 与供应商；Claude 端到端使用和 Codex 真实订阅登录、额度仍待验证。
- 部分输入法的触控板轻点兼容修复仍待 macOS 实机验收，若仍异常可暂切系统输入法。
- 多仓库提交不提供整体回滚，成功步骤会保留，重试记录仅在当前工作区会话内有效。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

Lithe 0.5.6 adds Agent conversations on macOS, improves multi-repository commits on both platforms, and expands Windows development tools.

### Downloads

- [Project homepage](https://github.com/1lck/Lithe-IDEA)

### Highlights

Changes are grouped below.

#### ✨ New features

- macOS adds an Agent sidebar for Codex and Claude conversations with project file references.
- macOS supports local and custom Agent providers, plus Codex subscription login and quota display.
- macOS adds conversation history, context usage, and model and permission controls.
- Both platforms can commit across repositories, follow submodule dependencies, and retry failed steps.
- Windows adds project-level Maven settings with effective configuration paths.
- Windows adds Spring endpoint search with navigation to source code.

#### ⚡ Improvements

- Both platforms use consistent Git graph layouts and branch colors for easier navigation.
- macOS editor tab icons match the project tree and refresh after file changes.

#### 🛠 Fixes

- macOS corrects unintended selection when moving the pointer after trackpad taps with some input methods.
- macOS settings no longer stay above other windows.
- macOS fixes empty Agent session reconnection and keeps settings accessible while Agents are disabled.
- Windows reuses the existing window when reopening a project.
- Windows restores semantic highlighting and keyboard shortcut editing.
- Windows fixes Git repository identification for network shares, extended paths, and special paths.
- Both platforms fix unstaging before the first commit and inaccurate previews of partially staged files.

### Upgrade instructions

- macOS: open the DMG for your architecture and drag Lithe.app to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.

### Compatibility and known issues

- Requires macOS 13 or later; see the [feature matrix](https://github.com/1lck/Lithe-IDEA/blob/v0.5.6/docs/development/platform-parity-matrix.md) for platform differences.
- macOS lacks Developer ID signing and notarization; Windows installers lack Authenticode publisher signing, so system security warnings may appear.
- The Agent UI is macOS-only and requires local CLIs and provider setup; Claude end-to-end use and live Codex subscription login and quotas remain unverified.
- The input-method trackpad compatibility fix still needs macOS device verification; switch to a system input method if symptoms persist.
- Multi-repository commits have no overall rollback; successful steps remain, and retry records last only for the current workspace session.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
