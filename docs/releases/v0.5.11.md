### 重点更新

本次更新集中改善批量整理文件、Agent 协作和 Git 提交。

#### ✨ 新功能

- macOS 项目树支持 ⌘ 多选、Shift 范围选择，以及批量拷贝、粘贴、创建副本和移到废纸篓。
- macOS 项目树可与 Finder 互相拷贝粘贴文件，⌘A 按焦点所在位置选择同级项目。
- macOS Agent 对话可显示可折叠的思考内容和计划进度，并同步 Agent 切换后的权限模式。
- macOS Agent 输入框支持 `/` 命令和 Codex `$` 技能补全，小输入框也能展开可点击的候选列表。

#### ⚡ 改进

- macOS Agent 模型与权限菜单更紧凑，保留上游选项名称，并配合本地化说明和品牌图标。
- Windows Commit 面板区分更改与未跟踪文件，可切换目录和平铺视图，并显示已选文件的增删改数量。
- Windows 提交说明区支持拖动或键盘调整高度并记住设置，未选文件或未填说明时提供明确提示。
- Windows 活动栏、标题栏、运行面板图标及默认 Git 状态配色与 IntelliJ IDEA 风格对齐。
- 功能矩阵新增在线阅读与下载入口，方便查看 macOS 和 Windows 的实现及验证差异。

#### 🛠 修复

- macOS 修复 Claude API Key 配置在新建和恢复对话时的鉴权冲突。
- macOS 切换 Agent 会话时不再短暂显示旧模型，准备完成前阻止发送。
- macOS 权限菜单的双行说明不再被裁剪，搜索思考内容后可恢复原来的折叠状态。
- macOS 项目树快捷键不再同时作用于编辑器，批量删除会检查未保存修改并提示中途停止。
- Windows 提交面板缩小后仍可正常调整说明高度，提交查询失败可重试且不会被旧请求覆盖。

### 升级说明

- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。
- Windows 提交历史统一从 Git Log 查看，Commit 面板不再提供 History 标签。

### 兼容性与已知问题

- macOS 需要 13 或更高版本，提供 Apple Silicon 和 Intel 安装包；Windows 提供 x64 安装包。
- macOS 安装包尚无 Developer ID 签名和公证，Windows 安装包尚无 Authenticode 签名；自动更新使用独立的更新签名。
- Agent 对话界面目前仅在 macOS 提供；思考、计划和命令列表取决于所连接 Agent 的支持，补全的方向键与 Tab 操作需要 macOS 14 或更高版本。
- Agent 思考、计划和模式同步的完整实机验收仍待完成；部分服务商配置下可能出现对话长时间无回复。
- Windows Commit 面板本版不提供 Amend（修改上一次提交）；PHP 语言服务不随应用内置，也不提供在线安装包，需另行安装兼容插件及 Node.js。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

### Highlights

This release focuses on organizing files, working with Agents, and committing changes.

#### ✨ New features

- macOS project trees support Command-click multiselection, Shift-click ranges, and batch copying, pasting, duplication, and moving to Trash.
- macOS project trees exchange copied files with Finder; Command-A selects siblings at the focused location.
- macOS Agent conversations display collapsible thinking and plan progress, and synchronize permission modes changed by the Agent.
- macOS Agent input completes `/` commands and Codex `$` skills, with clickable suggestions even in a small input area.

#### ⚡ Improvements

- macOS Agent model and permission menus are more compact, preserving upstream names alongside localized descriptions and brand icons.
- Windows Commit panels separate changed and untracked files, offer tree or flat views, and summarize selected additions, modifications, and deletions.
- Windows commit message areas remember mouse or keyboard resizing and explain missing file selections or commit messages.
- Windows activity bar, title bar, Run panel icons, and default Git status colors align with IntelliJ IDEA styling.
- The feature matrix gains online reading and downloads for comparing macOS and Windows implementation and verification status.

#### 🛠 Fixes

- macOS fixes Claude API Key authentication conflicts when starting or restoring conversations.
- macOS no longer briefly shows stale models when switching Agent sessions and prevents sending before setup completes.
- macOS permission menus no longer clip two-line descriptions; searching thinking content restores the previous collapsed state afterward.
- macOS project-tree shortcuts no longer also affect the editor; batch deletion checks unsaved changes and reports interrupted operations.
- Windows commit areas remain resizable after shrinking; failed commit queries support retry and ignore stale responses.

### Upgrade instructions

- macOS: open the DMG for your architecture and drag Lithe.app to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.
- Windows commit history is available through Git Log; the Commit panel no longer includes a History tab.

### Compatibility and known issues

- macOS requires version 13 or later, with Apple Silicon and Intel installers; Windows installers target x64.
- macOS installers lack Developer ID signing and notarization, and Windows installers lack Authenticode signing; automatic updates use separate update signatures.
- Agent conversations are currently available only on macOS; thinking, plans, and commands depend on the connected Agent. Arrow-key and Tab completion require macOS 14 or later.
- Full runtime verification of Agent thinking, plans, and mode synchronization remains pending; some provider configurations may leave conversations waiting for a reply.
- Windows Commit panels do not offer Amend in this release. PHP language services and online-installable archives are not bundled; install a compatible plugin and Node.js separately.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
