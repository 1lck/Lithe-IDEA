### 重点更新

本次重点是 Windows 上的 Java 工具识别，以及终端和 Git 的日常操作。

#### ✨ 新功能

- 打开装有多个独立仓库的文件夹时，可按仓库切换分支、查看 Git Log 和执行操作。
- 终端支持按列块选择、打开查找时预填选中文字，以及粘贴剪贴板中的图片。
- 终端设置可调整光标形状和粗细，并可开关 Shell 集成、单击移动光标和 Option 当作 Meta 键。
- 在提示符处调整终端宽度只保留一份提示符，单击命令行即可移动光标，PowerShell 同样适用。
- Git 控制台可按类别隐藏内部查询，默认只显示你执行的命令。

#### ⚡ 改进

- 更新和插件下载中断后可以接着下载，不再从头开始，大插件也不会因总时长超时。
- 悬浮提示更快出现；在同一位置再次停留时直接显示上次结果。
- 大型 Go 仓库打开后，Go 语言服务更快开始工作。
- 设置页排布更紧凑，构建页用下拉框选择工具链版本。
- 构建失败时显示工具自己的报错，鼠标悬停在构建树上可查看完整信息。
- 插件为新语言声明的行注释符号可以直接用于切换注释。
- Windows 终端改用随客户端提供的 ConPTY（Windows 的终端组件）。
- 打开本地终端时，窗口不再等待 Shell 启动而卡住。

#### 🛠 修复

- Windows：通过 PATH 或 JAVA_HOME 配置的 JDK 现在会出现在新建项目和工具链设置中。
- Windows：Maven 等构建工具装在带空格的目录时，构建模型可以正常加载。
- 设置页重新提供 GitHub 登录入口。
- 指针离开文字后，回到同一字符可再次显示悬浮提示。
- 文件名含反斜杠时，项目树不再报错。
- 命令刚结束就关闭终端时，后台任务会一起结束。
- 快捷键录制可以记录按下的组合键。

### 升级说明

- 已安装 0.8.0：在标题栏的更新入口或“设置 → 更新”中检查更新，即可升级到本版。
- macOS：也可选择对应芯片的 DMG，将 `Lithe Desktop.app` 拖入“应用程序”。
- Homebrew：当前 `lithe` 配方仍指向旧客户端 0.6.7；安装本版请使用上述 DMG。
- Windows：运行 x64 安装程序，或将 ZIP 解压到独立目录后运行 `lithe.exe`。
- Linux：使用对应架构的 DEB/RPM；tar.gz 用户需要自行满足运行库要求。
- Java 用户建议同时把 Java Support 插件更新到 2.0.1，以识别 Windows 和 Linux 常见目录中的 JDK。

### 兼容性与已知问题

- macOS 最低为 13.0，分别提供 Apple Silicon 和 Intel 包；Windows 桌面端提供 x64 包。
- Linux 提供 x64 和 ARM64 包，需要兼容的运行库和图形环境，未验证所有发行版。
- 新客户端的功能迁移仍在进行，组件与无头验证不代表旧版功能已全部对齐。
- macOS 使用临时签名且未公证，Windows 安装包没有发行者签名，系统可能显示安全提示。

如果 macOS 提示无法打开 `Lithe Desktop.app`，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可执行 `xattr -dr com.apple.quarantine "/Applications/Lithe Desktop.app"`。旧版 `Lithe.app` 对应命令是 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

### Highlights

This release focuses on Java tool detection on Windows and everyday terminal and Git work.

#### ✨ New features

- In a folder holding several repositories, switch branches, read Git Log and run actions per repository.
- The terminal supports column block selection, prefilled Find from the selection and pasting clipboard images.
- Terminal settings adjust the cursor shape and thickness and toggle shell integration, click-to-move and Option as Meta.
- Resizing at a prompt keeps one prompt, and clicking the command line moves the cursor, in PowerShell too.
- The Git console can hide internal queries by category and shows only your own commands by default.

#### ⚡ Improvements

- Interrupted update and plugin downloads resume instead of starting over, and large plugins no longer time out.
- Hover tips appear sooner, and pausing again at the same spot shows the previous answer at once.
- The Go language service starts working sooner after opening a large Go repository.
- Settings pages are more compact, and the Build page picks toolchain versions from a dropdown.
- Failed builds show the tool's own error, and hovering the build tree shows the full message.
- Line comment tokens that plugins declare for new languages now work with Toggle Comment.
- Windows terminals use the ConPTY (the Windows terminal component) shipped with the client.
- Opening a local terminal no longer freezes the window while the shell starts.

#### 🛠 Fixes

- Windows: JDKs set through PATH or JAVA_HOME now appear in New Project and the toolchain settings.
- Windows: build models load when Maven or other build tools are installed under a path with spaces.
- Settings show the GitHub sign-in entry again.
- Hover tips appear again on the same character after the pointer leaves the text.
- File names containing backslashes no longer break the project tree.
- Closing a terminal right after a command also ends its background jobs.
- Shortcut recording captures the chord you press.

### Upgrade instructions

- From 0.8.0: check for updates from the title-bar update entry or Settings → Updates to upgrade to this release.
- macOS: or open the DMG for your processor and drag `Lithe Desktop.app` to Applications.
- Homebrew: the `lithe` cask still targets the older 0.6.7 client; use the DMG above for this release.
- Windows: run the x64 installer, or extract the ZIP into its own directory and run `lithe.exe`.
- Linux: use the DEB/RPM for your architecture; tar.gz users must provide the required runtime libraries.
- Java users should also update the Java Support plugin to 2.0.1 to detect JDKs in common Windows and Linux locations.

### Compatibility and known issues

- macOS requires 13.0 or newer, with separate Apple Silicon and Intel packages; the Windows desktop package targets x64.
- Linux packages target x64 and ARM64, requiring compatible libraries and a graphical environment; not every distribution is verified.
- Feature migration continues; component and headless checks do not establish complete parity with the older client.
- macOS packages use ad hoc signing without notarization; Windows installers have no publisher signature and may trigger system prompts.

If macOS cannot open `Lithe Desktop.app`, Control-click it in Applications and choose Open. If it remains blocked, run `xattr -dr com.apple.quarantine "/Applications/Lithe Desktop.app"`. For the older `Lithe.app`, use `xattr -dr com.apple.quarantine /Applications/Lithe.app`. Use these commands only for an app from a source you trust.
