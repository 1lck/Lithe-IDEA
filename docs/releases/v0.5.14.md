### 重点更新

本次更新减少 Git 与 Maven 误识别，让差异审阅和 Agent 操作更方便。

#### ⚡ 改进

- Windows Git 提交差异在同一标签中切换文件，并可连续跳到下一文件的首处差异。
- Windows 差异视图提供词级高亮开关，保留空白显示设置，并改善滚动条和左右滚动同步。
- macOS Agent 任务、运行和修改面板更紧凑，支持展开详情，并集中显示保留或回撤修改操作。

#### 🛠 修复

- Git 自动发现跳过隐藏目录和常见构建、依赖目录，避免将缓存中的依赖误列为项目仓库。
- macOS 切换 Git 仓库时清理旧分支和历史选择，避免沿用旧引用导致“unknown revision”错误。
- Maven 按完整插件坐标识别框架及源码、报告目录，避免同名自定义插件误识别或遮蔽父模块插件。
- Windows 历史差异显示实际版本与重命名前后路径，跳转源码时按所选侧映射行号并禁用已删除文件。

### 升级说明

- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。

### 兼容性与已知问题

- macOS 需要 13 或更高版本，提供 Apple Silicon 和 Intel 安装包；Windows 提供 x64 安装包。
- macOS 安装包尚无 Developer ID 签名和公证，Windows 安装包尚无 Authenticode 签名；自动更新使用独立的更新签名。
- 隐藏目录中的仓库仍可直接打开；`.worktree` 和 `.worktrees` 保留自动发现，范围不受 `.gitignore` 或文件树自定义过滤配置控制。
- Agent 面板改进仅适用于 macOS；Windows 历史差异跳转到工作区时，提交后另行修改的文件仍可能存在行号偏移。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

### Highlights

This release reduces Git and Maven misidentification and makes diff review and Agent actions easier to use.

#### ⚡ Improvements

- Windows Git commit diffs switch files within one tab and navigate directly to the next file's first change.
- Windows diffs add a word-level highlighting toggle, retain whitespace settings, and improve scrollbars and synchronized scrolling.
- macOS Agent task, running, and edit panels become more compact, with expandable details and grouped keep or revert actions.

#### 🛠 Fixes

- Git discovery skips hidden directories and common build and dependency folders, avoiding cached dependencies appearing as project repositories.
- macOS repository switching clears old branch and history selections, preventing stale references from causing “unknown revision” errors.
- Maven uses full plugin coordinates for framework, source, and report detection, preventing same-name custom plugins from misidentifying or masking inherited plugins.
- Windows historical diffs show actual revisions and rename paths; source navigation maps the selected side's lines and disables deleted files.

### Upgrade instructions

- macOS: open the DMG for your architecture and drag Lithe.app to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.

### Compatibility and known issues

- macOS requires version 13 or later, with Apple Silicon and Intel installers; Windows installers target x64.
- macOS installers lack Developer ID signing and notarization, and Windows installers lack Authenticode signing; automatic updates use separate update signatures.
- Repositories in hidden folders can still be opened directly; `.worktree` and `.worktrees` remain discoverable, independently of `.gitignore` and custom file-tree filters.
- Agent panel improvements apply only to macOS; Windows navigation from historical diffs may have line offsets if working files changed after the commit.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
