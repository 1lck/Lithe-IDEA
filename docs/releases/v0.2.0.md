## Highlights

- Added a Database workspace with connection management, table browsing, SQL execution, and an independent `lithe-db-mcp` stdio adapter for external automation.
- Moved the language-server runtime into the Rust core, so LSP sessions, framing, diagnostics, and provider configuration are shared and authoritative across platforms.
- Generalized run configurations beyond Java, with cross-language service detection and per-service runtime and toolchain options.
- Lowered the minimum requirement to macOS 13.

## Database workspace

- Added connection profiles for MySQL, MariaDB, PostgreSQL, SQLite, and other common sources, with per-profile connection status and passwords preserved across edits.
- Added a table workspace with column header sorting, a visual filter and sort query bar, batch row selection and editing, and larger row hit targets.
- Added connection profile import from DBX exports, including encrypted exports and warnings for settings that need manual review.
- Added sidebar context menus, database brand icons, and a dashboard home layout.
- Separated structure and data refresh so metadata and rows update independently.

## Language tooling

- Moved LSP session hosting, inbound and outbound framing, text edits, code actions, completion resolve, rename, formatting, and the provider catalog into the Rust core.
- Made LSP providers dynamically configurable, with configurable tool installation and builtin fallbacks.
- Made readiness and failures authoritative, distinguishing executable verification from server readiness and surfacing degraded catalog loads instead of false errors.
- Added Java runtime JDK discovery and persistence, and validated `gopls` alongside generalized language tooling.
- Added an LSP control center derived from runtime state, with process state tracking and setup controls.

## Run and services

- Added shared project run configurations and generalized them across languages.
- Added Quarkus and Micronaut service detection in the Rust core.
- Moved Java toolchains into service options and made runtimes configurable from Services.
- Exposed managed process memory usage.
- Preserved colliding module configurations and made service actions independently clickable.

## Editor and interface

- Added editor tab layout modes with drag reordering.
- Added theme switching while preserving workspace state across theme changes.
- Added a shared workspace search index and restored Search Everywhere scrolling.
- Widened plain text file support.
- Restored the welcome window when closing a project, and refined the recent project menu layout.

## Git and workspace

- Kept Git graph branch lines continuous across merges.
- Derived Git watch context for status observation.
- Stopped Git log scrolling from redrawing the workbench.
- Ignored nested worktree checkouts and recovered the project tree when workspace loading fails.
- Restored Maven project detection.

## Install or update

- **GitHub Release:** Download the `arm64` DMG for Apple silicon or the `x86_64` DMG for Intel Macs from the release assets below.
- **In-app update:** Open **Settings > Updates**, select **Check for Updates**, and install the available update.
- **Homebrew:** Run `brew upgrade --cask lithe`. For a first installation, follow the Homebrew instructions in the project README.

Lithe requires macOS 13 or later. Java project features require a JDK, and semantic Java navigation requires Eclipse JDT LS.
