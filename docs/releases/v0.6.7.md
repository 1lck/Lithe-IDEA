本次更新改善 Git 操作和 Windows 编辑体验，并为 macOS 增加终端分屏、日志窗口和设置导入。

### 重点更新

本次更新涵盖编辑器、终端、Git、插件和诊断。

#### ✨ 新功能

- macOS 支持拖动终端标签分屏，移动时保留终端会话。
- macOS 支持导入 IDE 设置，并新增独立日志窗口和诊断导出。
- macOS 本地历史支持忽略规则、用量查看、容量调整和清空。
- macOS Markdown 支持离线 PlantUML、化学式和下标。
- macOS 可从设置查看插件提供的工具链和环境来源。
- 项目目录可标记为不参与索引；编辑器增加多种构建和脚本语言高亮。
- macOS 插件可提供编辑器高亮、文本动作和原生终端集成。

#### ⚡ 改进

- Git 统一变更列表归属、提交范围、整文件回滚和历史操作的判断。
- macOS 项目文件新增系统“打开方式”菜单，工具窗口菜单更清晰。
- macOS 改进语言服务器状态、动作搜索和导入窗口。
- Windows 改进 Markdown 预览、源码编辑和编辑后的断点位置更新。
- 搜索不再等待内容索引预热，项目使用所选 JDK，Windows 运行会话互相隔离。
- 插件安装进度更清晰，Codex 会话历史支持按供应商筛选。

#### 🛠 修复

- Windows 修复问题面板快速修复请求，以及无效快捷键条件导致界面卡死。
- Windows 修复历史列表中合法提交无法 cherry-pick 的问题。
- Git 修复提交所选文件、删除已暂存新文件，以及 Windows 回滚新增或重命名文件的问题。
- macOS 修复标签操作资格、提交时间时区和 AI 提交消息输出限制。
- macOS 修复长分支名悬停时的触控板滚动、终端环境和 Markdown 图片布局。
- 修复 IDE 快捷键导入和终端切换问题。

### 升级说明

- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。

### 兼容性与已知问题

- macOS 需要 13.0 或更高版本；Windows 安装包面向 x64。
- macOS 使用临时签名，尚无 Developer ID 签名或公证；Windows 安装包尚无 Authenticode 签名。
- 远程开发仍为阶段性实现；跨平台行为统一工作仍在进行，详见 [#1662](https://github.com/1lck/Lithe-IDEA/issues/1662)。
- 静态审计发现 macOS Shelf 保存期间的新编辑可能被清理、Windows 插件包完整性验证不足；尚未完成运行时复现。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

This release improves Git workflows and Windows editing, and adds terminal splits, a log window, and settings import on macOS.

### Highlights

This release covers editing, terminals, Git, plugins, and diagnostics.

#### ✨ New features

- macOS supports dragging terminal tabs into splits while preserving their sessions.
- macOS can import IDE settings and adds a dedicated log window and diagnostic export.
- macOS local history adds ignore rules, usage, capacity controls, and clearing.
- macOS Markdown supports offline PlantUML, chemical formulas, and subscripts.
- macOS settings show plugin-provided toolchains and environment sources.
- Project directories can be excluded from indexing, and more build and script languages receive highlighting.
- macOS plugins can provide editor highlighting, text actions, and native terminal integration.

#### ⚡ Improvements

- Git uses consistent change-list membership, commit scope, whole-file rollback, and history action rules.
- macOS project files gain the system Open With menu, and tool-window menus are clearer.
- macOS improves language-server status, action search, and the import window.
- Windows improves Markdown preview, source edits, and breakpoint relocation after edits.
- Search no longer waits for content indexing, projects use their selected JDK, and Windows run sessions are isolated.
- Plugin installation progress is clearer, and Codex session history can be filtered by provider.

#### 🛠 Fixes

- Windows fixes Problems quick fixes and interface hangs caused by invalid shortcut conditions.
- Windows fixes unavailable cherry-pick actions on valid history entries.
- Git fixes selected-file commits, deleted staged additions, and Windows rollback of added or renamed files.
- macOS fixes tag action eligibility, commit time zones, and the AI commit message output limit.
- macOS fixes trackpad scrolling over long branch names, terminal environments, and Markdown image layout.
- IDE shortcut import and terminal switching are fixed.

### Upgrade instructions

- macOS: open the DMG for your architecture and drag Lithe.app to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.

### Compatibility and known issues

- macOS requires version 13.0 or later; the Windows installer targets x64.
- macOS uses ad-hoc signing without Developer ID signing or notarization; the Windows installer lacks Authenticode signing.
- Remote development remains partial; cross-platform behavior alignment is ongoing in [#1662](https://github.com/1lck/Lithe-IDEA/issues/1662).
- A static audit identified possible loss of edits made while saving a macOS Shelf and incomplete Windows plugin package integrity checks; runtime reproduction is pending.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
