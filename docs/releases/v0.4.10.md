### 重点更新

本次更新内容如下。

#### ✨ 新功能

- macOS 主编辑区、独立窗口和分屏统一使用 Monaco，支持共享的查找、编辑命令和语言功能。
- macOS Maven 导航移至右侧工具窗口，构建输出独立显示在底部并可与其他面板同时使用。
- macOS 与 Windows 默认显示代码缩略图，并可在编辑器设置中随时关闭。

#### ⚡ 改进

- 独立 Java 文件会先编译再运行，可使用 JDK 8，并在编译失败时显示真实诊断。
- macOS Git 控制台、仓库设置和提交记录更完整，中文、日文和韩文输入也更稳定。
- Windows Maven 启动失败时会保留具体错误和失败阶段，便于排查工具链配置。

#### 🛠 修复

- macOS 与 Windows 会在保存前保护外部文件修改，避免编辑中的内容覆盖磁盘新版本。
- Windows 文件树会及时同步应用外的创建、删除和重命名，不再依赖频繁手动刷新。
- macOS 全局搜索支持以 `/` 查找命令，并修复搜索选项入口和无效控件。

### 升级说明

- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。

### 兼容性与已知问题

- macOS 需要 13 或更高版本；Windows 版本仍处于预览阶段，部分平台能力和界面细节可能与 macOS 不完全一致。
- Windows 安装包在未配置 Authenticode 发布者证书时可能显示系统安全提示。
- macOS 编辑器已迁移到 Monaco；系统剪贴板、输入法和复杂语言服务场景仍建议在实际项目中留意回归并及时反馈。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

This update upgrades cross-platform editing and makes Java runs, external file synchronization, and common tool windows more reliable.

### Highlights

Changes are grouped below.

#### ✨ New features

- The macOS main editor, standalone windows, and split views now use Monaco with shared search, editing commands, and language features.
- macOS Maven navigation moves to the right tool window, while build output remains independently available at the bottom.
- macOS and Windows show the code minimap by default, with an editor setting to turn it off.

#### ⚡ Improvements

- Standalone Java files are compiled before launch, enabling JDK 8 and showing real compiler diagnostics when compilation fails.
- The macOS Git console, repository settings, and commit history are more complete, with more reliable CJK input.
- Windows preserves the specific error and failed stage when a Maven launch cannot start, making toolchain issues easier to diagnose.

#### 🛠 Fixes

- macOS and Windows protect external file changes before saving, preventing edited buffers from overwriting newer disk content.
- The Windows file tree promptly follows external creates, deletes, and renames without frequent manual refreshes.
- macOS Search Everywhere supports `/` command queries and restores working search controls without inactive placeholders.

### Upgrade instructions

- macOS: open the DMG for your architecture and drag Lithe.app to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.

### Compatibility and known issues

- Requires macOS 13 or later; Windows remains a preview, and some platform capabilities and interface details may differ from macOS.
- The Windows installer may show a system security warning when no Authenticode publisher certificate is configured.
- The macOS editor has moved to Monaco; please report regressions found with system clipboard, input methods, or complex language-service workflows.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
