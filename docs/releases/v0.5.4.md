### 重点更新

本次更新改善多仓库 Git 浏览、运行输出与 Windows 编辑体验。

#### ✨ 新功能

- Git 历史记录的引用面板可按仓库查看分支、远程引用和标签，并可选择是否显示工作树仓库。
- macOS 和 Windows 的运行面板可切换输出自动换行，长行内容更易阅读。
- Windows 编辑器标签可选单行或多行布局，打开较多文件时无需只靠横向滚动。

#### ⚡ 改进

- Windows 编辑区只显示当前文件，不再将多个文件横向排列成卡片；自动换行设置也会按用户选择生效。
- Windows 的 Maven 入口统一放在右侧活动栏，减少重复入口。

#### 🛠 修复

- Java 项目启动语言服务时不再往模块目录生成项目配置文件，并会清理旧版留下的未跟踪文件。
- Windows 自动保存遇到文件被其他程序短暂占用时会重试，减少保存失败。
- Windows 终端的屏幕重绘更稳定，连续输出时不易抖动。
- 欢迎页的更新进度和详情提示布局恢复正常。

### 升级说明

- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。
- 首次启动 Java 语言服务时，旧版生成且未受 Git 跟踪的 `.project`、`.classpath`、`.factorypath` 和 `.settings/*.prefs` 可能被清理；已跟踪的文件会保留。

### 兼容性与已知问题

- macOS 需要 13 或更高版本；Windows 仍处于预览阶段，部分功能与 macOS 存在差异。
- Windows 的行号运行图标暂不提供“调试”，macOS 可从同一菜单调试。
- macOS 安装包尚未使用 Developer ID 签名和公证；Windows 安装包尚未使用 Authenticode 发布者签名，系统可能提示安全警告。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

### Highlights

This release improves Git browsing across repositories, run output, and the Windows editor.

#### ✨ New features

- Git history groups branches, remote references, and tags by repository, with an option to show or hide worktree repositories.
- The macOS and Windows Run panels can wrap long output lines for easier reading.
- Windows editor tabs can use a single row or wrap into multiple rows when many files are open.

#### ⚡ Improvements

- The Windows editor shows only the active file instead of arranging files as horizontal cards; word wrap follows your setting.
- Windows keeps the Maven entry in the right activity rail, removing the duplicate entry.

#### 🛠 Fixes

- Starting the Java language service no longer creates project configuration files in module folders and cleans up untracked files left by older versions.
- Windows retries autosaves when another program briefly locks a file, reducing save failures.
- Windows terminal screen redraws are steadier during continuous output.
- The welcome page displays update progress and details in their intended positions.

### Upgrade instructions

- macOS: open the DMG for your architecture and drag Lithe.app to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.
- On the first Java language service start, untracked `.project`, `.classpath`, `.factorypath`, and `.settings/*.prefs` files generated by older versions may be removed; Git-tracked files remain.

### Compatibility and known issues

- Requires macOS 13 or later; Windows remains a preview, with some features differing from macOS.
- Line-number run icons on Windows do not offer Debug yet; on macOS, the same menu can debug.
- macOS packages lack Developer ID signing and notarization; Windows installers lack Authenticode publisher signing, so system security warnings may appear.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
