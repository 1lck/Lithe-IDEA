### 重点更新

本次更新让提交范围更清晰、项目切换更方便，并改善日常使用的稳定性。

#### ✨ 新功能

- 双端新增 ChangeList 本地分组，可新建、重命名和移动文件，并限制“全部暂存”和提交的范围。
- 双端文件树右键支持查看 Git 差异、暂存文件，以及暂存后打开提交面板。
- macOS 发布包新增可独立下载的 PHP 插件，并在安装时检查插件完整性。
- Windows 新增项目颜色与头像，帮助区分多个项目窗口。

#### ⚡ 改进

- Windows 工作台采用 Islands 圆角标签、配色和焦点反馈，提交差异标签显示当前文件名。
- Windows 打开项目时可选择替换当前项目、新窗口或附加，窗口标题同步显示项目名和文件名。
- Windows 运行配置按类型折叠分组，使用服务类型图标，并可快捷运行、停止和编辑。
- Windows Git Log 文件列表支持横向滚动，便于查看长路径。
- macOS Markdown 预览目录默认展开，并使用完整可用高度。

#### 🛠 修复

- macOS 修复打开项目时重复 Git 状态导致的闪退，以及数据库视图退出清理后的崩溃。
- macOS Agent 单轮请求超时后会取消并提示重试，避免一直等待。
- macOS 即使未检测到新版，也可手动更新 Agent CLI。

### 升级说明

- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。

### 兼容性与已知问题

- macOS 需要 13 或更高版本，提供 Apple Silicon 和 Intel 安装包；Windows 提供 x64 安装包。
- macOS 安装包尚无 Developer ID 签名和公证，Windows 安装包尚无 Authenticode 签名；自动更新使用独立的更新签名。
- ChangeList 按完整文件分组，不支持把同一文件的不同修改块分到多个列表；双端完整实机验收仍待完成。
- Agent 对话界面目前仅在 macOS 提供；单轮请求最多运行 10 分钟，包含工具执行和权限等待，正常长任务也会在到期时取消。
- PHP 仍为可选插件，需要 Node.js；插件在线安装与 Agent 超时恢复的完整实机验收仍待完成。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

### Highlights

This release clarifies commit scope, improves project switching, and addresses everyday reliability.

#### ✨ New features

- Both platforms add local ChangeList groups with creation, renaming, file moves, and scoped Stage All and commit actions.
- Both platforms add file-tree Git actions to review diffs, stage files, and stage a file before opening Commit.
- macOS releases now include separately downloadable PHP plugins, with integrity checks during installation.
- Windows adds project colors and avatars to distinguish project windows.

#### ⚡ Improvements

- Windows adopts Islands rounded tabs, colors, and focus feedback; commit diff tabs show the current filename.
- Windows can replace, attach, or open projects in new windows; window titles show the project and active file.
- Windows Run configurations use collapsible type groups and service icons, with quick run, stop, and edit actions.
- Windows Git Log file lists scroll horizontally to reveal long paths.
- macOS Markdown preview outlines expand by default and use the full available height.

#### 🛠 Fixes

- macOS fixes crashes from duplicate Git status entries when opening projects and database views after shutdown cleanup.
- macOS Agent turns cancel with a retryable timeout instead of waiting indefinitely.
- macOS allows manual Agent CLI updates even when no newer version is detected.

### Upgrade instructions

- macOS: open the DMG for your architecture and drag Lithe.app to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.

### Compatibility and known issues

- macOS requires version 13 or later, with Apple Silicon and Intel installers; Windows installers target x64.
- macOS installers lack Developer ID signing and notarization, and Windows installers lack Authenticode signing; automatic updates use separate update signatures.
- ChangeList groups whole files, not individual hunks; full runtime verification on both platforms remains pending.
- Agent conversations are currently available only on macOS. Each turn has a 10-minute limit, including tools and permission waits; legitimate long tasks are also cancelled at the limit.
- PHP remains an optional plugin requiring Node.js; full runtime verification of online plugin installation and Agent timeout recovery remains pending.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
