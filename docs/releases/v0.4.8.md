### 重点更新

本次更新内容如下。

#### ✨ 新功能

- 编辑器支持中键关闭标签、常用行级编辑操作和更顺滑的标签滚动。
- macOS 运行面板补充 Maven 模块、生命周期和测试操作，并记忆项目级 LSP 开关状态。

#### ⚡ 改进

- 优化 macOS 左侧功能切换和双栏 Diff 横向滚动时的界面响应。
- 改进提交面板、编辑器软换行和大型文件编辑体验。

#### 🛠 修复

- 修复空行中的光标定位、Markdown 软段落换行和部分软换行场景的问题。
- 修复 macOS 双栏 Diff 横向滚动时不必要的重复重绘，降低长文本滚动卡顿。

### 升级说明

- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。

### 兼容性与已知问题

- macOS 需要 13 或更高版本；Windows 安装包未配置发布者证书，系统可能显示提示。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

## English

This patch release focuses on the editor, macOS run workflows, and Diff performance while fixing several interaction and formatting issues.

### Downloads

- [Project homepage](https://github.com/1lck/Lithe-IDEA)

- [All downloads](https://github.com/1lck/Lithe-IDEA/releases/tag/v0.4.8)

### Highlights

Changes are grouped below.

#### ✨ New features

- The editor adds middle-click tab closing, common line-level editing actions, and smoother tab scrolling.
- The macOS run panel adds Maven module, lifecycle, and test actions and remembers project-level LSP toggles.

#### ⚡ Improvements

- Improved responsiveness when switching macOS sidebar features and horizontally scrolling split Diff views.
- Refined the commit panel, editor soft wrapping, and large-file editing experience.

#### 🛠 Fixes

- Fixed caret placement on empty lines, Markdown soft paragraph breaks, and several soft-wrap cases.
- Reduced redundant redraws during horizontal scrolling in macOS split Diff views, improving long-text scrolling.

### Upgrade instructions

- macOS: open the DMG for your architecture and drag Lithe.app to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.

### Compatibility and known issues

- Requires macOS 13 or later; the Windows installer has no publisher certificate and may show a system warning.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
