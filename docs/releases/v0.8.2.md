### 重点更新

本次重点是多仓库 Git、构建窗口和只读输出的日常使用。

#### ✨ 新功能

- 编辑器可复制代码引用：有语言服务时复制符号名，否则复制文件路径和行号。
- 多仓库 Git Log 可点仓库名切换，也可勾选多个仓库按时间混合显示。
- 提交并推送后打开“推送提交”对话框，逐个仓库确认分支、远程和待推送的提交。
- 加载构建模型时，Run 窗口显示“同步”标签，实时显示下载依赖的日志，可停止和重新运行。
- Build 窗口按父子项目嵌套显示，每个项目下列出任务、依赖和目标。

#### ⚡ 改进

- Git Log 的读取上限可在设置中调整，读满后提示更早的提交，不再显示加载失败。
- 提交面板的每个仓库显示当前分支，复选框和缩进与 IDEA 对齐。
- 运行配置和需要隐藏的构建目录改由对应插件提供，各构建工具的行为一致。

#### 🛠 修复

- Run 控制台、测试输出、Git Log 提交详情和 Git 控制台的文字可以选择和复制。
- Windows：应用内增量更新退出后能装上新版并重新启动。
- Windows：运行或调试时不再反复弹出空白终端窗口，移到回收站也不再弹窗。
- 大型项目或同层有大量被忽略的目录时，项目树不再显示“项目目录不可用”。
- Go 项目的构建模型不再一直显示加载中。
- 语言服务启动较慢时，main 方法旁的运行和调试图标会在就绪后出现。
- 快速切换分支或同步时，Git 状态不再被旧的结果覆盖。
- 设置文件损坏时会先另存一份，不再被默认值覆盖。
- “恢复默认设置”会一并恢复终端回滚行数和光标样式。
- 插件只读设置里的列表逐行完整显示，不再显示无效的“重置”和“浏览”。
- Ubuntu 26.04 等系统的 bash 中，终端能正确识别每条命令的开始。

### 升级说明

- 已安装 0.8.1：在标题栏的更新入口或“设置 → 更新”中检查更新，即可升级到本版；Windows 会下载完整安装包。
- Windows 0.8.0 无法在应用内完成更新，请下载本版安装程序手动安装。
- macOS：也可选择对应芯片的 DMG，将 `Lithe Desktop.app` 拖入“应用程序”。
- Homebrew：配方更新到本版后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：运行 x64 安装程序，或将 ZIP 解压到独立目录后运行 `lithe.exe`。
- Linux：使用对应架构的 DEB/RPM；tar.gz 用户需要自行满足运行库要求。

### 兼容性与已知问题

- macOS 最低为 13.0，分别提供 Apple Silicon 和 Intel 包；Windows 桌面端提供 x64 包。
- Linux 提供 x64 和 ARM64 包，需要兼容的运行库和图形环境，未验证所有发行版。
- 自动生成运行配置、隐藏 `target`、`node_modules` 等目录需要启用对应的语言或构建插件。
- 新客户端的功能迁移仍在进行，部分旧版功能尚未完全对齐。
- macOS 使用临时签名且未公证，Windows 安装包没有发行者签名，系统可能显示安全提示。

如果 macOS 提示无法打开 `Lithe Desktop.app`，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可执行 `xattr -dr com.apple.quarantine "/Applications/Lithe Desktop.app"`。旧版 `Lithe.app` 对应命令是 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

### Highlights

This release focuses on multi-repository Git, the Build window and read-only output.

#### ✨ New features

- The editor copies a code reference: the symbol name with a language service, otherwise the file path and line.
- Multi-repository Git Log switches repositories by name and can mix several selected repositories by date.
- Commit and Push opens a Push Commits dialog to confirm each repository's branch, remote and commits.
- Loading a build model opens a Sync tab in the Run window with live dependency logs, Stop and Rerun.
- The Build window nests child projects under parents, each listing its tasks, dependencies and targets.

#### ⚡ Improvements

- Git Log read limits are adjustable in Settings, and a full log notes older commits instead of failing.
- Each repository in the commit panel shows its current branch, with checkboxes and indents aligned like IDEA.
- Run configurations and hidden build folders now come from the matching plugins, consistent across build tools.

#### 🛠 Fixes

- Text in the Run console, test output, Git Log commit details and Git console can be selected and copied.
- Windows: in-app patch updates install the new version and restart after quitting.
- Windows: running or debugging no longer keeps opening blank terminal windows, nor does Move to Trash.
- Large projects, or folders with many ignored siblings, no longer show "project directory unavailable" in the tree.
- Go project build models no longer stay loading forever.
- When a language service starts slowly, Run and Debug icons beside main methods appear once it is ready.
- Switching branches or syncing quickly no longer lets an older Git status overwrite the new one.
- A damaged settings file is saved aside first instead of being overwritten with defaults.
- Restore Defaults also resets terminal scrollback lines and cursor style.
- Lists in read-only plugin settings show every item on its own line, without unusable Reset and Browse buttons.
- In bash on Ubuntu 26.04 and similar systems, the terminal detects the start of every command.

### Upgrade instructions

- From 0.8.1: check for updates from the title-bar update entry or Settings → Updates; Windows downloads the full installer.
- Windows 0.8.0 cannot finish an in-app update; download and run this release's installer instead.
- macOS: or open the DMG for your processor and drag `Lithe Desktop.app` to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask is updated to this release.
- Windows: run the x64 installer, or extract the ZIP into its own directory and run `lithe.exe`.
- Linux: use the DEB/RPM for your architecture; tar.gz users must provide the required runtime libraries.

### Compatibility and known issues

- macOS requires 13.0 or newer, with separate Apple Silicon and Intel packages; the Windows desktop package targets x64.
- Linux packages target x64 and ARM64, requiring compatible libraries and a graphical environment; not every distribution is verified.
- Generated run configurations and hiding folders such as `target` and `node_modules` need the matching language or build plugin enabled.
- Feature migration continues; some features of the older client are not yet at full parity.
- macOS packages use ad hoc signing without notarization; Windows installers have no publisher signature and may trigger system prompts.

If macOS cannot open `Lithe Desktop.app`, Control-click it in Applications and choose Open. If it remains blocked, run `xattr -dr com.apple.quarantine "/Applications/Lithe Desktop.app"`. For the older `Lithe.app`, use `xattr -dr com.apple.quarantine /Applications/Lithe.app`. Use these commands only for an app from a source you trust.
