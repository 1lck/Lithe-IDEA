本次更新改进 Windows 编辑流畅度，扩展 macOS 调试与编辑器设置，并完善 Java 启动、Git 和更新下载。

### 重点更新

本次更新涵盖编辑、调试、项目运行和日常维护。

#### ✨ 新功能

- macOS 新增反汇编、指令步进、指令断点、寄存器和只读内存查看，具体能力取决于调试适配器。
- macOS 支持插件提供调试适配器、普通 TCP 调试连接和多会话调试标签。
- macOS 编辑器新增 VS Code、IDEA 等源码配色，以及行高、连字、行号、空白符和光标设置。
- macOS 设置新增网络代理，可跟随系统、直连或使用自定义服务器。
- macOS 正式版更新可配置镜像源，测试连接后应用，安装前仍校验签名。
- Windows 新增行内 Git 作者注释，支持跳转历史和右键操作。
- Windows 快速打开支持按路径或方法搜索 Spring 接口路由。

#### ⚡ 改进

- Windows 改进文件打开、标签切换、大文件输入和补全交互，减少界面卡顿。
- Windows 改进文件树、工作区扫描、启动反馈和项目导入进度。
- macOS 全局搜索优先呈现文件名，滚动时自动加载更多结果。
- macOS Git 支持多个独立 Diff 标签、连续滚动和更完整的提交文件操作。
- Windows 提交面板补充变更列表显示和父仓库引用选项。
- macOS Agent 对话支持多标签，并可配置上下文长度与压缩阈值。
- macOS 扩展远程工作区的终端、搜索、Git、构建与插件执行适配，完整 SSH 流程仍待验收。
- Java Support 改为独立插件，支持迁移与按需安装。
- macOS 插件补充命令、宿主接口和后端生命周期能力。
- 常见项目文件使用专用图标，双端界面翻译进一步统一。

#### 🛠 修复

- Java 启动按项目要求选择 JDK，并改善登录 shell 环境和 Node 启动路径读取。
- 保存后的构建先同步项目状态，减少 Java 启动竞态和重复重试。
- 自动发现的运行配置保留在内存，避免向用户工程写入配置文件。
- 连续输入时刷新补全候选，减少项目文件修改后的重复导入。
- 每个项目的本地历史限制为 100MB，基线跳过生成目录，并保护异常存储中的有效记录。
- macOS 更新下载支持断点续传，并按超时、连接和服务器原因提示失败。
- macOS 修复硬链接文件打开与保存，提供保留或解除硬链接等保存选择。
- macOS 改善大型工作区外部变更、工作树状态刷新和 Git 筛选文字布局。
- macOS 恢复系统重开的设置窗口内容，并减少语言设置页布局开销。
- Windows 修复当前文件定位、Git 启动路径、作者注释闪烁和推送弹窗交互。
- Windows 改善 MCP 请求调度与授权生命周期，补齐工具缓存元数据。

### 升级说明

- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”；Java 功能按提示迁移或安装 Java Support 插件。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。
- 自定义更新源目前仅支持 macOS 正式版；镜像需提供同名签名清单与更新包，AutoBuild 始终使用官方源。

### 兼容性与已知问题

- macOS 需要 13.0 或更高版本，提供 Apple Silicon 与 Intel 安装包；Windows 安装包面向 x64。
- macOS 当前使用临时签名，尚无 Developer ID 签名或公证；Windows 安装包尚无 Authenticode 签名，更新使用独立签名校验。
- 调试能力取决于语言插件与适配器，Windows 尚未具备本版全部 macOS 调试和设置能力。
- 远程开发仍为阶段性实现，完整 SSH 构建、插件启动与 Java 集成尚未完成实机验收。
- 完整 macOS 测试曾出现既有界面等待和时区相关失败；本轮未完成全量重跑、Swift 桥接与镜像安装验收。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

### Highlights

Changes cover editing, debugging, project execution, and everyday maintenance.

#### ✨ New features

- macOS adds disassembly, instruction stepping and breakpoints, registers, and read-only memory views, depending on adapter capabilities.
- macOS supports plugin-provided debug adapters, plain TCP debug connections, and tabs for multiple debug sessions.
- macOS adds VS Code and IDEA source color schemes, plus line-height, ligature, line-number, whitespace, and cursor settings.
- macOS adds network proxy settings for system proxies, direct connections, or a custom server.
- macOS stable updates support a custom mirror, applied after a connection test, with signatures still checked before installation.
- Windows adds inline Git author annotations with history navigation and context actions.
- Windows Quick Open supports searching Spring routes by path or method.

#### ⚡ Improvements

- Windows improves file opening, tab switching, large-file typing, and completion interactions to reduce interface stalls.
- Windows improves file trees, workspace scanning, startup feedback, and project import progress.
- macOS global search presents filenames first and loads more results while scrolling.
- macOS Git supports multiple independent diff tabs, continuous scrolling, and more complete commit-file actions.
- Windows commit panels add change-list visibility and parent-repository reference options.
- macOS Agent conversations support multiple tabs and configurable context lengths and compaction thresholds.
- macOS extends remote terminal, search, Git, build, and plugin execution integration; complete SSH workflows still await acceptance.
- Java Support becomes a separate plugin with migration and on-demand installation.
- macOS plugins gain command, host-interface, and backend lifecycle capabilities.
- Common project files gain dedicated icons, and interface translations improve across both platforms.

#### 🛠 Fixes

- Java launches select JDKs matching project requirements and improve login-shell environment and Node launch-path discovery.
- Builds synchronize project state after saving, reducing Java launch races and repeated retries.
- Automatically discovered run configurations stay in memory instead of writing configuration files into projects.
- Completion candidates refresh during continuous typing, with fewer repeated imports after project-file changes.
- Local history is capped at 100MB per project, skips generated directories during baseline collection, and protects valid records in damaged storage.
- macOS update downloads support resuming and distinguish timeout, connection, and server failures.
- macOS fixes opening and saving hard-linked files, with choices to preserve or break hard links.
- macOS improves large-workspace external changes, worktree status refreshes, and Git filter-label layout.
- macOS restores settings-window contents after system relaunch and reduces language-settings layout work.
- Windows fixes current-file location, Git launch paths, author-annotation flicker, and push-dialog interactions.
- Windows improves MCP request scheduling and authorization lifetimes, and adds missing tool-cache metadata.

### Upgrade instructions

- macOS: open the matching DMG and drag Lithe.app to Applications; migrate or install Java Support when prompted.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.
- Custom update sources currently support macOS stable releases only; mirrors must provide matching signed feeds and archives, while AutoBuild uses the official source.

### Compatibility and known issues

- macOS requires 13.0 or later, with Apple Silicon and Intel installers; Windows installers target x64.
- macOS currently uses ad-hoc signing without Developer ID signing or notarization; Windows installers lack Authenticode signing, while updates use separate signature verification.
- Debugging depends on language plugins and adapters; Windows does not yet offer all macOS debugging and settings features.
- Remote development remains partial; complete SSH builds, plugin launches, and Java integration still await runtime acceptance.
- Full macOS tests encountered existing UI-wait and timezone failures; a complete rerun, Swift bridge verification, and mirror-install acceptance remain unfinished.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
