## 中文

Lithe v0.5.15 支持 Windows 按修改块提交，修复 macOS 项目树多选与拖动，并改善 Agent 配置和 Java 运行诊断。

### 重点更新

本次更新让修改审阅、文件整理与运行问题恢复更方便。

#### ✨ 新功能

- Windows 可在提交差异中逐块包含或取消包含修改，只提交勾选的部分。

#### ⚡ 改进

- Windows 提交与历史差异使用统一页面，左右正文独立排列，并同步滚动与词级高亮。
- Windows 提交差异可连续浏览多个文件，并直接回退未暂存修改块，保留已暂存内容。
- macOS Agent 配置子菜单按选项收紧并自动避开屏幕边缘，不再撑宽模型菜单。

#### 🛠 修复

- macOS 项目树选择目录不再连带高亮全部后代，多选后可整体拖入目标目录移动。
- macOS 分别导入 Codex 与 Claude 本机配置时，不再互相覆盖供应商和模型。
- macOS Agent 菜单修复配置更新后选项滞后，以及键盘选择被静止鼠标抢走的问题。
- Java 构建诊断中的代码错误提供重建索引入口，缺少主类的旧运行配置提示重新生成。
- Windows 修复差异读取引起的反复刷新，并正确显示仅暂存区保留的修改。
- Windows 对 CRLF 或文件末尾无换行的修改保留整文件包含，避免不精确的块级写入。

### 升级说明

- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。
- macOS：此前被覆盖的 Codex 或 Claude 本机配置无法自动重建，请重新选择对应本机配置。
- Windows：差异中的块级回退箭头直接执行，不弹确认框；文件和仓库级丢弃仍遵循确认设置。

### 兼容性与已知问题

- macOS 需要 13 或更高版本，提供 Apple Silicon 和 Intel 安装包；Windows 提供 x64 安装包。
- macOS 安装包尚无 Developer ID 签名和公证，Windows 安装包尚无 Authenticode 签名；自动更新使用独立的更新签名。
- 项目树多选与批量拖动改进仅适用于 macOS；Windows 重命名、二进制及无法精确分块的差异使用整文件包含。
- Windows 并排差异内容刷新后可能重置光标和选区，继续导航或跳转源码前需重新定位。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

### Highlights

This release makes reviewing changes, organizing files, and recovering from run problems easier.

#### ✨ New features

- Windows commit diffs let you include or exclude individual change blocks and commit only the selected parts.

#### ⚡ Improvements

- Windows commit and history diffs share one page, with independently arranged panes, synchronized scrolling, and word-level highlighting.
- Windows commit diffs navigate across files and directly revert unstaged change blocks while preserving staged content.
- macOS Agent configuration submenus fit their options and screen edges without widening the model menu.

#### 🛠 Fixes

- macOS folder selection no longer highlights every descendant, and selected project-tree items can be dragged together into a destination folder.
- macOS imports of local Codex and Claude configurations no longer overwrite each other's providers and models.
- macOS Agent menus refresh changed options correctly and prevent a stationary pointer from stealing keyboard selection.
- Java code-error build diagnostics offer index rebuilding, and stale run configurations missing a main class prompt regeneration.
- Windows diff reads no longer cause repeated refreshes, and changes remaining only in the staging area display correctly.
- Windows retains whole-file inclusion for CRLF or missing-final-newline changes, avoiding inaccurate block-level writes.

### Upgrade instructions

- macOS: open the DMG for your architecture and drag Lithe.app to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.
- macOS: previously overwritten Codex or Claude settings cannot be reconstructed automatically; select the corresponding local configuration again.
- Windows: block-level revert arrows act immediately without confirmation; file and repository discard actions still follow confirmation settings.

### Compatibility and known issues

- macOS requires version 13 or later, with Apple Silicon and Intel installers; Windows installers target x64.
- macOS installers lack Developer ID signing and notarization, and Windows installers lack Authenticode signing; automatic updates use separate update signatures.
- Project-tree multiselection and batch dragging improvements apply only to macOS; Windows uses whole-file inclusion for renames, binary files, and diffs without safe block boundaries.
- Windows side-by-side diff content refreshes may reset the cursor and selection; reposition before continuing navigation or jumping to source.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
