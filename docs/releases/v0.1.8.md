## Added

- Added Editor, Split, and Preview views for Markdown files.
- Added shared JSON contracts and fixtures for workspace, search, Git, history,
  Java, Maven, and cancellation behavior.
- Added the initial Windows Qt/C++ application, Rust Core client, and Win32
  adapter boundaries.

## Changed

- Reorganized the macOS application around Rust Core operations, platform
  ports, macOS adapters, and UI feature models.
- Moved deterministic workspace, search, Git, Local History, and Java/Maven
  parsing behavior behind the shared Rust Core JSON/C ABI.
- Reduced `AppModel` to UI state aggregation, navigation, and feature model
  composition.
- Kept native file watching, process sessions, PTY behavior, runtime discovery,
  and native UI in the macOS adapter layer.

## Validation

- Swift unit tests, Rust Core tests, shared contract checks, service boundary
  checks, and Windows boundary checks pass locally.
- The macOS release workflow builds and verifies native `arm64` and `x86_64`
  application bundles and disk images.

Java LSP protocol state, Maven execution, Java Run/Debug sessions, and
terminal session state remain macOS application workflows. Windows is still an
independent implementation in progress and is not part of this macOS release.
