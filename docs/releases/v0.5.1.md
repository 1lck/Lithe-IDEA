### 重点更新

本次更新重点改善 Java 开发和日常编辑体验。

#### ✨ 新功能

- Windows 支持用 `Ctrl+Alt+L` 格式化 Java 等文件，并保留 `Shift+Alt+F` 快捷键。

#### ⚡ 改进

- macOS 打开 Maven 工具窗口时复用未变化的项目扫描结果，减少重复扫描。
- 大量运行与调试日志输出时，控制台更新更流畅，并保留程序结束前的最后输出。
- Java 运行列表展示项目准备和刷新状态，刷新失败时保留已有启动项。
- Java 测试识别支持继承的测试方法和自定义组合注解，并使用当前编辑内容。

#### 🛠 修复

- Java 25 的无参数入口、实例入口和紧凑源文件现在可被正确识别为启动项。
- Maven 项目导入会使用已配置的安装设置、本地仓库和镜像，避免重复下载到默认仓库。
- macOS 自动发现 SDKMAN 安装的 JDK，支持默认目录和 `SDKMAN_DIR` 自定义目录。
- 修复运行与调试日志中跨批次中文字符乱码，并改善控制台文本复制。
- Windows 打开多个文件时可用滚轮查看被遮挡的标签，切换文件也会正确定位活动标签。

### 升级说明

- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。
- Windows 新配置默认开启标签滚轮横向滚动；已有配置若关闭此功能，请在设置的编辑器页面开启缓冲区轮播选项。
- Java 25 项目仍需配置相应的项目 JDK；内置 Java 运行环境用于编辑器语言服务。

### 兼容性与已知问题

- macOS 需要 13 或更高版本；Windows 仍处于预览阶段，部分功能与 macOS 存在差异。
- macOS 安装包尚未使用 Developer ID 签名和公证；Windows 安装包尚未使用 Authenticode 发布者签名，系统可能提示安全警告。
- Maven 工具窗口在大型真实工作区中的卡顿及白屏问题仍需进一步验证，本版不承诺完全解决。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

### Highlights

This release focuses on Java development and everyday editing.

#### ✨ New features

- Windows supports `Ctrl+Alt+L` to format Java and other files while retaining `Shift+Alt+F`.

#### ⚡ Improvements

- macOS reuses unchanged project scan results when opening the Maven tool window, reducing repeated scans.
- Run and debug consoles update more smoothly during heavy output and preserve the final output before termination.
- Java run lists show preparation and refresh status, retaining existing launch entries when a refresh fails.
- Java test discovery recognizes inherited test methods and custom composed annotations, using the current editor contents.

#### 🛠 Fixes

- Java 25 no-argument main methods, instance main methods, and compact source files are correctly recognized as launch entries.
- Maven imports honor configured installation settings, local repositories, and mirrors, avoiding duplicate downloads into the default repository.
- macOS discovers SDKMAN-installed JDKs in the default directory and custom `SDKMAN_DIR` locations.
- Run and debug output preserves Chinese characters split across output batches, with improved console text copying.
- Windows wheel scrolling reveals hidden file tabs, and switching files correctly brings the active tab into view.

### Upgrade instructions

- macOS: open the DMG for your architecture and drag Lithe.app to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.
- Windows enables horizontal tab wheel scrolling for new configurations; if disabled in existing settings, enable Buffer Carousel in editor settings.
- Java 25 projects still require a matching project JDK; the bundled Java runtime serves the editor's language services.

### Compatibility and known issues

- Requires macOS 13 or later; Windows remains a preview, with some features differing from macOS.
- macOS packages lack Developer ID signing and notarization; Windows installers lack Authenticode publisher signing, so system security warnings may appear.
- Maven tool-window stalls and blank screens in large real-world workspaces still need verification; this release does not claim a complete fix.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
