### 重点更新

本次更新重点完善项目识别、启动体验、构建反馈与日常编辑器工作流。

#### ✨ 新功能

- 无后缀文件支持按插件首行规则自动识别语言类型。
- Git 分支操作支持删除远程分支与批量删除分支。

#### ⚡ 改进

- 随处搜索的“类型”和“符号”页签补充 ⓘ 范围说明并移除无效筛选。
- 运行配置编辑窗口对未修改字段的自动生成配置，显式选择保存作用域后即可直接保存。
- 热安装、启停或卸载插件时，自动刷新全部已打开标签页的构建检测与运行配置并在零实例时清理旧生成项。
- 同步 Viva 图形框架到最新上游基线（`f5b634bb`）。

#### 🛠 修复

- 为构建工具和运行时版本探测增加单次超时限制，拒绝非零退出并自动回退后续可用候选。
- 构建模型加载失败或受安全模式暂停时，直接在标题栏运行配置下拉展示原因并可跳转同步日志、构建窗口或工作区信任。
- 修复终端与控制台输出编码处理，默认按 UTF-8 解码并在中文 Windows 上兼容 GBK 输出。

### 升级说明

- 已安装版本可从标题栏更新入口或“设置 → 关于”检查更新；也可下载完整安装包。
- macOS：打开对应芯片的 DMG，将 `Lithe Desktop.app` 拖入“应用程序”。
- Homebrew：配方更新后运行 `brew update && brew upgrade --cask lithe`。
- Windows：运行 x64 安装程序；Windows 0.8.0 用户需要手动下载安装。
- Linux：全部下载文件中提供 x64、ARM64 的 DEB、RPM 和 tar.gz。

### 兼容性与已知问题

- macOS 最低 13.0；Windows 提供 x64 包；Linux 需要兼容的运行库和图形环境。
- 部分依赖本机特定交互的 Windows 能力仍待在本机 Windows 环境进一步验收，功能矩阵按实保留待验证状态。
- macOS 使用临时签名且未公证，Windows 安装包没有发行者签名，系统可能显示安全提示。

如果 macOS 提示无法打开 `Lithe Desktop.app`，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可执行 `xattr -dr com.apple.quarantine "/Applications/Lithe Desktop.app"`。旧版 `Lithe.app` 使用 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

### Highlights

This release improves project detection, startup workflows, build diagnostics, and everyday workbench tasks.

#### ✨ New features

- Extensionless files detect their language from plugin first-line rules.
- Git branch management supports deleting remote branches and batch branch deletion.

#### ⚡ Improvements

- Types and Symbols tabs in Search Everywhere add ⓘ scope guidance and remove ineffective filters.
- Selecting a save scope explicitly in the run configuration editor lets unmodified generated entries save directly.
- Hot-installing, toggling, or uninstalling plugins refreshes build detection and run configurations across all open tabs and clears stale generated items when zero build systems remain.
- Synchronized Viva with upstream commits (`f5b634bb`).

#### 🛠 Fixes

- Bounded per-candidate build tool and runtime version probes, rejected non-zero exit output, and fell back automatically to later candidates.
- Surfaced failed and safe-mode paused build models directly in the title run configuration menu with one-click navigation to sync logs, the Build window, or workspace trust.
- Defaulted console output decoding to UTF-8 with GBK fallback support on Chinese Windows systems.

### Upgrade instructions

- Check for updates from the title bar or Settings → About, or download a full package.
- macOS: open the DMG for your processor and drag `Lithe Desktop.app` to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` once the cask update is available.
- Windows: run the x64 installer; Windows 0.8.0 users must download and install manually.
- Linux: All downloads includes DEB, RPM and tar.gz packages for x64 and ARM64.

### Compatibility and known issues

- macOS requires 13.0 or newer; Windows packages target x64; Linux requires compatible libraries and a graphical environment.
- Native Windows acceptance for recently shared workbench workflows remains pending in the feature matrix.
- macOS packages use ad hoc signing without notarization; Windows installers have no publisher signature and may trigger system prompts.

If macOS cannot open `Lithe Desktop.app`, Control-click it in Applications and choose Open. If it remains blocked, run `xattr -dr com.apple.quarantine "/Applications/Lithe Desktop.app"`. For the older `Lithe.app`, use `xattr -dr com.apple.quarantine /Applications/Lithe.app`. Use these commands only for an app from a source you trust.
