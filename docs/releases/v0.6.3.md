### 重点更新

本次更新覆盖 Agent、插件、Java 项目、编辑器与跨平台日常工作流。

#### ✨ 新功能

- Windows 新增 Agent 面板和编辑区对话标签，可配置 CLI、使用 Codex 登录并查看订阅额度。
- Windows Agent 支持计划、推理、模式切换、斜杠命令、逐轮统计和回复中补充要求。
- macOS Agent 可附加文件上下文，调整模型配置，并展开任务、子代理和修改文件摘要。
- 支持声明式构建工具插件，macOS 可通过插件启动构建并查看构建窗口。
- 插件开发者可使用 Node SDK、示例构建插件和插件函数调用接口。
- Java 项目新增 Gradle 导入设置。
- Windows 编辑器行号栏可查看逐行 Git 历史，项目树文件可复制或拖入终端插入路径。
- macOS 新增 MCP 服务器资源库，终端回滚行数可配置，编辑器字号下限降至 8。
- macOS 社区插件可从磁盘安装，待重启生效时可直接点击“重启 Lithe”。

#### ⚡ 改进

- macOS 项目树按需展开目录，增量处理外部文件变化，并排除嵌套工作树。
- macOS 改进 Git Log 和终端性能，统一分支弹窗交互及光标反馈。
- macOS 欢迎页、项目标签、编辑器图标和断点展示更一致，测试结果增加类、方法与耗时。
- macOS 调试暂停与顶栏运行目标更连贯，关闭主项目窗口可返回欢迎页。
- macOS Agent 退出确认更清晰，命令中的 JSON 自动格式化，CLI 检查和更新反馈更明确。
- macOS 设置增加说明提示，欢迎页补充分支信息，终端配色随深浅主题切换。
- Windows 改进项目与提交面板交互，以及 Shelf 暂存内容恢复。
- Windows Spring 索引限制并发，并可取消扫描。
- macOS 和 Windows 统一日志分类与诊断信息，便于排查问题。

#### 🛠 修复

- macOS 终端聚焦时正确接收 Control 组合键，避免被全局快捷键拦截。
- Windows 终端选中文本后可用 Ctrl+C 复制。
- Windows 修复 Git 图谱断线、分叉与 HEAD 样式，以及撤销局部修改时的换行和文件末尾问题。
- macOS 修复插件市场安装确认、构建窗口和插件资源释放问题。
- macOS 修复设置说明不显示，以及部分源码断点、测试重跑与调试目标关联问题。

### 升级说明

- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。
- macOS Go/PHP 旧官方插件已迁移为社区版：先卸载旧版并重启，再从 Lithe Store 安装社区版。
- PHP 社区插件不再附带 Intelephense，请自行运行 `npm install -g intelephense` 安装。

### 兼容性与已知问题

- macOS 要求 13.0 或更新版本，提供 Apple Silicon 和 Intel 安装包；Windows 提供 x64 安装包。
- macOS 使用临时签名，尚无 Developer ID 签名和公证；Windows 安装包尚无 Authenticode 签名。
- 两个平台的自动更新均使用独立的更新签名。
- 新增 Agent 能力的真实供应商、订阅组合与完整恢复流程仍有待验证，具体能力以供应商支持为准。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

### Highlights

This release covers Agent, plugins, Java projects, editing, and everyday workflows across platforms.

#### ✨ New features

- Windows adds an Agent panel and editor conversation tabs, CLI settings, Codex login, and subscription usage.
- Windows Agent supports plans, reasoning, modes, slash commands, per-turn statistics, and follow-up instructions during replies.
- macOS Agent adds file context, model configuration, and expandable summaries for tasks, subagents, and changed files.
- Declarative build-tool plugins are supported; macOS can start plugin builds and display their build windows.
- Plugin developers can use a Node SDK, a sample build plugin, and plugin function calls.
- Java projects add Gradle import settings.
- Windows adds per-line Git history in the editor gutter and inserts project-tree file paths into terminals through copying or dragging.
- macOS adds an MCP server library, configurable terminal scrollback, and editor font sizes down to 8.
- macOS community plugins can be installed from disk, with a Restart Lithe action for pending changes.

#### ⚡ Improvements

- macOS loads project-tree directories on demand, updates external file changes incrementally, and excludes nested worktrees.
- macOS improves Git Log and terminal performance, with consistent branch-popup interactions and cursor feedback.
- macOS aligns welcome screens, project tabs, editor icons, and breakpoints; test results show classes, methods, and durations.
- macOS improves debugger pause and toolbar target behavior; closing the main project window can return to the welcome screen.
- macOS clarifies Agent exit confirmation, formats JSON in commands, and improves CLI check and update feedback.
- macOS adds settings help and welcome-screen branch details; terminal colors follow the light or dark theme.
- Windows improves project and commit panel interactions and Shelf restoration.
- Windows limits concurrent Spring indexing and supports cancelling scans.
- macOS and Windows unify log categories and diagnostics to help investigate problems.

#### 🛠 Fixes

- macOS terminals receive Control key combinations while focused, avoiding interception by global shortcuts.
- Windows terminals copy selected text with Ctrl+C.
- Windows fixes Git graph gaps, branches, and HEAD styling, plus line-ending and end-of-file issues during hunk rollback.
- macOS fixes marketplace installation confirmation, build windows, and plugin resource cleanup.
- macOS fixes missing settings help, plus source breakpoint, test rerun, and debug target association issues.

### Upgrade instructions

- macOS: open the DMG for your architecture and drag Lithe.app to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.
- macOS Go/PHP official plugins have moved to community packages: uninstall the old package, restart, then install from Lithe Store.
- The PHP community plugin no longer bundles Intelephense; install it yourself with `npm install -g intelephense`.

### Compatibility and known issues

- macOS requires 13.0 or later, with Apple Silicon and Intel installers; Windows installers target x64.
- macOS uses ad-hoc signing without Developer ID signing or notarization; Windows installers lack Authenticode signing.
- Both platforms use separate signatures for automatic updates.
- Some real-provider, subscription, and full recovery workflows for new Agent features remain unverified; capabilities depend on provider support.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
