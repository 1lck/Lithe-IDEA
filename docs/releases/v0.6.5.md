### 重点更新

本次更新内容如下。

#### ✨ 新功能

- macOS 新增项目创建向导，可使用插件提供的项目模板。
- macOS 新增 Linux SSH 连接管理，支持测试连接、浏览远程目录及编辑保存文件。
- macOS 的 Claude 与 Codex 官方订阅支持添加多个账号并手动切换。
- Claude 可选择官方订阅或 API Key 连接方式。
- Agent 设置新增 Codex 与 Claude Code 的 Hook 管理，可配置工具运行前后的动作。
- macOS 的 HTML 预览支持网页导航、缩放、页内查找、打印和导出 PDF。
- macOS 插件可提供原生界面和项目模板，SVN 改为独立社区插件。
- Windows 新增声明式插件的磁盘安装、启用管理、设置和独立网页工具窗口。
- Windows 支持在项目树和搜索结果按 F4 打开焦点文件，并保留匹配位置。

#### ⚡ 改进

- macOS 数据库改为从插件市场的 Lithe Store 安装 Database，已有连接与历史可迁入插件。
- Agent 对话改进长历史加载，并将每轮思考和工具过程合并为默认折叠的过程区。
- macOS Agent 显示工具返回的图片缩略图，支持点击放大和查看后台任务状态。
- macOS 改进 Claude Desktop 会话中的计划、待办事项与后台任务展示。
- 完善 Agent、技能、全局指令和 MCP 设置，Windows 补充会话与运行状态能力。
- macOS 设置窗口拖动与工作台更新分离，统一常用输入框、树列表和按钮样式。
- macOS 项目树按名称自然排序，隐藏路径可用同一模式列表管理。
- Windows 终端支持拖动停靠活动栏，并改善搜索快捷键。
- 统一双端中英文资源，减少界面语言切换后的翻译遗漏。

#### 🛠 修复

- 关闭项目、退出或更新前确认并结束运行服务，避免遗留后台进程。
- Git 推送使用正确的上游目标，大型未跟踪目录按目录汇总显示。
- Windows 修正 Diff 新增行颜色、文件导航顺序和预览标签行为。
- Windows 的 Ctrl+Z 优先恢复键盘移动后的光标位置。
- Java 方法调用补全默认留空参数，避免插入不需要的实参。
- macOS 终端退出 shell 后自动关闭标签，并同步主题及终端程序背景色。
- macOS 隐藏标题栏后仍可使用原生全屏，插件详情不再超出面板边界。
- macOS 恢复压缩过的 Claude 会话时保留较早用户消息中的截图。
- 修正 Agent 正文留白和 AI 设置排序。

### 升级说明

- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”；使用数据库的用户升级后请从 Lithe Store 安装 Database。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。

### 兼容性与已知问题

- macOS 需要 13.0 或更高版本，提供 Apple Silicon 与 Intel 安装包；Windows 安装包面向 x64。
- macOS 使用临时签名，尚无 Developer ID 签名或公证；Windows 安装包尚无 Authenticode 签名，自动更新使用独立签名。
- 数据库插件目前仅支持 macOS；首次使用请从 Lithe Store 安装 Database，旧版“直到重启”保存的密码需重新输入。
- macOS 远程开发目前仅接入 Linux SSH 文件浏览、编辑与保存，远程 Git、搜索、终端和构建尚未接入。
- macOS 的多账号界面、原生插件界面与项目向导尚未在 Windows 提供；Windows 插件构建能力与市场来源仍有限制。
- 部分 Agent、插件和真实 WebView2 交互仍待完整实机验收，不代表所有功能已双端一致。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

### Highlights

Changes are grouped below.

#### ✨ New features

- macOS adds a project creation wizard with templates supplied by plugins.
- macOS adds Linux SSH connection management, connection tests, remote folder browsing, and file editing and saving.
- macOS supports multiple Claude and Codex subscription accounts with manual switching.
- Claude connections can use either an official subscription or an API key.
- Agent settings add Codex and Claude Code Hook management for actions around tool execution.
- macOS HTML previews support navigation, zoom, in-page search, printing, and PDF export.
- macOS plugins can provide native interfaces and project templates; SVN is now a separate community plugin.
- Windows adds disk installation, enable/disable controls, settings, and separate web tool windows for declarative plugins.
- Windows adds F4 navigation from the project tree and search results, preserving the focused result location.

#### ⚡ Improvements

- macOS database features move to the Database plugin in Lithe Store, with migration for existing connections and history.
- Agent conversations improve long-history loading and group each turn’s reasoning and tool activity into a collapsed section.
- macOS Agent displays tool-image thumbnails with enlarged previews and shows background-task status.
- macOS improves plans, to-do lists, and background-task presentation in Claude Desktop sessions.
- Agent, skills, global instructions, and MCP settings improve; Windows gains additional conversation and execution-state capabilities.
- macOS separates settings-window dragging from workbench updates and unifies common fields, tree lists, and buttons.
- macOS project trees use natural name sorting, and hidden paths share one pattern list.
- Windows terminals support activity-bar drag docking and improve search shortcuts.
- Shared Chinese and English resources reduce missing translations when switching interface languages.

#### 🛠 Fixes

- Closing projects, quitting, or updating confirms and stops running services to avoid leftover background processes.
- Git pushes use the correct upstream target, and large untracked folders appear as directory summaries.
- Windows fixes added-line colors, file navigation order, and preview-tab behavior in diffs.
- Windows Ctrl+Z prioritizes restoring the cursor position after keyboard navigation.
- Java method-call completion leaves arguments empty instead of inserting unwanted values.
- macOS closes terminal tabs after shell exit and synchronizes themes and terminal-application background colors.
- macOS retains native fullscreen with hidden title bars and keeps plugin details within panel boundaries.
- macOS preserves screenshots from earlier user messages when restoring compacted Claude conversations.
- Fixes Agent message spacing and AI settings ordering.

### Upgrade instructions

- macOS: open the matching DMG and drag Lithe.app to Applications; database users should install Database from Lithe Store after upgrading.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.

### Compatibility and known issues

- macOS requires 13.0 or later, with Apple Silicon and Intel installers; Windows installers target x64.
- macOS uses ad-hoc signing without Developer ID signing or notarization; Windows installers lack Authenticode signing, while automatic updates use separate signatures.
- The Database plugin currently supports macOS only; install it from Lithe Store, and re-enter passwords previously stored only until restart.
- macOS remote development currently connects Linux SSH file browsing, editing, and saving; remote Git, search, terminals, and builds are not connected.
- The macOS multi-account interface, native plugin interfaces, and project wizard are not yet on Windows; Windows plugin build capabilities and marketplace sources remain limited.
- Some Agent, plugin, and real WebView2 interactions still await complete runtime acceptance; feature parity between platforms remains incomplete.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
