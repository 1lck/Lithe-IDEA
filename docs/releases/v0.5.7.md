### 重点更新

本次更新内容如下。

#### ✨ 新功能

- macOS 快捷键设置新增 macOS、IntelliJ IDEA Classic 和 Eclipse 预设，切换即时生效。
- 各预设分别保存自定义快捷键，恢复默认仅影响当前预设。

#### ⚡ 改进

- macOS 欢迎页统一深浅主题、最近项目和按钮样式，并改善窗口尺寸与布局。
- macOS 项目图标在标题栏、欢迎页和项目菜单中保持一致，项目配色便于辨认工作区。
- macOS 标题栏窗口按钮对齐，调整窗口或退出全屏后仍保持正确位置。
- macOS Agent 侧栏入口换用更清晰的对话图标。

#### 🛠 修复

- macOS 打开 Agent 对话不再因图标资源定位失败而闪退，缺少图标时显示默认图标。
- macOS 修正 Eclipse 预设的快捷键继承及 IntelliJ IDEA Classic 的停止运行快捷键。

### 升级说明

- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。

### 兼容性与已知问题

- macOS 需要 13 或更高版本；提供 Apple Silicon、Intel 和 Windows x64 安装包。
- 本版功能改动仅涉及 macOS，Windows 同步发布安装包。
- macOS 安装包尚未使用 Developer ID 签名或公证，Windows 安装包尚无 Authenticode 发布者签名；应用更新使用独立签名校验。
- Agent 对话仍仅在 macOS 提供，需要本地 CLI 与提供商配置；真实 Claude 端到端对话及 Codex 订阅额度显示仍待验证。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

Lithe 0.5.7 adds macOS keymap presets, refreshes the interface, and fixes a crash when opening Agent chat.

### Highlights

Changes are grouped below.

#### ✨ New features

- macOS keyboard settings now offer macOS, IntelliJ IDEA Classic, and Eclipse presets that take effect immediately.
- Each preset keeps its own custom shortcuts, and restoring defaults affects only the selected preset.

#### ⚡ Improvements

- macOS welcomes you with consistent light and dark styling, refreshed recent projects and buttons, and improved window sizing and layout.
- macOS uses consistent project icons across the title bar, welcome page, and project menu, with colors to distinguish workspaces.
- macOS window controls stay aligned in the title bar after resizing or leaving full screen.
- macOS gives the Agent sidebar entry a clearer chat icon.

#### 🛠 Fixes

- macOS no longer crashes when Agent chat cannot locate its icon resources; missing icons use a default icon.
- macOS fixes Eclipse preset shortcut inheritance and the IntelliJ IDEA Classic Stop Run shortcut.

### Upgrade instructions

- macOS: open the DMG for your architecture and drag Lithe.app to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.

### Compatibility and known issues

- macOS requires version 13 or later; installers are available for Apple Silicon, Intel, and Windows x64.
- Feature changes in this release apply to macOS; Windows receives a matching versioned installer.
- macOS packages are not Developer ID signed or notarized, and Windows installers lack an Authenticode publisher signature; app updates use separate signature verification.
- Agent chat remains macOS-only and requires local CLI and provider configuration; real Claude end-to-end chat and Codex subscription quota display remain unverified.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
