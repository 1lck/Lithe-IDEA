Lithe v0.5.10 改善 Windows Git 编辑与历史查看体验，让 Java 项目选择 JDK 和启动更可靠，并修复 macOS 中文输入重影。

### 重点更新

本次更新集中改善编辑、Git 操作和 Java 项目运行。

#### ✨ 新功能

- Windows 编辑器新增 Git 行边修改标记，点击可预览差异、切换修改块并暂存已保存的单块修改。
- Windows 工作区单文件差异支持确认后按块回滚，保留其他未暂存修改。
- 自动选择 JDK 时会考虑项目要求，优先使用兼容版本，并在没有兼容版本时提示。

#### ⚡ 改进

- Windows 单文件差异可展开省略的上下文，方便理解修改前后的代码。
- Windows Git Log 支持预览提交文件、调整并记住列宽，提交日期显示考虑时区。
- Windows 设置入口移至标题栏，底部面板默认全宽且可切换宽度，面板间距和文件树显示更清晰。
- Windows 标签页右键菜单将关闭操作置顶，减少查找步骤。
- 更新 README 微信群二维码，并统一问题反馈表单，方便交流和补充复现信息。

#### 🛠 修复

- macOS 中文组合输入不再透出下层原文字，避免输入时重影。
- Windows Git 提交详情显示完整的多行提交信息。
- Windows JDK 8 项目支持超长依赖路径，启动准备也不再阻塞界面。

### 升级说明

- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。
- JDK 自动选择可能改用更符合项目要求的版本；手动指定的 JDK 路径保持优先。

### 兼容性与已知问题

- macOS 需要 13 或更高版本，提供 Apple Silicon 和 Intel 安装包；Windows 提供 x64 安装包。
- macOS 安装包尚无 Developer ID 签名和公证，Windows 安装包尚无 Authenticode 签名；自动更新使用独立的更新签名。
- Windows 按块回滚仅支持符合条件的未暂存单文件差异；混合暂存修改及部分换行格式暂不支持。
- PHP 语言服务不随应用内置，本版不提供可在线安装的 PHP 插件包；使用时需另行安装兼容插件及 Node.js。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

Lithe v0.5.10 improves Git editing and history on Windows, makes Java JDK selection and launching more reliable, and fixes Chinese input ghosting on macOS.

### Highlights

This release focuses on editing, Git workflows, and running Java projects.

#### ✨ New features

- Windows Git gutter markers let you preview changes, navigate between them, and stage individual saved changes.
- Windows single-file workspace diffs support confirmed rollback of individual changes while preserving other unstaged edits.
- Automatic JDK selection considers project requirements, prefers compatible versions, and warns when none are available.

#### ⚡ Improvements

- Windows single-file diffs can expand omitted context to show surrounding code.
- Windows Git Log previews commit files, remembers resized column widths, and accounts for time zones when displaying dates.
- Windows moves settings to the title bar, defaults the bottom panel to adjustable full width, and improves panel spacing and file-tree readability.
- Windows tab context menus place close commands at the top for easier access.
- The README has an updated WeChat group QR code, and issue forms help contributors provide reproduction details.

#### 🛠 Fixes

- macOS Chinese composition no longer shows underlying text bleeding through the input area.
- Windows Git commit details display complete multiline commit messages.
- Windows JDK 8 projects support long dependency paths, and launch preparation no longer blocks the interface.

### Upgrade instructions

- macOS: open the DMG for your architecture and drag Lithe.app to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.
- Automatic JDK selection may choose a version better suited to your project; explicitly configured JDK paths retain priority.

### Compatibility and known issues

- macOS requires version 13 or later, with Apple Silicon and Intel installers; Windows installers target x64.
- macOS installers lack Developer ID signing and notarization, and Windows installers lack Authenticode signing; automatic updates use separate update signatures.
- Windows per-change rollback supports eligible unstaged single-file diffs; mixed staged changes and some line-ending formats are not supported.
- PHP language services are not bundled, and this release provides no online-installable PHP plugin archive; a compatible plugin and Node.js must be installed separately.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
