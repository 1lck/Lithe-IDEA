### 重点更新

本次重点是新桌面客户端及其工作流，具体语言和构建工具的支持由插件提供。

#### ✨ 新功能

- 在统一工作台中使用项目树、文件标签、文件与符号搜索，以及编辑器导航和草稿恢复。
- 从插件市场或本地安装插件，查看权限、管理语言服务，并安装插件声明的缺失命令。
- 从插件提供的项目模板创建工程，在同一处查看构建任务、依赖、运行输出和调试会话。
- 在编辑器旁预览 Markdown、HTML、SVG、PDF 和图片，Markdown 标题可在结构窗口导航。
- 在 Git 工具窗口查看变更、差异、提交历史、分支、工作树和写操作控制台。
- 在工作台使用 Agent 对话、终端和上下文工具，并从右侧通知窗口集中查看消息。
- 查看应用及相关进程的内存、CPU 和 GPU 信息，并导入 VS Code 或 IDEA 快捷键。

#### ⚡ 改进

- 每次运行拥有独立输出标签，控制台可显示命令输出中的 ANSI 颜色。
- 项目树与滚动列表显示滚动条，Git 跟踪分支菜单按远端和目录逐级展开。
- 本地历史规则改为列表管理，新建项目的字段说明收进提示，高级字段出错时自动展开。
- 正式版本与每日自动构建均提供相同的五个系统/芯片组合、12 种下载包及校验文件。

#### 🛠 修复

- 修复已安装插件列表点选后总是选中最后一项的问题。
- 修复 macOS 包签名结构、Linux RPM 运行库声明和安装包缺少原生内核的问题。
- 修复升级界面框架后，新建项目分组标题和 Git 分页、控制台占位行可能触发的崩溃。
- 修复项目树行名字以外区域的右键菜单，并保留调试配置中的自定义参数和包目录工作目录。

### 升级说明

- macOS：选择对应芯片的 DMG，将 `Lithe Desktop.app` 拖入“应用程序”；ZIP 也包含同一应用。
- Homebrew：仓库当前的 `lithe` 配方仍指向旧版 0.6.7；安装本版请使用上面的 DMG，不要用 `brew upgrade --cask lithe` 获取 0.7.0。
- Windows：运行 x64 安装程序，或将 ZIP 解压到独立目录后运行 `lithe.exe`。
- Linux：优先使用对应架构的 DEB/RPM，让包管理器安装声明的依赖；tar.gz 用户需要自行满足运行库要求。
- 从 0.6.x 迁移：先保留旧版和数据备份，在新客户端打开项目、重新核对设置并安装兼容插件；不承诺完整自动迁移或旧插件直接兼容。
- 本次使用独立的 `desktop-v0.7.0` 发布标签；为保护旧客户端的更新渠道，GitHub 仍标为 prerelease，程序内显示 `0.7.0`。当前发布流程没有配置签名更新源，请手动下载安装。

### 兼容性与已知问题

- macOS 最低为 13.0；分别提供 Apple Silicon 与 Intel 包，没有合并为通用包。
- Windows 提供 x64 包；Linux 提供 x64 与 ARM64 包，需要兼容的系统运行库和图形环境，并未验证所有发行版。
- 新客户端的功能仍在迁移，构建与包校验通过不代表旧版功能已全部对齐或所有原生工作流已完成验收。
- macOS 使用临时签名，没有 Apple Developer ID 证书及公证；Windows 安装包没有发行者签名，系统可能显示安全提示。

如果 macOS 提示无法打开 `Lithe Desktop.app`，可在“系统设置 → 隐私与安全性”中选择“仍要打开”，或在“应用程序”中按住 Control 点按应用并选择“打开”。如果仍被阻止，可执行 `xattr -dr com.apple.quarantine "/Applications/Lithe Desktop.app"`。旧版 `Lithe.app` 对应命令是 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

### Highlights

This release focuses on the new desktop client and its workflows; plugins provide support for particular languages and build tools.

#### ✨ New features

- Use the project tree, file tabs, file and symbol search, editor navigation and draft recovery in one workbench.
- Install plugins from the marketplace or local files, inspect permissions, manage language services and install declared missing commands.
- Create projects from plugin templates and access build tasks, dependencies, run output and debug sessions in one place.
- Preview Markdown, HTML, SVG, PDF and images beside the editor, with Markdown headings available in the Structure window.
- Browse changes, diffs, commit history, branches, worktrees and the write-operation console in the Git window.
- Use Agent conversations, terminals and context tools, with messages collected in the notification window on the right.
- Inspect memory, CPU and GPU information for the app and related processes, and import VS Code or IDEA keymaps.

#### ⚡ Improvements

- Each run has its own output tab, and consoles display ANSI output colors.
- Trees and scrolling lists show scrollbars; tracked-branch menus expand by remote and directory.
- Local-history rules use a list; project-field explanations use tooltips, and invalid advanced fields reveal their group automatically.
- Versioned releases and daily builds provide the same five system/processor targets, 12 packages and checksum files.

#### 🛠 Fixes

- Selecting an installed plugin no longer always selects the final row.
- Fix macOS package signature structure, Linux RPM runtime dependencies and packages missing the native core.
- Prevent invalid project-group, Git pagination and console placeholder identities from crashing after the framework upgrade.
- Restore project-tree context menus outside row names and preserve custom debug arguments and package-directory working directories.

### Upgrade instructions

- macOS: open the DMG for your processor and drag `Lithe Desktop.app` to Applications; the ZIP contains the same app.
- Homebrew: the repository's `lithe` cask still points to 0.6.7; use the DMG above for 0.7.0 instead of `brew upgrade --cask lithe`.
- Windows: run the x64 installer, or extract the ZIP into its own directory and run `lithe.exe`.
- Linux: prefer the DEB/RPM for your processor so the package manager installs declared dependencies; tar.gz users must provide runtime libraries themselves.
- Migrating from 0.6.x: retain the older client and a data backup, open projects in the new client, review settings and install compatible plugins; complete automatic migration and old-plugin compatibility are not promised.
- This release uses the separate `desktop-v0.7.0` tag; GitHub retains its prerelease flag to protect the older clients' update channel, while the app displays `0.7.0`. The current publishing workflow does not configure a signed update feed; download and install manually.

### Compatibility and known issues

- macOS requires 13.0 or later, with separate Apple Silicon and Intel packages rather than a universal binary.
- Windows packages target x64; Linux packages target x64 and ARM64 and require compatible runtime libraries and graphics support; not every distribution is validated.
- Feature migration continues; successful builds and package checks do not establish complete parity or acceptance of every native workflow.
- macOS uses ad-hoc signing without an Apple Developer ID certificate or notarization; Windows installers lack publisher signing and may trigger security prompts.

If macOS blocks `Lithe Desktop.app`, choose Open Anyway in System Settings → Privacy & Security, or Control-click it in Applications and choose Open. If it remains blocked, run `xattr -dr com.apple.quarantine "/Applications/Lithe Desktop.app"`. For the older `Lithe.app`, the command is `xattr -dr com.apple.quarantine /Applications/Lithe.app`. Use these only for an app from a source you trust.
