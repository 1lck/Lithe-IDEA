### 重点更新

本次重点是代码导航和问题排查窗口、更多语言的语法高亮，以及服务调试。

#### ✨ 新功能

- 查找用法改为按文件分组的结果树，右侧预览会高亮文件中的全部用法。
- 在编辑器中右键点一个符号，即可查找它的用法。
- 问题窗口可在“当前文件”和“整个项目”之间切换，问题按文件分组并显示行号。
- 问题窗口的预览按严重程度着色，可以直接在预览里修改代码。
- 状态栏左侧显示导航路径，跟随编辑器、项目树和问题窗口的当前项。
- 编辑器新增 Python、Shell、Kotlin、PHP、SQL 等 18 种语言的语法高亮。
- 服务类运行配置可以调试，使用其他插件提供的对应类型调试器。
- 插件设置可以按模块逐个配置源目录、依赖等条目，条目可以增删和排序。

#### ⚡ 改进

- 项目树为 Lua、Zig、Protobuf、GraphQL 和 CMake 文件显示专用图标。
- 问题窗口中选中行的颜色加深，更容易看清。
- 运行和调试构建插件的目标时，使用设置中指定的构建工具路径。

#### 🛠 修复

- Windows 上打开依赖或反编译的源码后，标签页和窗口可以正常关闭。
- 打开工作区外的文件时不再提示最近文件记录失败。
- 长时间运行的服务满 30 分钟后不再被自动结束。
- 安装、启用或停用插件后，可用的调试器列表会及时更新。
- 没有运行配置时，“编辑运行配置…”会说明原因，并显示被隐藏的已保存配置数量。
- 插件设置在语言服务器不可用时显示具体原因，并允许重启语言服务器。
- 保存工具链设置后，相同的语言服务器启动失败不再重复弹出通知。
- 刚打开内存详情时，CPU 和 GPU 占用率不再短暂显示过高。

### 升级说明

- 已安装 0.8.3：在标题栏的更新入口或“设置 → 更新”中检查更新，即可在应用内更新到本版；更早的版本会下载完整安装包。
- Windows 0.8.0 无法在应用内完成更新，请下载本版安装程序手动安装。
- macOS：也可选择对应芯片的 DMG，将 `Lithe Desktop.app` 拖入“应用程序”。
- Homebrew：配方更新到本版后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：运行 x64 安装程序，或将 ZIP 解压到独立目录后运行 `lithe.exe`。
- Linux：使用对应架构的 DEB/RPM；tar.gz 用户需要自行满足运行库要求。

### 兼容性与已知问题

- macOS 最低为 13.0，分别提供 Apple Silicon 和 Intel 包；Windows 桌面端提供 x64 包。
- Linux 提供 x64 和 ARM64 包，需要兼容的运行库和图形环境，未验证所有发行版。
- 自动生成运行配置、调试服务、隐藏 `target`、`node_modules` 等目录需要启用对应的语言或构建插件。
- 新客户端的功能迁移仍在进行，部分旧版功能尚未完全对齐。
- macOS 使用临时签名且未公证，Windows 安装包没有发行者签名，系统可能显示安全提示。

如果 macOS 提示无法打开 `Lithe Desktop.app`，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可执行 `xattr -dr com.apple.quarantine "/Applications/Lithe Desktop.app"`。旧版 `Lithe.app` 对应命令是 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

### Highlights

This release focuses on navigation and problem windows, syntax highlighting for more languages, and service debugging.

#### ✨ New features

- Find Usages now shows a results tree grouped by file, with a preview that highlights every usage.
- Right-click a symbol in the editor to find its usages.
- The Problems window switches between Current File and Project, groups problems by file and shows line numbers.
- The Problems preview is colored by severity and can be edited directly.
- The left of the status bar shows a navigation path that follows the editor, project tree and Problems window.
- The editor adds syntax highlighting for 18 languages, including Python, Shell, Kotlin, PHP and SQL.
- Service run configurations can be debugged with a matching debugger provided by another plugin.
- Plugin settings can configure source folders, dependencies and other entries per module, with add, remove and reorder.

#### ⚡ Improvements

- The project tree shows dedicated icons for Lua, Zig, Protobuf, GraphQL and CMake files.
- The selected row in the Problems window is darker and easier to see.
- Running and debugging build plugin targets uses the build tool path set in Settings.

#### 🛠 Fixes

- On Windows, tabs and windows close normally after opening dependency or decompiled sources.
- Opening a file outside the workspace no longer reports a recent files error.
- Long-running services are no longer stopped automatically after 30 minutes.
- The list of available debuggers updates after a plugin is installed, enabled or disabled.
- With no run configurations, "Edit Run Configurations…" explains why and shows how many saved ones are hidden.
- Plugin settings show why a language server is unavailable and allow restarting it.
- Saving toolchain settings no longer repeats the same language server startup failure notice.
- CPU and GPU usage no longer spikes briefly when the memory details first open.

### Upgrade instructions

- From 0.8.3: check for updates from the title-bar update entry or Settings → Updates to update in-app; earlier versions download the full package.
- Windows 0.8.0 cannot finish an in-app update; download and run this release's installer instead.
- macOS: or open the DMG for your processor and drag `Lithe Desktop.app` to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask is updated to this release.
- Windows: run the x64 installer, or extract the ZIP into its own directory and run `lithe.exe`.
- Linux: use the DEB/RPM for your architecture; tar.gz users must provide the required runtime libraries.

### Compatibility and known issues

- macOS requires 13.0 or newer, with separate Apple Silicon and Intel packages; the Windows desktop package targets x64.
- Linux packages target x64 and ARM64, requiring compatible libraries and a graphical environment; not every distribution is verified.
- Generated run configurations, service debugging and hiding folders such as `target` and `node_modules` need the matching language or build plugin enabled.
- Feature migration continues; some features of the older client are not yet at full parity.
- macOS packages use ad hoc signing without notarization; Windows installers have no publisher signature and may trigger system prompts.

If macOS cannot open `Lithe Desktop.app`, Control-click it in Applications and choose Open. If it remains blocked, run `xattr -dr com.apple.quarantine "/Applications/Lithe Desktop.app"`. For the older `Lithe.app`, use `xattr -dr com.apple.quarantine /Applications/Lithe.app`. Use these commands only for an app from a source you trust.
