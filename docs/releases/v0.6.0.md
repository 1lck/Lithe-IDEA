### 重点更新

本次更新覆盖编辑、项目导航、Git、Java 运行与调试，以及 macOS Agent 的配置和重连。

#### ✨ 新功能

- macOS 编辑器支持搜索和选择等宽字体，并同步应用到主要差异视图。
- 通知列表会合并重复消息并显示次数，减少相同通知反复占位。
- macOS 项目树右键菜单新增全项目查找和替换入口。
- Windows 支持从菜单和项目树创建 Java 类型、包及 package-info 文件。
- Windows 为 Spring 配置文件提供属性名称补全与说明。
- Windows Git 支持在选定提交创建标签，以及删除本地标签。
- Windows 新增编辑器代码缩略图开关，并保留用户选择。
- Windows 可将当前运行输出保存为只读编辑器快照，继续查看和搜索已被实时输出淘汰的内容。

#### ⚡ 改进

- Windows 字体设置支持搜索已安装字体、调整字号和连字，并提供实时预览。
- Windows Git 提交图优化分支配色、祖先高亮和长连线显示。
- Windows Git 差异视图显示变更数量，并支持跨文件跳转到上一个或下一个变更。
- Windows Git 拉取远端信息时保留当前页面并显示进度，提交列表支持更完整的键盘操作。
- Windows 常规分支切换和本地标签删除减少确认步骤，分支更新操作更加完整。
- Windows 英文 Git 日志使用系统日期与时间格式，Islands 主题的选中状态更加清晰。
- Windows 窗口标题显示项目和当前文件，并区分同名项目的不同路径。
- Windows 编辑器和笔记本滚轮响应更快，快速打开搜索更完整，数值设置按钮更易点击。
- macOS 分支菜单支持调整并记住尺寸，悬停可查看完整分支名，项目菜单更易读。
- macOS Agent 临时连接错误会显示有界重试进度，无效密钥等永久错误更快给出反馈。
- Agent 长任务不再因固定总时限被强制中断，长时间无输出时会显示静默提醒。
- macOS 优化 Commit 与 Stash 面板，统一差异查看和文件导航。
- Windows 改善 Git 面板、滚轮滚动和终端链接打开体验。

#### 🛠 修复

- macOS 减少打开项目时工具版本探测造成的界面卡顿。
- macOS 修复项目树方向键焦点和文件夹双击展开行为。
- macOS 修复外部修改 Codex 或 Claude 配置后，Agent 使用过期连接信息的问题。
- macOS 修复新建 Agent 提供商时模型默认值混用，并保留已有的手动配置。
- macOS 恢复 Agent 提供商品牌图标，并避免选择菜单被底部状态栏遮挡。
- macOS 补齐内置 Starship 字体图标，修正 TOML 文件图标和 Git 上游提交计数。
- Windows 修复部分 Java 主类无法从文件菜单创建或运行配置的问题。
- Windows 修复 Java 调试启动、断点、暂停位置和停止后的状态清理。
- Windows 修复 Git 日志翻页顺序，并减少提交详情在刷新时重复加载或丢失内容。
- Windows 修复字体列表遗漏用户安装字体，以及加载期间已选字体丢失的问题。
- Maven 项目运行前同步资源文件，避免修改配置后仍加载旧内容，并在处理失败时停止启动。
- 切换远程分支时使用最新获取的提交，Windows 恢复正确的本地化成功提示。
- Windows 修复整文件 Git 差异重复显示，以及调试断点路径不一致的问题。
- Windows 在 Java 适配器就绪后刷新 Spring 依赖。
- Agent 已完成部分工作后恢复会话，不再被提前取消。
- macOS 修复切换差异文件后滚动条变更标记未刷新的问题。

### 升级说明

- **旧客户端必须手动下载安装本版本**：更新器和官方插件签名密钥已轮换，旧客户端无法信任新签名。
- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。
- macOS：通用“添加提供商”入口需要明确填写模型，已有的手动配置会保留。
- Windows：常规分支切换和本地标签删除会直接执行，受保护的切换场景仍保留确认。

### 兼容性与已知问题

- macOS 要求 13.0 或更新版本，提供 Apple Silicon 和 Intel 安装包；Windows 提供 x64 安装包。
- macOS 安装包使用临时签名，尚未提供 Developer ID 签名和公证；Windows 安装包尚未提供 Authenticode 签名。
- macOS 和 Windows 自动更新使用各自的更新签名，与系统应用签名独立。
- macOS 新增的编辑器字体选择不影响终端和输出面板字体。
- Windows 重复通知合并作用于通知列表，独立弹出的通知仍会逐条显示。
- Windows 新增 Java 文件和包创建入口，本次不包含项目向导或模块创建。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

### Highlights

This release covers editing, project navigation, Git, Java running and debugging, and macOS Agent configuration and reconnection.

#### ✨ New features

- macOS lets you search and select a monospaced editor font, also applied to the main diff views.
- Notification lists group repeated messages and show their count to reduce clutter.
- macOS adds project-wide Find and Replace to the project tree context menu.
- Windows lets you create Java types, packages, and package-info files from menus and the project tree.
- Windows adds property name completion and descriptions for Spring configuration files.
- Windows Git lets you create tags at selected commits and delete local tags.
- Windows adds an editor minimap toggle and remembers your choice.
- Windows can freeze current run output into a read-only editor snapshot for continued reading and searching.

#### ⚡ Improvements

- Windows font settings support installed-font search, size and ligature controls, and a live preview.
- Windows improves Git graph branch colors, ancestor highlighting, and long connection visibility.
- Windows Git diff views show change counts and let you navigate between changes across files.
- Windows Git Fetch preserves the current page with progress feedback, while commit lists gain more keyboard controls.
- Windows reduces confirmations for ordinary branch checkouts and local tag deletion, and improves branch update operations.
- Windows English Git logs follow system date and time formats, and the Islands theme shows selections more clearly.
- Windows titles show the project and current file, distinguishing same-named projects by their paths.
- Windows improves editor and notebook scrolling, Quick Open search coverage, and numeric setting controls.
- macOS branch menus remember resized dimensions, reveal full branch names on hover, and make project menus easier to read.
- macOS Agent shows bounded retries for temporary connection errors and reports permanent errors, such as invalid keys, sooner.
- Agent long tasks are no longer stopped by a fixed total deadline and show a notice during extended silence.
- macOS improves Commit and Stash panels with consistent diff viewing and file navigation.
- Windows improves Git panels, wheel scrolling, and opening terminal links.

#### 🛠 Fixes

- macOS reduces interface stalls caused by tool version checks when opening projects.
- macOS fixes arrow-key focus and folder expansion by double-click in the project tree.
- macOS fixes stale Agent connection settings after external changes to Codex or Claude configuration.
- macOS fixes mixed-up model defaults when adding Agent providers and preserves existing manual configuration.
- macOS restores Agent provider brand icons and prevents the selector from being obscured by the bottom status bar.
- macOS restores bundled Starship font icons and corrects TOML file icons and Git upstream commit counts.
- Windows fixes some Java main classes being unavailable when creating or running configurations from file menus.
- Windows fixes Java debugger startup, breakpoints, paused locations, and state cleanup after stopping.
- Windows fixes Git log pagination order and reduces unnecessary reloads or lost content in commit details.
- Windows fixes missing user-installed fonts and selected fonts disappearing while the font list loads.
- Maven runs refresh resource files before launch, avoiding stale configuration and stopping launch if resource processing fails.
- Remote branch checkout uses the latest fetched commit, and Windows restores localized success notifications.
- Windows fixes duplicate full-file Git diffs and inconsistent debugger breakpoint paths.
- Windows refreshes Spring dependencies when the Java adapter becomes ready.
- Agent session recovery is no longer cancelled prematurely after partial work.
- macOS refreshes scrollbar change markers when switching diff files.

### Upgrade instructions

- **Older clients must download and install this version manually**: updater and official plugin signing keys have rotated, so older clients cannot trust the new signatures.
- macOS: open the DMG for your architecture and drag Lithe.app to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.
- macOS: the generic Add Provider form requires an explicit model; existing manual configuration is preserved.
- Windows: ordinary branch checkouts and local tag deletion execute directly, while protected checkout scenarios still require confirmation.

### Compatibility and known issues

- macOS requires version 13.0 or later, with Apple Silicon and Intel installers; Windows installers target x64.
- macOS installers use ad-hoc signing without Developer ID signing or notarization; Windows installers do not yet have Authenticode signing.
- macOS and Windows automatic updates use their respective update signatures, independently of operating-system application signing.
- The new macOS editor font selection does not change terminal or output panel fonts.
- Windows groups repeated notifications in the notification list; individual notification popups still appear separately.
- Windows adds Java file and package creation; project wizards and module creation are outside this release.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
