## 中文

本次小版本改进 Git 操作记录与搜索替换体验，并修复 Windows 菜单导致工作区黑屏的问题。

### 重点更新

本次更新内容如下。

#### ✨ 新功能

- Git 控制台集中保留项目操作记录，支持搜索、展开、复制完整输出和停止操作。
- Git 设置支持选择可执行文件、查看配置来源，并调整项目和单次 Fetch 选项。

#### ⚡ 改进

- Git 认证支持重试与取消，多远程 Fetch 可查看各远程结果和具体失败原因。
- macOS 搜索替换面板更紧凑，项目替换预览支持调整大小并对照替换前后的文本。

#### 🛠 修复

- macOS 搜索预览不再产生多余标签，编辑后会提示重新搜索，避免跳转过期结果。
- macOS 搜索预览保存时保护外部文件修改，并保留文本快捷键与输入法取消行为。
- Windows 打开服务多选或 Git 仓库菜单不再因菜单错误导致工作区黑屏。

### 升级说明

- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。

### 兼容性与已知问题

- macOS 需要 13 或更高版本；Windows 安装包未配置发布者证书，系统可能显示提示。
- macOS 项目替换目前提供预览和手动编辑保存，不支持在该弹窗中批量应用替换。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

## English

This patch improves Git operation history and search and replace, and fixes Windows menus that could blank the workbench.

- [Project homepage](https://github.com/1lck/Lithe-IDEA)

### Highlights

Changes are grouped below.

#### ✨ New features

- The Git console keeps project operation history with search, expandable details, full-output copying, and cancellation.
- Git settings let you choose an executable, inspect configuration sources, and adjust project and per-operation Fetch options.

#### ⚡ Improvements

- Git authentication supports retry and cancellation; multi-remote Fetch shows individual results and specific failure reasons.
- macOS search and replace panels are more compact, with resizable project replacement previews showing before-and-after text.

#### 🛠 Fixes

- macOS search previews no longer create extra tabs, and edits prompt a new search to prevent navigation to stale results.
- macOS search previews protect external file changes when saving and preserve text shortcuts and input-method cancellation.
- Windows service selection and Git repository menus no longer blank the workbench because of menu errors.

### Upgrade instructions

- macOS: open the DMG for your architecture and drag Lithe.app to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.

### Compatibility and known issues

- Requires macOS 13 or later; the Windows installer has no publisher certificate and may show a system warning.
- macOS project replacement currently supports previews and manual editing and saving; the dialog does not apply replacements in bulk.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
