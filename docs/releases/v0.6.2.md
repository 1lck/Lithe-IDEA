### 重点更新

本次更新覆盖 Agent、调试与测试、Git、进程管理和 Windows 编辑体验。

#### ✨ 新功能

- macOS Agent 回复过程中可以继续发送补充要求，Agent 会在同一会话里接着处理。
- macOS Agent 历史页可以查看并恢复已归档的 Codex 会话。
- macOS Agent 对话右侧新增轮次导航，悬停预览问答摘要，点击跳到对应提问。
- macOS 退出 Lithe 时会结束本次启动的运行程序、语言服务和插件进程，后台服务和仍在运行的终端会先询问你。
- macOS 调试变量可直接以格式化 JSON 查看并一键复制，也可切回树形视图。
- macOS 测试面板新增性能视图，可查看测试运行期间的 JVM 数据。
- macOS 分支弹窗可直接更新未检出的本地分支，无需先切换过去。
- Windows 可使用 Maven Daemon（mvnd）构建项目，自动识别安装目录和环境变量。
- Windows 编辑器字体新增内置 JetBrains Mono。

#### ⚡ 改进

- macOS Agent 恢复紧凑对话布局，输入框随内容自动增高，宽窗口下对话居中显示。
- macOS Agent 历史会话会显示上下文用量，订阅连接也可查看模型调用统计。
- macOS Agent 添加供应商改用表单填写名称、密钥、地址和模型，也可切回编辑配置文本。
- macOS Agent 回复中的加粗、表格显示更准确，表格可单独复制并粘贴到表格软件。
- macOS Agent 本机导入的 Claude/Codex 供应商可开启“允许不安全的 HTTP”连接 HTTP 地址。
- Agent CLI 只在确实有新版本时显示“更新”按钮，已是最新时会明确提示。
- macOS 调试面板、调用栈和监视表达式布局更紧凑，与其他工具窗口样式一致。
- macOS 测试面板重新排布工具栏、测试树和结果摘要，失败与通过状态一目了然。
- macOS 运行、调试和测试共用同一套控制台样式，日志级别以不同颜色标出。
- macOS 问题面板可在当前文件和整个项目之间切换，并统一图标与源码预览。
- macOS Git Log 的工作树页与其他工具窗口样式保持一致。
- AutoBuild 改为独立安装为 Lithe-Dev，与正式版分开保存设置、缓存和凭据。

#### 🛠 修复

- macOS 修复切换 Agent 模式后仍显示过期自动模式提示的问题。
- macOS 修复 Agent 尚未上报用量时显示空圆环、容易误以为占用为 0 的问题。
- macOS 修复打开分支下拉框时切换应用或窗口失焦导致崩溃的问题。
- macOS 修复非等宽字体出现在编辑器字体列表中、导致对齐错乱的问题。
- macOS 修复工具窗口向右拖动时位置总是跳到末尾的问题。
- Windows 修复撤销修改后保存未写入磁盘、Git 仍显示有改动的问题。
- Windows 修复新建标签页不显示的问题，现在会打开空白未命名编辑器。
- Windows 编辑器标签右键菜单补上“关闭已保存”。
- Windows 修复设置对话框打开后整体发虚的问题。
- Windows 移除始终显示“不可用”的 Codex 集成设置入口。

### 升级说明

- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。
- 如果之前在正式版里切换到了 AutoBuild 更新渠道，请改回正式版渠道；AutoBuild 现在会作为独立的 Lithe-Dev 安装。

### 兼容性与已知问题

- macOS 要求 13.0 或更新版本，提供 Apple Silicon 和 Intel 安装包；Windows 提供 x64 安装包。
- macOS 安装包使用临时签名，尚未提供 Developer ID 签名和公证；Windows 安装包尚未提供 Authenticode 签名。
- macOS 和 Windows 自动更新使用各自的更新签名，与系统应用签名独立。
- 退出时清理进程、调试 JSON 视图、测试性能视图和 Agent 新增功能本次仅在 macOS 提供。
- Agent 归档会话目前只支持 Codex。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

### Highlights

This release covers Agent, debugging and testing, Git, process management, and Windows editing.

#### ✨ New features

- macOS Agent accepts follow-up instructions while it is replying and continues in the same conversation.
- macOS Agent history can show and restore archived Codex conversations.
- macOS Agent adds turn navigation on the right, previewing each exchange on hover and jumping to it on click.
- macOS quitting Lithe ends the programs, language services, and plugin processes it started, asking first about background services and busy terminals.
- macOS debugger variables can be viewed and copied as formatted JSON, or switched back to the tree view.
- macOS Test panel adds a performance view showing JVM data while tests run.
- macOS branch popup can update a local branch that is not checked out, without switching to it.
- Windows can build projects with Maven Daemon (mvnd), detecting its install directory and environment variables.
- Windows adds bundled JetBrains Mono as an editor font.

#### ⚡ Improvements

- macOS Agent restores the compact conversation layout, grows the input with its content, and centers conversations in wide windows.
- macOS Agent history shows context usage, and subscription connections can show model call statistics.
- macOS Agent adds providers through a form for name, key, address, and model, with the config text still available.
- macOS Agent renders bold text and tables more accurately, and tables can be copied into spreadsheet apps.
- macOS Agent lets locally imported Claude/Codex providers enable Allow insecure HTTP to connect to HTTP addresses.
- Agent CLIs show Update only when a newer version exists, and say clearly when they are up to date.
- macOS Debug panel, call stack, and watches are more compact and match other tool windows.
- macOS Test panel reorganizes its toolbar, test tree, and result summary so failures and passes stand out.
- macOS Run, Debug, and Test share one console style, with log levels shown in different colors.
- macOS Problems panel switches between the current file and the whole project, with unified icons and source previews.
- macOS Git Log Worktrees page now matches the style of other tool windows.
- AutoBuild now installs separately as Lithe-Dev, keeping its settings, caches, and credentials apart from the stable app.

#### 🛠 Fixes

- macOS fixes an outdated Auto mode notice remaining after switching Agent modes.
- macOS fixes an empty usage ring appearing before Agent reports usage, which looked like 0% usage.
- macOS fixes a crash when switching apps or windows while the branch dropdown is open.
- macOS fixes non-monospaced fonts appearing in the editor font list and breaking alignment.
- macOS fixes tool windows jumping to the end when dragged to the right.
- Windows fixes undo changes not being written on save, leaving Git showing the file as modified.
- Windows fixes New Tab showing nothing; it now opens a blank untitled editor.
- Windows adds Close Saved to the editor tab context menu.
- Windows fixes the Settings dialog looking blurry after it opens.
- Windows removes the Codex integration settings entry that always showed as unavailable.

### Upgrade instructions

- macOS: open the DMG for your architecture and drag Lithe.app to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.
- If you switched the stable app to the AutoBuild update channel earlier, switch it back to Stable; AutoBuild now installs separately as Lithe-Dev.

### Compatibility and known issues

- macOS requires version 13.0 or later, with Apple Silicon and Intel installers; Windows installers target x64.
- macOS installers use ad-hoc signing without Developer ID signing or notarization; Windows installers do not yet have Authenticode signing.
- macOS and Windows automatic updates use their respective update signatures, independently of operating-system application signing.
- Process cleanup on quit, the debugger JSON view, the test performance view, and the new Agent features are available on macOS only in this release.
- Archived Agent conversations are currently supported for Codex only.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
