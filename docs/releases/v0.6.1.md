### 重点更新

本次更新覆盖插件、工作台布局、数据库、Agent 和 Windows 设置。

#### ✨ 新功能

- 新增 UTF-16、Big5、日文、韩文和西里尔文等编码的读取与保存支持。
- Windows 可将运行输出保存为只读快照标签，方便搜索和保留日志。
- macOS 新增插件市场，可搜索、安装、更新和卸载插件，并查看作者、来源仓库、版本和许可证。
- macOS 预置社区插件源 [Lithe Store](https://github.com/Lithe-IDEA/Lithe-store)，也可以添加其他插件仓库地址。
- 首个社区插件 [Lua Support](https://github.com/Lithe-IDEA/lithe-plugin-lua) 已上架 Lithe Store，自带语言服务器，提供 Lua 补全、跳转、诊断和运行当前文件。
- macOS 官方 PHP Support 和 Go Support 改为从插件市场安装，之后可独立于 Lithe 版本更新。
- macOS 工具窗口可拖到左侧、右侧和底部共六个位置，并按项目记住位置、顺序和大小。
- macOS 编辑器标签可拖到另一组，或拖到编辑区四周创建分屏。
- macOS Agent 输入框上方新增会话状态栏，显示轮次、生成速度、Token 用量、缓存命中和上下文占用。
- macOS 数据库改为右侧独立工具窗口，每个连接使用一个编辑器标签，并记住页面、所选表和 SQL 草稿。

#### ⚡ 改进

- macOS Agent 对话可拖入编辑区，支持复制消息和整段对话，历史会话保留用量统计。
- macOS Agent 优化模型选择、Markdown 回复、工具调用和思考内容的呈现。
- macOS 统一运行、提交和暂存面板样式，改善差异查看与导航。
- 设置新增独立 AI 分组，更新页可选择正式版或 AutoBuild，并显示构建时间。
- Java 运行前同步 Maven 资源，避免修改配置文件后仍读取旧内容。
- Java 语言服务提高内存上限，并随 macOS 内置 Java Support 插件提供。
- Windows 改善 Git 面板滚动、仓库状态同步和终端链接打开体验。
- macOS 社区插件安装前会核对安装包校验值，并列出权限、要运行的程序和来源仓库供你确认。
- macOS 插件启用和停用立即生效，不再需要重启。
- macOS 设置入口移到右上角菜单，可直接打开设置、插件、主题和快捷键。
- macOS 空编辑区会提示“全局搜索”和“在项目中查找”的当前快捷键。
- macOS 各列表和树的选中行统一为聚焦时显示主题色，失焦或窗口不活动时显示灰色。
- macOS 数据表格单击立即选中，新增、修改和删除的行以不同颜色标示，列宽按内容自动分配。
- macOS 数据库各页面、连接树、图标和连接编辑弹窗统一为与其他工具窗口一致的样式。
- Windows 设置界面统一控件、分类和中英文文案，支持调整分类栏宽度，并在切换页面时保留未提交的修改。
- Windows 项目 JDK 和 Maven 路径可从候选中选择或输入任意路径，清空后恢复自动配置。

#### 🛠 修复

- macOS 修复 Agent 长会话权限提示导致界面卡死，以及 Claude 重连后模型显示不一致。
- Agent 长任务不再被固定时限中断，恢复已有会话时避免提前结束。
- Java 修复测试目录中的 main 入口启动失败，非 UTF-8 源码不再影响整个运行列表。
- 修复检出远程分支后未更新至最新提交的问题。
- Windows 修复连续编辑期间自动保存遗漏最新内容的问题。
- Windows 修复断点标记不一致、Spring 依赖未刷新和重复显示整文件差异的问题。
- macOS 修复从程序坞或访达启动 Lithe 时，PHP 语言服务器因找不到 Node.js 而无法启动的问题。
- macOS 修复在同一文件内“跳转到定义”时光标不移动的问题。
- macOS 修复应用异常退出后，已安装的插件被误停用的问题。
- macOS 修复数据库新增行有时不显示，以及快速切换连接时页面被迟到的结果切回的问题。
- 修复 SQLite 表的主键信息无法正确识别的问题。
- Windows 修复主题切回“跟随系统”后，窗口外观仍停留在手动选择的主题的问题。
- Windows 修复交互式变基停在编辑步骤时，偶尔被误报为已中断的问题。

### 升级说明

- macOS：打开对应架构的 DMG，将 Lithe.app 拖入“应用程序”。
- Homebrew：新版配方更新后，运行 `brew update && brew upgrade --cask lithe`。
- Windows：下载并运行 x64 安装包。
- macOS：Go Support 不再随应用内置，旧版 PHP Support 也不再加载；升级后请在“设置 → 插件 → 插件市场”中重新安装。
- macOS：使用 API 密钥连接 Agent 时默认开启“模型调用统计”，请求会经过本机的统计通道；可在 Agent 设置中关闭，重新连接后生效。

### 兼容性与已知问题

- macOS 要求 13.0 或更新版本，提供 Apple Silicon 和 Intel 安装包；Windows 提供 x64 安装包。
- macOS 安装包使用临时签名，尚未提供 Developer ID 签名和公证；Windows 安装包尚未提供 Authenticode 签名。
- macOS 和 Windows 自动更新使用各自的更新签名，与系统应用签名独立。
- 插件市场、Lithe Store、工具窗口停靠、编辑器分屏和 Agent 会话状态栏本次仅在 macOS 提供。
- 社区插件由各自的开发者维护且不带 Lithe 签名，请只安装来源可信的插件。
- Lua Support 目前只提供 macOS 安装包；运行 Lua 文件需要本机已安装 `lua`。
- Agent 的步骤数、生成速度和上下文构成只在使用 API 密钥连接并开启“模型调用统计”时显示，上下文构成为估算值。
- 依赖企业自签根证书访问模型服务的网络，可能需要关闭“模型调用统计”。

如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

### Highlights

This release covers plugins, workbench layout, databases, Agent, and Windows settings.

#### ✨ New features

- Adds reading and saving for UTF-16, Big5, Japanese, Korean, and Cyrillic text encodings.
- Windows can freeze run output in a read-only snapshot tab for searching and retaining logs.
- macOS adds a plugin marketplace to search, install, update, and uninstall plugins, showing author, source repository, version, and license.
- macOS includes the [Lithe Store](https://github.com/Lithe-IDEA/Lithe-store) community plugin source, and you can add other plugin repository addresses.
- [Lua Support](https://github.com/Lithe-IDEA/lithe-plugin-lua), the first community plugin, is listed in Lithe Store with a bundled language server for Lua completion, navigation, diagnostics, and running the current file.
- macOS installs the official PHP Support and Go Support plugins from the marketplace, so they can update independently of Lithe.
- macOS tool windows can be dragged to six positions on the left, right, and bottom, with position, order, and size remembered per project.
- macOS editor tabs can be dragged to another group, or to an edge of the editor area to create a split.
- macOS Agent adds a session status bar above the input, showing turns, generation speed, token usage, cache hits, and context usage.
- macOS moves Database to its own tool window on the right, with one editor tab per connection that remembers its page, selected table, and SQL draft.

#### ⚡ Improvements

- macOS Agent conversations can move into the editor, copy messages or entire conversations, and retain usage statistics across history loads.
- macOS Agent improves model selection, Markdown replies, tool calls, and thinking content.
- macOS aligns Run, Commit, and Stash panels and improves diff viewing and navigation.
- Settings adds an AI group; updates offer Stable and AutoBuild channels and show build times.
- Java runs synchronize Maven resources first, so configuration changes reach the launched application.
- Java language services have a higher memory limit and ship through the bundled macOS Java Support plugin.
- Windows improves Git panel scrolling, repository status synchronization, and opening terminal links.
- macOS checks a community plugin's package checksum before installing and lists its permissions, programs to run, and source repository for you to confirm.
- macOS applies plugin enabling and disabling immediately, without a restart.
- macOS moves the settings entry to a top-right menu that opens Settings, Plugins, Theme, and Keymap directly.
- macOS shows the current shortcuts for Search Everywhere and Find in Files in an empty editor area.
- macOS lists and trees consistently show selected rows in the theme color when focused, and in gray when unfocused or the window is inactive.
- macOS data grids select a cell on a single click, color added, changed, and deleted rows differently, and size columns to their content.
- macOS database pages, connection tree, icons, and the connection editor now match the style of other tool windows.
- Windows settings use consistent controls, categories, and wording, support resizing the category list, and keep uncommitted edits when you switch pages.
- Windows project JDK and Maven paths can be picked from suggestions or typed freely, and clearing them restores automatic configuration.

#### 🛠 Fixes

- macOS fixes Agent permission prompts freezing long conversations and Claude showing the wrong model after reconnection.
- Long Agent tasks no longer end at a fixed time limit, and existing conversations avoid premature recovery interruption.
- Java fixes main entry points in test directories; non-UTF-8 sources no longer break the entire run list.
- Fixes remote branch checkout not advancing to the latest fetched commit.
- Windows fixes automatic saving missing the latest content during continuous editing.
- Windows fixes inconsistent breakpoint markers, stale Spring dependencies, and duplicate full-file diffs.
- macOS fixes the PHP language server failing to start because Node.js was not found when Lithe was launched from the Dock or Finder.
- macOS fixes Go to Definition not moving the cursor when the target is in the same file.
- macOS fixes installed plugins being disabled by mistake after the app quit unexpectedly.
- macOS fixes newly added database rows sometimes not appearing, and late results switching the page back after quickly changing connections.
- Fixes primary key information not being recognized correctly for SQLite tables.
- Windows fixes the window keeping the manually selected theme after switching back to Follow System.
- Windows fixes an interactive rebase stopped at an edit step occasionally being reported as interrupted.

### Upgrade instructions

- macOS: open the DMG for your architecture and drag Lithe.app to Applications.
- Homebrew: run `brew update && brew upgrade --cask lithe` after the cask update is available.
- Windows: download and run the x64 installer.
- macOS: Go Support is no longer built into the app and the older PHP Support is no longer loaded; after upgrading, reinstall them from Settings → Plugins → Marketplace.
- macOS: Agent connections that use an API key enable Model Call Statistics by default, routing requests through a statistics channel on your Mac; you can turn it off in Agent settings, effective after reconnecting.

### Compatibility and known issues

- macOS requires version 13.0 or later, with Apple Silicon and Intel installers; Windows installers target x64.
- macOS installers use ad-hoc signing without Developer ID signing or notarization; Windows installers do not yet have Authenticode signing.
- macOS and Windows automatic updates use their respective update signatures, independently of operating-system application signing.
- The plugin marketplace, Lithe Store, tool window docking, editor splits, and the Agent session status bar are available on macOS only in this release.
- Community plugins are maintained by their own developers and are not signed by Lithe, so install only plugins from sources you trust.
- Lua Support currently provides macOS packages only; running Lua files requires `lua` to be installed on your Mac.
- Agent step counts, generation speed, and context breakdown appear only for API key connections with Model Call Statistics enabled, and the context breakdown is an estimate.
- Networks that rely on an enterprise self-signed root certificate to reach the model provider may need Model Call Statistics turned off.

If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
