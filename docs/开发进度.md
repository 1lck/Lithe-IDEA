# Lithe 开发进度

更新日期：2026-07-31

## 当前状态

当前版本为可安装的原生 macOS Java 项目浏览与 Git 审查工具。核心浏览、审查、导航和终端流程已经形成闭环；Run 仍是明确的未接入状态。

## 已完成

- 项目：Welcome Screen、最近项目、文件树、文件增删改、默认目录排除和外部变化监听。
- 编辑器：多标签、保存、基础 Java 高亮、括号提示、代码折叠、参数提示、实现标记和路径面包屑。
- Java 导航：基于 JDT LS 的定义、引用和实现跳转，按需启动并在关闭项目时停止。
- 搜索：文件名、相对路径和项目全文搜索，结果可定位到文件与行。
- Git：Changes、暂存/取消暂存、撤销、提交、分支操作、提交历史、Blame 和分支比较。
- Diff：新增、修改、删除、移动状态区分；新增/删除使用单文件整页显示，修改使用并排对比。
- 工具窗口：内置交互式终端、可拖拽布局、窄窗口适配、设置持久化。
- Local History：磁盘快照、历史 Diff 和整文件恢复；默认保留 30 天，不把历史正文常驻内存。
- 交付：应用图标、Release App Bundle、本地签名和 `/Applications/Lithe.app` 安装流程。

## 性能基线

- Welcome 空闲状态实测常驻内存约 86 MB；产品目标保持在 150 MB 以内。
- 普通项目目标保持在 300 MB 以内，不包含按需启动的 JDT LS、Shell 和项目子进程。
- Java 服务、终端和后续 Run/Debug 均遵循用户触发时启动、关闭项目或会话后释放。
- Local History 使用磁盘存储；搜索、Diff 和历史记录均限制读取范围与结果数量。

以上数据是当前开发机单次基线，不替代后续的冷启动、空闲 30 分钟、开关项目和重复操作压力测试。

## 下一步计划

### 优先

- 可配置文件隐藏规则，并让文件树、搜索、监听和 Local History 共用排除配置。
- 双 Shift Search Everywhere：文件、类、符号和文本统一搜索；磁盘索引与流式扫描结合。
- 项目级搜索替换：分批预览、Local History 保护和逐文件写入。
- Java 实时分析开关：错误/警告波浪线、原因提示、Problems 跳转和未使用代码淡化。

### 后续

- Java 编译与运行：仅在用户触发时启动 Maven、Gradle、Javac 或项目 JVM。
- Java Debug：断点、线程、调用栈和按需变量展开；停止后清空调试状态。
- Diff 内搜索、代码块级暂存/撤销，以及更完整的大文件策略。

## 明确边界

- 仅面向 macOS 和 Java 项目。
- 不内置 AI、Agent 会话或模型调用。
- 不开发传统代码补全、自动导包、快速修复和重型插件平台。
- 不在 Lithe 内重复建立一套 Java 全项目语义索引；语义能力复用 JDT LS。
- 新功能不得阻塞 Welcome 首屏，后台服务不得在未使用时常驻。

## 验收重点

- 启动到 Welcome 可交互的耗时。
- 空闲 30 分钟后的内存是否稳定。
- 打开并关闭项目后内存是否回落。
- JDT LS、终端及未来 Run/Debug 停止后子进程是否退出。
- 多次搜索、Diff 和 Local History 查看后内存是否持续增长。
