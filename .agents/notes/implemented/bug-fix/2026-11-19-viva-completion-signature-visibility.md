# Agent 笔记：补全名称和长签名的显示空间

状态：已实现

## 先说结论

补全列表优先给候选名称留出宽度，便于区分前缀相同的函数。签名在列表中放不下时，选中项的完整内容会在列表底部换行，超出详情区域时可以滚动。方向键切换候选时同步更新详情。

## 问题

固定宽度的补全弹窗在同一行压缩名称和签名。两个候选可能只显示相同的名称前缀，调用参数和返回类型也可能藏在省略号后。

## 决策

- 工作台使用实际字体测量可见候选，按窗口可用宽度限制弹窗大小。候选行保留单行，先压缩签名摘要，再在极窄窗口中省略摘要。
- 列表放不下选中项的全部文字时，在有界高度的详情区域绘制完整文字。选中详情可滚动，键盘焦点留在编辑器。
- 参数信息根据补全弹窗当帧的实际位置和尺寸放置。窗口不足以同时容纳两个弹窗时，优先保留当前可操作的补全列表。

## 考虑过的备选方案

- 给所有弹窗改用更大的固定宽度。窄窗口和更长的签名仍会遇到截断。
- 在每个候选行换行显示签名。可见候选行数会随内容变化，用户逐项浏览时需要追踪位置。

## 后果

常用函数名可以直接在列表中辨认。长签名的详情会临时占用额外高度，窗口边缘的弹窗会调整位置。布局测量只遍历当前可见候选。
