# Agent 笔记：标题

状态：已实现

## 先说结论

用 2～4 句话说明：我们遇到什么问题、最后怎么决定、开发者以后最需要记住什么。
第一次出现的专业术语要顺手解释。

## 问题

说明这个决策要解决什么问题。不依赖具体方案也能成立。

## 决策

用现在时说明已经落地的决策。先写开发者要怎么做，再写边界、所有权和必须保持稳定的表面。
每条规则都说明“放在哪里”“不要放在哪里”或“违反后会发生什么”。

### 正确做法

- 具体示例。

### 不要这样做

- 具体反例和原因。

## 考虑过的备选方案

### 备选方案一

先写它最有吸引力的理由，再写为什么没有采用。

### 备选方案二

先写它最有吸引力的理由，再写为什么没有采用。

- 收益。
- 代价。
- 需要重新评估的触发条件。
