# Agent 笔记：标题

状态：提议中

## 先说结论

用 2～4 句话说明要解决什么问题、准备怎么做、开发者需要关注什么。
第一次出现的专业术语要顺手解释。

## 问题

说明为什么需要这个方案，以及不处理会造成什么后果。

## 提案

先说明开发者将来应该怎么使用这个方案，再说明边界和预期落地点。

### 正确做法

- 具体示例。

### 不要这样做

- 具体反例和原因。

## 考虑过的备选方案

### 备选方案一

先写它最有吸引力的理由，再写为什么暂不采用。

### 备选方案二

先写它最有吸引力的理由，再写为什么暂不采用。

## 验收标准

- 可观察、可验证的完成条件。

## 风险

- 已知风险和回退方式。
