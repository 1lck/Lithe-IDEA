# Agent 笔记：标题

状态：已否决：一句话原因

## 先说结论

用 2～4 句话说明当时想解决什么问题、为什么没有采用、以后遇到类似情况
应该优先记住什么。第一次出现的专业术语要顺手解释。

## 问题

说明当时为什么会考虑这个方案。

## 提案

按当时最强形态描述该方案，不要故意写弱；同时补一句它会怎样影响开发者。

## 考虑过的备选方案

### 当前采用的方案

说明为什么当前方案更适合。

### 其他备选方案

说明为什么也没有采用。

## 否决理由

说明该方案为什么被否决，以及未来什么情况下可以重新评估。
