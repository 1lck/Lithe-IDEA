# litheIOCN

处理用户指定的图标和页面；先确认 Lithe 现有按钮、动作、图标资源、渲染尺寸与调用位置，再查 [IntelliJ IDEA Community](https://github.com/JetBrains/intellij-community) 中对应的动作定义、SVG 和明暗变体。用上游源码中的 `viewBox`、显示尺寸、描边或填充和颜色作为依据，不凭截图猜数值。

- 优先复用 Lithe 已导入的 IDEA SVG 和 `LitheIDEAIcon`。缺少资源时，只引入所需图标及其明暗变体，保留上游版权声明和仓库现有许可说明；不要新增按钮或顺手迁移其他页面。
- 保持原按钮动作、可见条件、提示和禁用状态。图标应随当前应用主题选择对应资源；核对实际渲染尺寸与 SVG 原始尺寸，不靠缩放改变笔画粗细。
- 检查目标按钮及其局部样式是否调用 `.lithePointer()` 或其他手形光标逻辑。如果悬停会变成手形，仅在目标按钮处移除该效果，保留按钮点击行为和默认箭头光标；不要修改全局光标规则。
- 仅当用户要求悬停显隐时，按用户指定的悬停区域实现显隐，并检查渐变期间、隐藏时的命中测试及可访问性。不要把单个按钮悬停误作整行悬停。
- 在 macOS 深浅主题和实际界面检查图标、悬停光标与原动作。遵守 `develop-lithe` 的构建、功能矩阵和预览进程清理规则。

逐模块处理后说明本次准确改动的页面、上游资源路径、验证结果，以及仍未处理的页面。
