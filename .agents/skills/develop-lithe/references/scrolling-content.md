# 滚动内容与连续列表

新增或修改滚动列表、树、表格、日志、长文本和分页列表时遵守本页。通用规则见 [Lithe 开发规范](../SKILL.md) 第四节；本页路径都相对于仓库根目录。

## 滚动内容默认虚拟化

虚拟化指只创建或绘制视口及预取范围内的内容；离开该范围的行不存在对应的视图或 DOM 节点。

- 适用于滚动列表、树、表格、日志和长文本。固定且很短的表单、说明可以不虚拟化。不得因为本规则批量重写与当前任务无关的页面。
- 设置最大高度、裁剪、外包一层 `ScrollView` 都不是虚拟化。不得先创建全部行的控件或 DOM 再隐藏离屏部分。
- 复用已有能力：macOS 优先使用原生列表或文本视口，以及适用的惰性容器；Windows 使用现有的虚拟列表。不得另造通用滚动引擎。
- 单行内容也可能很重。长命令、日志和代码按行虚拟化后，不得仍让一个控件反复排版整篇文本：使用缓存排版、只绘制可见字形等原生能力；滚动时不得重建全文、不得重新测量所有行，不得把逐像素的滚动偏移发布到业务根模型。
- 选择、勾选和展开状态按行的稳定标识保存，不得依赖当前是否已创建该行的控件。保留键盘操作、无障碍、文本复制和滚动锚点。

验证：离屏内容没有被全部创建；滚动离开再回来后状态仍在；单条超长内容不卡顿。组件级计时不能代替真实产品的帧率测量。

## 连续列表随滚动自动加载

适用于连续浏览的分页列表，例如 Git 历史和反汇编：滚动接近视口边缘时预取下一页，不得要求用户反复点击“加载更多”或“上一页/下一页”。反汇编向上下两端扩展，Git 历史向下追加更早的提交。内存查看器这类离散页面仍然显式翻页。

### 加载

- 复用有界的后端分页和现有的原生或虚拟化渲染器。不得一次拉取全量数据，不得一次创建全部行来冒充无限滚动。
- 逐像素滚动状态留在局部视口。现有惰性 SwiftUI 列表使用 `LitheScrollLoadTrigger`。非惰性容器中页脚的 `onAppear` 不能证明页脚已进入可见视口；原生渲染器保留自身对视口的所有权。

### 锚定

- 在头部插入或在尾部追加时，保持选择不变，保持可见行的像素位置不变。
- 定位操作只做必要的纵向滚动，不得把代码横向居中，不得重置用户手动调整过的横向位置。
- 后台状态刷新或文件监听刷新，不得把已加载的范围缩回第一页，不得暂时移除分页页脚。原子地刷新已加载的范围；结果没有变化时保留原有的呈现标识。
- 顶部插入新行时，用“行标识 + 像素偏移”锚定视口，不得用选中行代替视口锚点。用户显式切换上下文或导航时可以重新定位。

### 请求与失败

- 对在途请求和返回结果按标识去重；上下文变化后丢弃过期结果。数据耗尽或翻页没有进展时停止请求。
- 请求失败后暂停自动请求，提供本地化的“重试”按钮；不得因为边缘仍然可见就持续自动重试。
- 调试器可能拒绝跨越未映射地址的整页请求，而不是返回空页。此时用有界的请求序列缩小反汇编窗口；只有最近的相邻请求也失败、并且适配器仍能读取已知边缘时，才停止该方向的加载。保留真实的传输错误和超时错误，忽略无效的填充数据；不得猜测 CPU 指令长度，不得对适配器返回的不透明地址做算术。

### 验证

覆盖真实视口滚动、头部插入与尾部追加时的锚定、缩放、短内容与溢出内容、失败与重试、数据耗尽和取消。声称两个平台行为一致之前，先检查另一平台的实际行为。
