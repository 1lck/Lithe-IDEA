Database brand icon assets
==========================

MySQL, MariaDB, PostgreSQL, SQLite, Microsoft SQL Server, MongoDB and Redis
SVGs (including available dark variants) are unmodified IntelliJ Community
platform/icons/src/providers assets. PostgreSQL, SQL Server and MongoDB retain
local filenames postgres, sqlserver and mongodb, respectively.
Source: https://github.com/JetBrains/intellij-community
Revision: c7f91397daa3a961b4e78bc634fe467a0a7d9ade
Each imported SVG retains its upstream copyright and Apache-2.0 header.

Nacos has no dedicated provider mark in this Community revision. Its local
nacos{,_dark}.svg files are unmodified platform/icons/src/expui/general/settings
variants from the same revision, used as a generic configuration icon.
