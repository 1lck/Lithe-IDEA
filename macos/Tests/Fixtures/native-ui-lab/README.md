# UI 验收实验室（macOS）

这是独立测试插件 `org.example.native-ui-lab`，与旧 Sample Build 可同时安装。
所有界面由 IDE 原生控件生成，没有 HTML、CSS、前端框架或自绘样式。
仅供当前支持 `ui: 3` 的 macOS DEBUG 预览；Windows 和正式发行版不适用。

0.3.4需要本分支加入公共组件后的新宿主；仅安装新ZIP不会更新宿主支持。
验收前先退出其他分支的旧预览，再启动本分支预览，避免把旧窗口当成本次结果。

## 安装

1. 在插件管理中“从磁盘安装”，选择 `NativeUILab-0.3.4.zip`，按提示重启预览。
2. 打开随包生成的 `UI-Lab-Workspace` 文件夹，确认里面有 `lithe-ui-lab.json`。
3. 动态面板需要可用的 Node.js 20.3+；如提示运行插件 Provider，允许这个本地测试插件。
4. 左侧活动栏有“UI Lab · 动态列表”“UI Lab · 静态列表”；右侧有“UI Lab · 动态树”“UI Lab · 静态树”，底部有“UI Lab · 空面板”、“UI Lab · 表单控件”和“UI Lab · 按钮验收 0.3.4”。此外会出现宿主自动生成的 `UI Lab Provider` 构建面板，它不属于这七个验收面板。

静态面板不需要 Provider。表单可先编辑；输入框回车、选择器和通知复选框提交时调用本地测试 Provider。动态面板若提示需要一个匹配实例，先确认打开了配套工作区，
不能只把插件 ZIP 当作工作区打开。测试数据只在内存中修改，不改工作区文件；Provider 退出后恢复默认。

## 建议验收顺序

1. **静态树**：展开至第三层，试 ↑↓←→、顶部/底部边界、中文/英文/表情、长标签截断；收起父节点后不能继续选到隐藏子节点。
2. **静态列表**：鼠标悬停和单选、方向键、滚动；叶节点不应有展开箭头。
3. **焦点和样式**：左右各选一个条目，再点中间 README 编辑器；只有当前树/列表显示活动选中色，其余变灰；背景两侧留白一致，没有整个面板蓝色框。缩放面板后短内容仍从顶部排列。
4. **动态树/列表**：鼠标进入整个面板后才显示顶部图标按钮；移出面板后隐藏。刷新、检查（放大镜）、重置使用图标，悬停显示名称；键盘焦点仍可显露并执行动作。顶部“检查”在无选择时禁用。选择一个节点后点击“检查”，消息显示标签和 ID。右键另一个节点执行“检查”，必须显示右键目标，不能误操作之前选中项。
5. **修改标签**：右键执行，标签追加 ✓；稳定 ID 不变，选中应保留。刷新后不丢失选择和已展开的层级。
6. **增删排序**：右键“添加节点”后底部出现新节点；“反转顺序”后选择仍指向相同 ID；“移除所选”删除该节点及子树，失效的选择清除，“检查”应禁用。
7. **长数据**：右键“加载长数据（600 项）”，试快速滚动和方向键自动滚动可见；动态树每项另含一个子节点，共 1200 个节点。顶部“重置”恢复。
8. **空数据**：右键“切换空数据”，显示 No items，“检查”禁用；顶部“重置”恢复。独立“空面板”始终显示 No items，不应卡在加载状态。
9. **失败恢复**：分别试右键“模拟动作失败”“模拟数据加载失败”“模拟重复 ID”。应显示错误并保留上一次合法数据；非法数据不能替换当前界面。顶部“重置”恢复，刷新后恢复正常。
10. **加载和生命周期**：右键“慢加载（3 秒）”，出现加载提示且动作暂时禁用；正常完成后恢复。再次执行并立即隐藏面板或关闭工作区，不能冒出旧结果或崩溃；重开后可刷新。
11. **状态恢复**：展开、选中后隐藏再打开面板，仍存在的节点应恢复选择与展开；可再检查浅色/深色和整个窗口失焦后的颜色。

动态树和动态列表使用独立数据；修改一边不应改变另一边。空列表没有节点右键菜单，使用顶部“重置”恢复。
加载失败和非法数据模式会持续到“重置”；单击“刷新”会再次报错，这是刻意设计的恢复测试。

## 表单控件验收（0.3.4，公共组件实验室）

1. 安装新 ZIP 后重启，打开底部“UI Lab · 表单控件”；窗口标题没有图标或边框，表单下方有普通/主要按钮、短文案/长文案自然宽度及禁用状态示例。
2. 在“名称”输入中文、英文、Emoji，试粘贴、选择和撤销；输入时不调用插件，按回车后面板上方出现“已收到”及全部字段值。
3. 空输入框显示占位提示，试中文输入法组合输入。输入长度上限为1024 UTF-8字节。
4. 打开“环境”下拉，鼠标选择或用方向键/回车选择；Escape 取消。提交反馈应显示 dev/test/prod 的稳定值而非显示标签。
5. 切换“启用通知”复选框，反馈应显示 true/false；点击文字也能切换。Tab/Space 的键盘行为与 IDE 公共复选框一致。
6. “离线模式”只修改本地值，不单独调用 Provider；下一次提交其他字段时也应包含它的新值。
7. 三个禁用控件分别不能编辑、展开或勾选。函数执行期间全部控件暂时禁用。
8. 修改控件后隐藏、重开面板，检查值恢复；切换其他工作区时不能沿用此工作区的值。停止或重启 Provider 不清除宿主保存的表单值。
9. 宽面板每行显示两个完整字段（标题＋控件），每项占6列；按声明顺序排列。
10. 将窗口或停靠面板调窄，内容区窄于640pt后自动变为单列；变宽后恢复栅格，输入值和焦点不应丢失。调矮后可滚动，没有水平溢出；分别检查深浅主题及公共控件外观。

## 0.3.4重点验收

1. 普通/禁用输入框、搜索框、多行输入均复用与IDE设置页相同的完整组件，标题间距与外框由公共入口负责。
2. 每个禁用字段都有独立说明：输入仍不能修改，但“i”可以悬停、点击固定、再次点击关闭，并可通过键盘打开。
3. 禁用普通/主要按钮旁也有“i”：说明可用，按钮不能调用函数；慢提交期间说明也应保持可用。
4. 对比插件市场或设置页搜索框：搜索图标、清空按钮、输入焦点和外框一致。输入后清空，再用Tab/鼠标聚焦，试中文组合输入与回车。
5. 多行输入按Enter只换行，按钮提交时保留换行；隐藏重开保持当前值。宽面板两列、窄面板单列。

## 新增公共组件验收

| 组件 | 声明 | 重点验收 |
| --- | --- | --- |
| 标题信息提示 | `info` | 悬停后显示、点击固定、移出/关闭、键盘可达；禁用字段也可悬停查看说明 |
| 搜索框 | `search` | 未聚焦I形光标、组合输入、清空按钮、回车提交；清空只改本地值 |
| 多行输入 | `editor` | Enter换行、滚动、中文/Emoji、撤销；使用下方提交按钮传值 |
| 分段选择 | `segmented` | 选择高亮与选项ID、禁用、状态恢复 |
| 数字步进器 | `stepper` | 1–8边界、增减、数字类型传递、禁用和恢复 |
| 普通/主要按钮 | `buttons` | 原有公共外框、颜色、高度和禁用状态 |
| 按钮宽度与间距 | 宿主统一 | 短文案最小72pt，长文案自然增长；动作间距6pt，空间不足纵向排列 |

1. 每个字段旁的“i”都来自 `LitheInfoTip`；支持悬停延迟与点击固定。点击其他区域或再次点击提示图标关闭，不能阻挡相邻字段。
2. 多行输入修改后不会自动执行插件；按钮提交时，反馈包含全部字段。按钮不应作为字段出现在 `values` 中。
3. 搜索框、分段选择和步进器各有正常/禁用版本，不能通过禁用控件改变值。
4. 依次测试普通与主要按钮的短/长文案，以及两个禁用按钮；禁用按钮不能调用函数。
5. “慢提交”期间所有输入与动作禁用；隐藏面板取消执行，重开后值恢复。“模拟提交失败”只显示错误，不清空任何字段；普通提交可恢复。
6. 在宽面板、窄面板、深浅主题和失焦状态分别检查公共样式。全部控件按两列排列，窄于640pt自动单列；调矮后可滚动。

## 当前插件声明的边界

覆盖 schema 1 已开放的 tree/list/form、静态 nodes、动态 source、节点层级、稳定 ID、文字标签、
refresh/invoke 动作、requiresSelection、工具栏、节点右键菜单，以及 left/right 工具窗口位置。
原生工具窗口也支持 bottom，本包把空面板与表单放到底部以验证该位置。
表单已支持 input/search/editor/select/segmented/checkbox/stepper、信息提示、按钮及 公共自然宽度规则、初始值、禁用状态、栅格和 onCommit。插件树/列表当前只有单选；公共控件的多选、节点图标、自定义双击/回车动作、
菜单分组和子菜单尚未作为插件声明 API 开放，本包不模拟这些能力。公共组件的外观由宿主统一；插件不能传入颜色、字体、边框、像素间距或任意UI代码。

## 从源码重新打包

在仓库根目录执行：

```sh
export LITHE_PLUGIN_SDK_ROOT=/path/to/lithe-plugin-docs/sdk/node
node macos/Tests/Fixtures/native-ui-lab/package.mjs
node --test macos/Tests/Fixtures/native-ui-lab/native-ui-lab.test.mjs
```

本目录仅保留宿主验收数据与动作，不保存 SDK；先取得官方 lithe-plugin-docs 仓库，再设置上述 SDK 路径。

输出位于 `.artifacts/native-ui-lab/`。ZIP 中自带官方 Node SDK，不需要安装依赖。

## 0.3.4按钮统一验收

宿主已接入#1422公共按钮标准：28pt高、13pt常规字、14pt水平内边距、72pt最小宽，
无外部焦点留白。主按钮使用公共蓝色及hover/按下/禁用状态；动作之间保持6pt间距。
按钮随文字自然增长，面板宽度不足时按钮组纵向排列；不按栅格列数拉伸按钮。
旧包的buttons.width/content/fill及buttons.span仍兼容读取，但不再控制按钮宽度或动作组布局。
新版示例省略这些字段；普通/主要按钮均有短文案与较长文案，另外保留禁用和提示验收。

## 0.3.4 独立按钮验收面板

打开底部「UI Lab · 按钮验收 0.3.4」，无需滚动表单即可查看按钮。
「取消」是普通短按钮，「应用」是主要短按钮；另外包含两种长文案、禁用普通/主要按钮、慢提交及失败反馈。
点击启用的普通/主要按钮，应收到带0.3.4版本的成功反馈；禁用按钮不能执行，旁边i提示仍可查看。
拖窄面板检查纵向排列，切换深浅主题检查颜色，分别检查hover、按下和键盘焦点。

按钮外观属于IDE宿主：必须先运行本分支最新构建，再安装此ZIP。仅更新插件不能替换旧宿主里的按钮样式。
