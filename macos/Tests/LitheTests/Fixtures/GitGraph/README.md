# Reported Git graph regression

`issue410-history.tsv` freezes the first 200 commits of `0a85abc4` in
`git log --topo-order`, including the merge cluster in the reported screenshot.
`issue410-context.tsv` freezes the first 1,000 commits of `git log --all
--topo-order` in the same repository state. Columns are full hash, ordered
parent hashes, decorations, and subject. Author names/emails are omitted;
context-only subjects are placeholders. Ref decorations are frozen, so future
branch movement cannot change the test.

The expected text files were generated by running the actual IntelliJ classes
from IDEA **IU-262.10315.125**, with compact long edges:

- `issue410-idea.txt`: independent page graph, without repository context.
- `issue410-context-idea.txt`: permanent layout from all references, then the
  selected 200 commits in the base graph's order. Page-external parents remain
  unloaded edges, as they do in the paginated Lithe view.
- `idea-colors.txt`: archived fallback-theme RGB samples from the first oracle.
- `idea-theme-colors.txt`: current light/dark expUI / Islands overrides
  (saturation 0.6, brightness 0.7 / 0.6), using the actual generator.
  Includes negative IDs and 32-bit integer overflow. ID zero uses the platform foreground.
- `issue410-date-history.tsv`: first 300 commits of `631ede91` with `--date-order`.
- `issue410-date-context.tsv`: all 1,711 reachable commits from the frozen refs,
  within the product's 5,000-commit limit, in `--date-order`. Complete context
  matters: clipping the DFS changes fragment IDs and therefore colors.
- `issue410-date-idea.txt`: repository-context oracle for the date-ordered page.

`GenerateIdeaOracle.java` calls `GraphLayoutBuilder`,
`GraphElementComparatorByLayoutIndex`, `PrintElementGeneratorImpl`, and the
original color generator, with unique negative IDs for distinct unloaded parents.
The no-argument graph builder aliases all unloaded parents to one sentinel and
must not be used for a multi-parent page boundary. Its presentation callback implements the reference
priority and `GraphColorManagerImpl` head/fragment rules. It does not call Lithe
or derive expected output from the Swift implementation. The `origin/` remote
parser is intentionally limited to the frozen data, whose only remote is origin.

To regenerate deliberately, point `IDEA_CONTENTS` at an installation's Contents
directory. Use a temporary output directory and inspect differences before
replacing the frozen expected files:

```sh
fixture=macos/Tests/LitheTests/Fixtures/GitGraph
oracle_output=$(mktemp -d)
"$IDEA_CONTENTS/jbr/Contents/Home/bin/javac" \
  -cp "$IDEA_CONTENTS/lib/*" -d "$oracle_output" "$fixture/GenerateIdeaOracle.java"
"$IDEA_CONTENTS/jbr/Contents/Home/bin/java" -Djava.awt.headless=true \
  -cp "$oracle_output:$IDEA_CONTENTS/lib/*" GenerateIdeaOracle \
  "$fixture/issue410-history.tsv" "$oracle_output/issue410-idea.txt" \
  "$oracle_output/idea-theme-colors.txt"
"$IDEA_CONTENTS/jbr/Contents/Home/bin/java" -Djava.awt.headless=true \
  -cp "$oracle_output:$IDEA_CONTENTS/lib/*" GenerateIdeaOracle \
  "$fixture/issue410-history.tsv" "$oracle_output/issue410-context-idea.txt" \
  "$oracle_output/idea-theme-colors.txt" "$fixture/issue410-context.tsv"
"$IDEA_CONTENTS/jbr/Contents/Home/bin/java" -Djava.awt.headless=true \
  -cp "$oracle_output:$IDEA_CONTENTS/lib/*" GenerateIdeaOracle \
  "$fixture/issue410-date-history.tsv" "$oracle_output/issue410-date-idea.txt" \
  "$oracle_output/idea-theme-colors.txt" "$fixture/issue410-date-context.tsv"
```

Ordinary Swift tests only read the frozen data. They require no Java, IDEA,
network, or repository history. Setting `LITHE_GIT_GRAPH_CAPTURE_DIR` saves
light/dark PNGs rendered by the production SwiftUI Git graph and AppKit painter.
These are fixture replays, not screenshots of a user's running application.
The test windows are closed at the end of each appearance check.

These runtime-generated oracles supplement the nine original fixtures pinned
to IntelliJ source commit `36415d346b3d18a6ded90d05afb8e0a0bface9d6`
under `LitheGitModuleTests/Fixtures/GitGraphIDEA`. See the repository's
`macos/Resources/GitGraph` for upstream license and attribution.

The reference screenshot is reproduced from `2bedf381` through `887f49ea`,
including the `de4208d5` update commit. `idea-reference-light.png` and
`idea-reference-dark.png` capture exactly these 11 rows; the original dense
merge cluster is also replayed. The full-window fixture has no user data.
